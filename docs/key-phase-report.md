# K 通道偏移相位搜索：本地筛查

## 方法与边界

在 v324 的加权均值及8轮偏移更新之后，固定当次尺度，每通道搜索17个偏移候选（包含原点），最小化加权格点误差，再重新生成尺度并执行原 GPTQ。共用通道平移在连续域保持 softmax 不变；固定尺度代理目标下降不保证重新量化后的最终 PV 误差下降。

数学检查：100个随机实例、400项断言通过，全部实例至少有一个通道改善，平均固定尺度目标比值0.813005。这不是线上收益估计。

## 实际接口筛查

两套建模激活数据各6组、每组5例，完整结果见 `key-phase-screen-feedback.json` 和 `key-phase-screen-covariance.json`。两套相对 v324 的总增量均为0，12组校准守门全部拒绝，无分支异常。检查父状态未修改、Q/V状态相同、状态和K输出格式有效。

守门考察最终PV及两折改善，部分平均误差略降并不足以通过。没有放松守门来制造本地正收益。当前脚本为离线研究工具，使用文件读取及动态装载，不是可提交 solution。

## 决策

不合入 v350/v351，不覆盖默认入口，不据此断言该方向在线上必然无效。固定格点误差降低与最终 Attention 输出收益之间仍有目标错配；继续增加同类偏移候选暂时缺乏证据。两套数据都是 checkpoint 投影权重加建模激活，不是真实模型前向采集，不具备绝对线上分数预测资格。

## 拒绝候选审计（2026-09-05）

|---|---:|---:|
| feedback | +0.034610994 | 15/15/0 |

feedback组14/19分别−0.009891/−0.026151，组49+0.059754。因此“全拒绝”不等于所有测试都无收益，也不支持全量绕开守门。covariance的增量中+0.086204发生于T=10，占约87.5%；此bank沿用了1/10/128/512/1024长度，**没有线上Attention长度依据**，不能用其短序列收益预测线上。feedback实际长度为128/256/512/1024/2048，按长度合计增量为+0.016164/+0.034051/−0.008650/+0.009833/−0.016787。

下一项可检验假设是最后一个校准序列的选择偏差：通过多份校准样本的留出/交叉拟合衡量候选的跨长度稳定性，不能利用测试结果决定阈值或按本地组ID路由。目前未实现该选择器，不宣称已发现线上长短序列比例；不产生新的正式solution。

## 两份校准留出实验完成

新增 `--cross-calibration`：父状态和候选只用校准序列0/2/3构建，序列1/4完全留出；两份各32个查询、奇偶两折。预先固定接受规则为每折跨序列平均误差比<0.995，且所有序列/折误差比<1.02；不按测试结果改阈值。测试阶段仅使用已选状态。这里是一次固定划分，不是完整交叉验证或重训后部署。
