# 实际 GPTQ 前向下的共享正交变换学习

2026-09-03。线上最佳仍v314=20071/241秒，目标22000+未达；v315待回执。本轮研究不更改生产入口、Linear或数据集，不创建新solution版本。

## 已实现的算法

在父版已有配平坐标之后，对每个KV组学习一个共享正交矩阵O。Q/K同时右乘O，理论上原始logit不变；两个角色的矩阵变换均与O融合，不能只接受一侧。

- 新GPTQ逆度量通过 `Oᵀ(UᵀU)O` 重新做上三角Cholesky；不需要再次求完整逆矩阵。
- refinement H同步变为 `OᵀHO`，保留父版H的存储dtype。单位O直接返回父状态，避免身份变换也引入重算误差。
- 训练只使用末份校准之前、2≤T≤1024的最后两份样本，保留全部key；Q分别抽16/64个query。
- 每次前向使用真实GPTQ及原有refinement；STE只为量化输入提供近似导数，不把它当离散问题的真实导数。
- 在正交切空间计算方向，Cayley变换尝试学习率及其1/4两档；按两份训练样本归一化实际损失接受，最多4步。损失可选最终PV或去除每query公共偏移的logit误差。
- 末份校准保留完整key、最多64query，以实际量化V评分，两折KV组均值都改善才成对采用。V策略不变。

这不是完整论文方法的等价复现，也不是所有正交变换的穷尽搜索：只有有限样本、STE方向、两档步长和少量步骤；运行预算及迁移表现仍需验证。

## 逐步对照及负结果

首批反馈组1/5/14/49，共20题。下表都是相对v314的本地原始分变化，不是线上分数。

| 配置 | 本地增量 | 观察 |
|---|---:|---|
| 16query，稠密O，步长0.03 | -0.000655 | 少数组训练改善，但测试未稳定受益 |
| 16query，稠密O，步长0.1 | 0 | 全部回退 |
| 64query，稠密O，PV目标 | 0 | 全部回退 |
| 64query，稠密O，中心化logit目标 | 0 | 额外逐Q头限制下全部回退 |
| 64query，64通道块内O，PV目标 | 0 | 额外逐Q头限制下全部回退 |
| 块内O，移除额外逐Q头限制 | +0.001222 | 仍要求两折KV平均都改善 |
| logit目标，移除额外逐Q头限制 | -0.198145 | 两折校准采用也不能保证测试收益 |

最初额外要求每个Q头误差不超过父版1.05倍。这不是评分规则要求，会拦住一些组平均改善的候选，故做了移除此限制的独立对照。它不是所有拒绝的唯一原因：例如块内O在组5某KV头两折比率为0.8221/1.0714，另一KV头为0.9678/0.9935，只有后者满足两折条件。组平均改善不等于两折都改善。

## 数值与性能整理后的复核

初始单组探针的FP32 Cayley求解产生约1.35e-5的正交误差。后改用FP64内部求解、返回FP32；这是数值修正，原报告保留，不拿它作为稳定版本证据。

最后将STE表达式改为 `quant + (x-x.detach())`，确保前向逐项等于真实量化值，避免等价代数写法的浮点抵消误差。同时增加确定性早停：没有动量、调度或重采样，状态及两档步长完全不变且均失败时，下一轮只会重复，故结束训练。单测验证与未早停最终O逐项一致。早停不意味着已经找到全局最优。

使用修正后的64query、64通道块内O、仅两折组均值守门：

| 数据范围 | 样本数 | 原始分增量 |
|---|---:|---:|
| 反馈首批1/5/14/49 | 20 | +0.001224 |
| 反馈第二批2/9/18/48 | 20 | -0.000715 |
| 协方差组7/16/27/38 | 20 | 0 |

收益不足以支持提交，不能据此断言所有可学习变换无效。部分训练损失下降1%–10%以上，但留出折之间会分歧；当前有限查询和训练目标的下降没有稳定迁移。现有bank是checkpoint投影加模型化hidden，不是真实前向激活，也没有可靠线上预测资格。

## 验证

- FP32返回O的单测正交误差3.58e-7；原始logit最大差6.68e-6；逆度量共轭误差1.12e-8。块外元素保持0。
- 单位变换返回原状态；训练不改变校准输入/全局RNG，末份校准标签不参与训练；支持外层inference_mode，状态不保留梯度或优化器对象。
- 精确STE前向、早停与完整循环最终矩阵一致、训练接受目标单调、GQA及动态格式检查通过。
- 最终三份复核报告两个版本合计24次state、663次公开动态返回格式检查通过，含校准内部调用，不是663道不同题目。
- 部署审计对反馈组5的T=128/1024/2048检查了训练/校准/测试：即使完整Q与子集Q跨越NumPy/Torch分支，抽查量化结果逐项相同；连续logit相对MSE约2.8e-13–3.2e-13。此为有限范围证据，不是任意形状/backend的bit-exact证明。
- 多个实验并行且计时含评分/校验，不能外推线上耗时；未运行新提交自检或全250题候选验证。

## 决策

保留真实GPTQ前向、共享正交更新、度量同步和隔离验证工具；不向v315叠加本次未形成稳定收益的候选。所有原始、数值修正、严/宽守门及失败报告均保存。

下一方向是固定HiF4格点上的成对坐标更新：现有搜索逐次改变一个通道，相关通道可能存在两个单独更新都不改善、联合更新却改善的局部最优。需要用完整二次交叉项证明收益，先测实际被困行的比例，再决定实现规模；不能把它包装为已经验证的200+收益。
