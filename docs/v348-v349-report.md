# v348/v349：显式位置与背景的联合二阶风险

独立父版v324，Linear/Q/K不变，不叠加v341或v347。v348单独表示首1个位置，v349首4个位置。它们是假设检验，不声称线上这些位置必有高权重。

校准保留显式位置概率与背景总质量的联合Gram C。背景内部按交换对称建模，增加β(I−11ᵀ/n)，保持PSD并保留组间协方差。背景误差均值与显式位置误差组成小向量u，优化uᵀCu+β||e_bg−mean(e_bg)||²，加微小MSE稳定项。固定原生HiF4尺度，8轮单坐标更新，每次用精确代理二次增量选择；动态没有T²矩阵。

两份校准各16query、完整key估计。状态还记录每校准query的显式位置/背景相对强度和背景集中度；动态按最近校准长度选模型，用当前长度重新归一化位置/背景质量，再形成小Gram。末份32query两折仅选采用头。输入只有当前V和冻结CPU统计，不访问当前测试Q/K，不共享动态全局数据。

长度迁移假设是相对背景强度较稳定，不是已经验证的线上规律。背景方差和位置关联跨模型/长度可能变，未补偿Q/K一次交叉残差，可能仍然退化。T4–4096、V≤4194304元素；显式位置数过多导致背景不足时回退父版。
