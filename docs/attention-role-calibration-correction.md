# Attention校准信息边界重大修正

## 用户确认的事实与未知项

Q分支校准收到真实Q和虚假K/V，只保留q_state；K、V分支同理。三次分别校准。假矩阵来源尚不清楚，不能假定为标准高斯、其他模型、打乱张量或特定低秩分布。此处为用户确认信息，未取得线上判题器源码。

这不是Linear那种共享同一份真实W的信息条件：存入V state的校准Q/K可能是假的，而非当前或同源真实Q/K。无法通过扩大state、增加搜索轮数弥补信息来源失真。

## 本地哪里不匹配

- evaluate_local.py的evaluate_attention对真实配对calib只校准一次，直接取三个state。
- self_check.py也一次校准取三个state，它保证公共接口和格式，不证明线上真实数据流。
- 之前v405/v406隔离测试分别加载动态模块，但仍取自同一次真实配对校准。其动态无共享缓存结论仍成立，不能据此声称验证了三次角色校准机制。

先前本地实验不是伪造结果，但证明的运行条件与线上不同；今后不能沿用它来为跨角色优化排序。当前数据仍可做张量/格式/数学诊断，不删原始数据、不调权重制造历史同分。

## 策略影响

| 策略 | 新信息下的解释与处理 |
|---|---|
| V→Q/K回归、sigma情景、双概率核 | 可能拟合到假的对端，失去“真实联合关系”依据；暂停以原配对评测支持继续扩展 |
| 真实Attention输出守门、Output-Jacobian、温度及VR | 校准目标可能是由假对端组成的输出；通过门槛不保证真实测试改善 |
| Q/K自适应联合缩放/矩阵平衡/旋转 | 三次校准分别决策，拼出的Q/K状态未必配套；共同变换必须证明跨调用一致，不能假定互逆 |
| GPTQ | 对端Gram可能是假的，不能再解释成真实对端敏感度；但历史线上收益真实，保留基线做逐项消融，不直接全删 |
| 单角色尺度/码字/裁剪统计 | 对应真实角色仍有有效训练信息；采用自身统计和当前输入可避免虚假跨角色相关性 |
| 当前K常量平移 | softmax对所有key共同平移的不变性仍成立；如何选择偏移及舍入收益需要新的独立角色评测 |
| V均值/误差协调 | 操作当前真实V仍可执行，但“扩散注意力”代理假设不能由假Q/K验证；需方差保护与分布敏感性分析 |
| 固定共享正交变换 | 若只依赖双方共有的确定信息，Q/K可以配套；分别自适应选变换则仍有失配风险 |

不凭这条消息认定所有历史退化已解释、线上维度已识别或22500已可达到。

## 已落地的诊断执行器

tools/check_role_decoy_calibration.py保留真实测试Q/K/V，每个角色新加载模块、分别校准、只取对应state，再新加载动态角色模块。两种假数据仅为敏感性假设：独立行置换、16列块独立行重采样；量化值与scale一起变换，真实目标角色逐值不变。没有冒充官方假数据生成器。

固定结构组10、5个真实测试，结果见role-decoy-calibration-screen.json：

| 校准方式 | v402原始质量合计 | v406原始质量合计 | 增量 |
|---|---:|---:|---:|
| 一次真实配对（旧评测） | 4.690657422 | 4.729955471 | +0.039298050 |
| 三次校准/非目标行置换假设 | 4.662371075 | 4.708874506 | +0.046503430 |
| 三次校准/非目标块重采样假设 | 4.648243734 | 4.695462892 | +0.047219158 |

6种版本/方式均通过组装state检查、每种15个动态格式检查。结果表明校准机制改变会改变结果，但这两种假数据并未复现线上同分；不隐去反例，不宣称已经拟合线上。范围只有一个组，不能估计总体影响或线上耗时。

## 后续执行顺序

1. 正式区分“目标角色真实数据”与“未知对端分布”，评测同时覆盖三次独立校准及多个明确标记的假数据假设；若拿到官方假数据规则则直接替换假设。
2. 使用v400线上基线，对跨角色模块做分组消融，统计每个角色的拟合/启用/回退以及最终Q/K变换兼容性，先消除无效校准成本；不一次删光。
3. 优先开发对端无关的K平移和尺度/码字联合搜索、固定兼容Q/K变换、单角色可迁移统计。所有state的生成只依赖该输出角色可信输入，未知对端仅作为明确的稳健假设，不能作真实配对样本。
4. 校准调用模式尚无生产自动识别标志，因此不能写“猜哪个角色是真的”的启发式；应让三个返回state分别满足各自信息边界。

本轮只修正研究协议与记录，不发布基于未知假矩阵来源的v407、不替换默认提交。
