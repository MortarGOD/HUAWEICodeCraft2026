# 全通道 V→K 与条件查询误差度量

2026-09-03。线上最佳仍 v314=20071/241 秒，22000+ 未达；v315 待回执。此次研究未改生产入口、Linear 或数据集。

## 为什么重新做全通道预测

此前只测128/256个随机通道的回归，不能代表全部V信息。本轮以 calib[:-1] 的全部V通道拟合K，比较ridge=0.0001/0.01，末份校准和全部测试只评估新增预测器。每份校准最多512行；若所有拟合样本K=V精确相等，则使用恒等映射而非重新拟合。

必须区分两个误差：K预测MSE/官方HiF4的K误差，以及在评分器中使用真实Q/V时，预测K导致的softmax·V输出MSE/官方输出基准误差。后一项仅是离线诊断，真实测试Q/V不属于V→K预测器输入。

反馈代理首批组1/5/14/26/37/49、第二批2/9/18/32/41/48，每组5题：

- K=V组1/2/48/49，恒等映射误差为0；这不是线上一般性质，校准相等也不保证未来输入永远相等。
- 其余反馈组，ridge0.01的测试K误差约为HiF4误差的2.15–35.52倍；预测K所致输出误差均值约为官方基准的12.96–137.52倍。
- 某些组K相对误差仅约1.6%–1.8%，输出仍严重偏离。小的逐元素误差不能代替输出度量。
- 协方差代理的非相等组7/16，ridge0.01下K误差分别约37.09/34.30倍，但输出误差约0.99/0.82倍。两个bank都表明不能仅凭K MSE推断最终输出。
- 更小ridge在这些非相等组上没有解决问题，部分情况更差。不把某个回归器失败写成所有跨角色建模均不可能。

完整记录：`full-key-prediction-screen.json`、`full-key-prediction-holdout.json`、`full-key-prediction-covariance.json`。

## 只预测误差权重，不预测真实输出

即使预测K不够精确，也可能提供有用的权重方向。本轮因此实现条件查询度量：

1. 用完整V通道拟合K，采样固定的校准Q。
2. 将V→K系数与这些Q融合成查询系数，动态由当前V直接计算softmax权重，无需读取当前Q/K，也不必生成完整预测K。
3. 优化残差始终是当前真实V减量化V，不把预测PV当真值。
4. 最后一份校准用父版实际量化Q/K/V、完整key、最多64query，两折都至少改善1%才按KV头采用。

状态只含固定CPU center/scale、查询系数、常数偏置及回退state。偏置对每个query的所有key相同，保留它不改变softmax，但后续可在有性能需要时删除；本轮没有为这类微小差异创建新版本。父版仍沿用自己的校准流程，不能声称末份校准对整个父版完全独立。

## 条件权重与尺度树组合

复用上一轮六种尺度基底，先在每棵树上按条件查询度量做格点反馈，再按token×64块选择。令误差e的条件目标为 `mean_query ||P e||² + (1/T) mean_token ||e||²`，则单token变化的曲率和梯度为：

`curvature_j = mean_query(P_ij²) + 1/T²`

`gradient_j = mean_query[P_ij (P e)_i] + e_j/T²`

候选增量用 `curvature*delta²−2*gradient*delta`，多行交叉项通过重新计算完整代理目标处理；按全量/8行/1行三种预算接受，并限制逐通道MSE为父版1.1倍。最终仍由真实校准输出守门。

这一组合并未超过本批固定尺度的条件查询方案，说明扩大可行格点与增加预测复杂度没有自然转化为更多实际收益。只测首批，不作整个方向失败的结论。

## 验证

- 无噪声线性单测留出MSE约1.26e-10；融合查询系数与显式预测K的softmax最大差1.79e-7。
- 恒等/常量输入、全局RNG不变、校准输入不变、末份校准三种角色均排除、合法state通过。
- 条件格点和尺度树两实现均覆盖T=1/129/1024/4097，格式、未激活头、禁用路径、边界回退、代理目标单调及各自MSE上限通过；采用分支确实改变了输出。
- 单行非均匀权重二次增量与FP64直接重算差2.58e-15。
- 四份动态回归报告的9个配置合计50次state、877次公开动态返回格式检查通过，包含校准中的调用，不是877道不同题目。
- 本轮未进行候选完整250题回归、新提交自检或96核性能评估。研究计时含打分/校验，部分运行并行，不能视作线上时间。

## 决策

不将预测PV作为真值，不为此次小增益另发版本；保留条件权重建模及融合计算实现。两套bank均是checkpoint投影加模型化hidden，不是真实模型前向激活，线上预估资格仍不足。

下一轮重新审视线上已证明有效的Q/K GPTQ、校准度量及变换。不能仅因本地V误差分解较大，就把优化路线锁定在V预测/均值反馈；必须回到线上大消融证据。v315待回执期间仅研究，不覆盖生产。入口SHA256仍为 `d85f87cc68ab4161056fb47b810be16d5465e12171ad86e3dda25db05c956fa6`。
