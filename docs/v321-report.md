## 本版真正改变了什么

对任意查询q和所有key共享的向量c：

`softmax(q @ (K-c).T) = softmax(q @ K.T)`。

这是严格的连续域等价，因为每行logit只减去同一个常数。即使q已经量化，这个结论也成立；不要求获取当前测试Q。因此，可以把“选择哪一个c”变成改善HiF4量化的优化变量，而不是固定减均值后结束。

1. 沿用父版Key平滑/旋转，得到Y；c从当前完整Key的通道均值开始。
2. 用现有HiF4尺度搜索对Y-c做廉价RTN。记e=Q_RTN(Y-c)-(Y-c)，更新`c <- c - sum(w*e)`，共3轮。
3. 普通模式w=1/T。关注加权模式用**冻结校准Q**对当前完整K计算Softmax，沿探针求均值，再混入10%均匀权重；不读取当前Q或V。
4. 只对最后的Y-c运行一次父版GPTQ及原有refinement；不增加GPTQ/refinement轮数。
5. 校准末份保留完整keys。已有refinement的组只验证关注加权候选，最多32个query、两折均改善至少1%；没有refinement的组保留普通/关注加权两候选、64个query和0.5%门槛。逐KV头选择；未采用头保持原输出参数。T=1及测试T>4096回退。

固定本轮量化值时，上述c更新是加权平方误差的精确最优偏移；对公共正定通道度量也成立。但是RTN阶段重新选择了多级尺度，并非完整加权最近邻，**整个多轮过程不保证单调，更不保证线上PV改善**，所以仍需部署一致的输出守门。

新增K状态仅包含模式、启用/加权掩码，以及加权模式需要的校准Q探针。每份取最多16行，最多两份，GQA同组Q头合并。它是校准输入，不是当前测试Q，也不进行跨接口缓存通信。Linear、Q、V的源代码和返回路径不改。

与失败的Q原型搜索不同，本版保留当前完整K，只采样未知query的校准分布；任意偏移在量化前都保持Softmax不变，不引入齐次/低秩表示中的连续投影误差。

## 论文与本题适配的边界

- 重新定向阅读了[SageAttention2第3.1节](https://arxiv.org/html/2411.10958v4)：K去均值利用Softmax不变性；论文的Q去均值还需要在attention内核追加logit修正。本题没有该追加接口，不能直接照搬。
- 本版将K平移进一步当作量化优化变量，采用Lloyd式偏移更新和输入条件化关注权重。这是针对本题的组合推导，**不是声称论文原样提供了该HiF4算法**，也没有移植其GPU INT4/FP8内核或GPU加速数字。
- 本轮另检索了冗余frame/Kashin量化，实施了线性Parseval表示原型；未实现完整Kashin迭代，不计为整篇算法已经落地。
