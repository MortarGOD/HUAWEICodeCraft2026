# v433：有MSE约束的完整64元素尺度树

独立父v422；Linear/Q/K与父校准保持。每个head/64通道块按无约束风险下降上界筛一个token，对其穷举255个合法E6M2值；层级动态规划联合选择8个lv2、16个lv3及64个整数码。每通道允许区间由父全序列MSE×1.05推导，求解时直接限制整数码区间，最终再次验收完整二次风险与MSE帽。每个特征块仅改一个token，避免遗漏同特征跨token交叉项。

给定单token、单SF与层级参数时，最佳约束码是对二次最优点的截断舍入；再逐层取最小得到该token完整合法树的最小代理风险。token上界筛选是近似，不声称全序列最优。计算限制为至多64个块、现有T/工作量/128场景上限，每16个块分批枚举。一次末份两折实际输出守门；不叠加集中度或K quotient，保留与v431的独立对照。

三项机制检查通过：独立Python标量枚举255尺度及每个8元素节点全部层级组合，与DP最小代价一致；固定值区间可精确复原；实际风险下降、全通道MSE帽、合法参数、输入/state/RNG、父Q/K保持均通过。官方6/22自检日志另存，自检完成后立即推送，随后完成两bank及角色压力，结果见下表。尚不能可靠估分；本地枚举开销和筛选结果已记录，线上时间待实测。
