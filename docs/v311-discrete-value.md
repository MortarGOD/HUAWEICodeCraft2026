## 数学目标与实现

沿用上一轮基于PV输出误差的秩一加对角近似：

`J=mean(e)^2 + mean(e²)/T`，其中`e=V−Q(V)`。

乘以T²可写为`F=(Σe)²+Σe²`。单个token的量化值改变δ时：

`ΔF = 2δ² − 2δ(Σe + e_i)`。

保持所有HiF4尺度不变，对每通道所有token并行计算±一个合法档位的收益，选择最负的一项更新；各通道独立，因此可以同时改码。每轮只在收益严格负时接受，signed code始终在[-7,7]。8轮后重新打包，不增加任何state。

这不是全局最优证明：只搜索相邻档位、轮数有限，且优化的是PV代理目标，不是当前未知Q/K对应的真实P。也不是把某篇论文完整算法直接照搬；它是沿用GPTQ/BOA的任务二次误差思想，对本题完整V输入可用条件下的token耦合进行求解。

正式v311只新增`_polish_value_mean`并在V分支调用；Linear、Q/K、校准以及T1逻辑保持v310。释放原反馈的全尺寸临时张量，避免新旧两套工作区同时保留；避免分配整矩阵的浮点方向张量，全通道收敛后提前结束。
