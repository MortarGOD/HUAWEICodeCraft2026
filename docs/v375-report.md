# v375：输出度量消融与单次修正

以v374为源码父，仅追加两个函数覆盖：拟合出的两类矩阵等权合并；动态删去分类和第二次重复修正，只执行一次四轮。仍保留拟合阶段的两类统计，使其精确对应本轮合并消融；不是按样本数加权的全局平均。后续若删除拟合聚类，需要另做对照，不能称等价。

## 同父状态消融

六组0/4/14/19/48/49，每组只构造一份父校准，各实验使用独立深拷贝和相同拟合矩阵，避免父校准波动。各接受行最多四轮，比较：

1. v374按Query选择两类矩阵。
2. 两矩阵平均，同样四轮。
3. 父原始Logit矩阵，同样四轮。

每种方案独立经过同一留出最终输出判据，随后才测试。测试不选择状态。该对照比较包含各方案门控决策的完整策略，不是固定mask的纯曲率因果试验。

30题原始增量：条件化+0.044277181；合并+0.058864053；原始度量加轮数+0.037369768。组14中原始度量无收益而输出度量有收益；组49只有原始度量方案通过守门。结果不支持当前两类条件化优于单矩阵，也不支持把所有收益归于新增轮数；效应随组而异。

v375将合并消融中的两次完全相同修正压成一次。六种形状（D=64/128/256，T=16/129）全部量化参数与未压缩消融逐值相同、合法性通过。它不保证与原始v374逐值同分；合并度量本身改变了策略。

实际v375独立六组30题分数与同父合并消融逐题相同，每侧96项返回/状态检查通过。官方接口6/6、格式22/22通过。上述是实际提交文件验证，不仅是研究函数结果。
