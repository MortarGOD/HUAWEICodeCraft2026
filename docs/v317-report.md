# v317：固定解码权重联合优化＋等输出提速

## 版本边界

父版为v315（线上20189/259秒）。Attention函数、参数、GPTQ/refinement/温度策略保持v315；不带入v316线上零增益的坐标银行。升维与方阵动态搜索预算不变。正式单文件为solution/solution_v317.py，入口solution/solution.py与之相同。

## 优化内容与删除依据

| 改动 | 依据 | 精度保护 |
|---|---|---|
| 升维固定Q(W)与encoder完整逆映射交替 | 前轮两套checkpoint代理和未缩小权重均改善 | 输入宽度≤2048用4轮，2048<I≤4096用3轮，I>4096只用清理父路径；只比较最终候选与父候选，末份校准奇偶行均改善0.01%才采用 |
| 唯一subspace候选提前返回 | 旧函数最终无条件返回唯一subspace候选；后续数轮Q(A)求解和残差权重候选不影响返回值 | 清理消融Q(W)、实际被读取state和动态返回逐项一致；无候选/方阵仍保留原有选择 |
| 删除旧global-policy校准调用链 | 降维入口已提前返回，剩余O≥I不可能达到32倍压缩；最终精确目标路径不会读取旧global-policy、teacher-bank或其低秩状态 | 不删除构建初始Q(W)所用的反馈量化、配平或polar；清理消融逐项对照 |
| 降维每级只量化自己的64通道块 | 各残差级占据独立、连续且64对齐的块，后级不能改变前级参数 | 全50题清理消融逐项相等；另测非整数比例和8级残差；最后一级不再计算无人使用的残差 |

前三类中的旧global-policy不是“历史上一直无效”，而是**当前精确目标路径覆盖后，其校准产物不再被读取**。不得据此否认v32等历史优化的贡献。v316是另一个有直接线上零增益证据的删除项。GPTQ没有删除。

新权重迭代仍使用上一轮研究的`B*=W'P^{-T}`，量化后重解P；中间不构造64/4块搜索统计、不评估中间检查点、不枚举未胜出的ALS配置。只在最后编译搜索统计并执行父/候选两次守门。校准末份用于选择而非测试；测试前Q(W)已固定。父算法本身使用过全部校准样本，因此该守门不是整套算法完全独立的留出集。
