## 本轮改变及可证伪解释

v387虽然在实际量化操作数上计算Jacobian，但OJ后还有K平移和温度，后续会改变拟合工作点。本轮不加残差训练或动态轮数，只改变已有模块的条件优化顺序：

| 版本 | 完成共同V处理后的次序 |
|---|---|
| v387 | OJ → KT → TS → TEMP |
| v385 | KT → TS → OJ → TEMP |
| **v390** | **KT → TS → TEMP → OJ** |

OJ表示Q输出度量拟合及真实输出守门；KT/TS为K平移与加权Lloyd选择，TEMP为温度选择。各模块一次，不计算两套完整组合竞赛。最终OJ看到已选K/V/温度，其后不再执行改变K/温度的阶段。

这是工作点一致性的组合实验，不是新增论文算法或完整全局最优化。也存在相反作用：前面的K/温度没有看到新的OJ-Q，可能作出较差选择；OJ只对本组合的前态验收，不保证结果优于v387。不能把之前两次重排的+65/+60分相加当收益预估。
