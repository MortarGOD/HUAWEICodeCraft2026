# v341/v342：条件注意力矩与交叉残差

最新线上：v34120720/252秒，相对20803.75精细基线净退化83.75。该结果与本地正收益不一致，未获得部署增益支持。没有逐题信息，不能确定损失来自哪些头或长度；不将后续候选叠加在v341上。

## 方法与边界

父版v324，Linear/Q/K保持不变；两版独立，不需要其他solution文件。

校准用实际部署Q/K生成Pq，原始Q/K生成P。通过当前V可见的通道、能量、位置特征拟合注意力均值a、平方均值b，以及Q/K量化交叉梯度。最后一份校准数据分两折，只有两折输出MSE均改善0.5%的KV头采用。位置特征是待验证假设，不是已知线上分布。

v341用H≈aaᵀ+diag(max(b−a²,0)+ε)；v342再加入受限的预测交叉梯度g。原生HiF4尺度固定，优化eᵀHe+2gᵀe，每通道每轮只改一个token，8轮。代理为PSD，单坐标变化量精确可算；但条件均值近似遗漏了非对角协方差，代理下降不保证真实输出下降。

测试阶段仅用当前V和冻结CPU状态，不访问当前Q/K，不共享模块全局测试数据，不读写本地文件。T不在4–4096或V超过4194304元素时回退父版。Linear权重路径完全冻结。

## 初筛及验证

六组30道本地测试，研究版原始分增量：仅均值+0.138557，二阶v341+0.140844，交叉v342+0.138180。组0五道均改善，其他组大多未采用；没有普遍大收益证据。该银行使用checkpoint衍生权重和建模激活，并非真实模型前向采集，不能把它直接换算为线上分数。

各版本144项数学/强制启用接口检查通过：显式H与紧凑目标一致、PSD、单坐标增量一致、1/2/8/16轮代理不增、码范围及格点合法；d64/128，T1/4/17/129/1025/4097，零输入，未选头逐项回退，独立加载，输入/state/RNG不变。各官方mini22/22通过。父代码AST除模块文档完整一致，静态禁止模块及动态加载调用扫描通过。

依用户流程，先推送通过自检的版本（7dcbcac），再完成实际文件30题回归与串行接口计时。回归增量与研究实现逐项一致，实际校准状态合法、Q/K状态相同，所有动态V输出合法。不是完整860检查。

六组共享父校准的增量Attention计时：v324 53.094秒、v341 59.656秒（+12.36%）、v342 59.305秒（+11.70%）。校准训练与V动态均计入，共同Q/K计时复用，不是三份完整300题独立运行。以内核比例套246秒父版，条件情景约275–277秒；但Attention占整场比例未知、本机线程与线上不同，不能当作可信区间或280秒保证。工作锚点仍是20803附近，不将0.14原始分线性外推到250题，也不承诺线上+50/+200。

22000目标尚未达到，建议先v341，再v342区分交叉梯度作用。组0中学习均值的L1误差反而高于均匀权重，故不能把改善归因于成功预测注意力分布；新增均匀权重消融定位离散搜索器本身的贡献。
