# v350额外校准性能归因与等价精简

2026-09-05；未修改已发布solution或Linear。

## 已实现的等价精简

`attention_factor_fast_guard.py`重写factor分支的校准守门，删除旧moment分支遗留但未用于决策的交叉误差梯度、二阶概率统计、预测概率L1诊断；量化概率只计算一次。拟合、32query选取、最终PV目标、两折0.995守门、8轮搜索、返回state内容均保留。AM_DEBUG不再包含probability_l1/uniform_l1，仅是离线诊断字段变化。

反馈bank6组+协方差bank6组：首轮以及三轮交替顺序测量，所有校准返回state逐值相同、输入parent state不变；每组5个实际动态V输出逐值相同，共60例。该验证不是全形状等价证明或新版本官方自检；优化尚未并入独立提交文件。

## 计时结论

首轮存在明显波动（某组精简路径单次变慢），因此保留首轮数据，不用单次最好结果。三轮对每组取中位数再求和：额外校准3.458440→3.369701秒，−2.5659%。这不是完整提交耗时提速2.6%，不能据此承诺v350进入280秒预算。

嵌套函数计时为inclusive，不能相加。三轮原始守门累计计时中，K动态量化占约55.76%；它被模型拟合及留出验证分别调用。删除小型统计不是主要性能解法。

## 下一步

保留等价精简作为待整合补丁。下一试验审计父校准是否已算过与新分支输入、量化state完全相同的K结果；如有，设计仅存活于一次校准调用的复用，并验证输入身份/完整state/返回值不变。若state不同，不能仅按张量指针缓存；也不能把缓存带到测试阶段、改变独立接口语义或未经核对复用中间候选。

若无可复用结果，再比较采样校准的精度/时间，而非直接删搜索轮数并声称无精度影响。尚未实现复用方案，没有新的线上收益/时间结论。
