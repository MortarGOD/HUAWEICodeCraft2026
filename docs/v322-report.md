## 新算法与原来的区别

v321从当前K的普通通道均值开始，按关注权重做3轮RTN偏移更新，再运行一次GPTQ。本版增加一个独立候选：

1. 从冻结校准Q探针和当前完整K得到关注概率，混合10%均匀质量，得到token权重w。
2. 起点直接设为 `c0 = sum(w * Y)`，Y为原平滑/旋转后的当前K。
3. 做8轮 `c <- c - sum(w * (Q_RTN(Y-c) - (Y-c)))`，随后每个候选执行一次原GPTQ/refinement。混合启用头需要同时计算父版回退与新候选，开销已计入配对计时。
4. 不局限于v321原先选择了平移的头；针对每个KV头，与v321实际输出比较，最后一份校准的两折PV误差都降低0.5%才启用。未采用头完整回退参数，T<4或T>4096回退v321。

不是修改输出实数后绕过HiF4编码。所有返回仍是原格式的整数码与合法多级尺度；独立K接口仅消费当前K与冻结校准探针，没有读当前Q/V的通道。

任意c都保持未量化Softmax不变；改变起点会影响多级离散尺度及舍入落点。8轮并非数学最优或单调收敛保证，而是本轮有限实验支持的配置。24轮更差的结果也保留。
