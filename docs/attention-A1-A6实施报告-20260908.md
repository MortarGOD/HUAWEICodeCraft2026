v431/v432 的“最优”仅指给定二次代理中所选节点的未约束码最优，再用 MSE 帽筛选，并非求解全部约束组合。v433 把约束转为每通道合法码区间，完成固定 token 的完整树最小化；它的 token 筛选和全序列有限更新仍不具全局最优保证。新温度和子树策略只写入自身 V state；动态路径不读取真实 Q/K，不依赖跨角色缓存或调用顺序。
