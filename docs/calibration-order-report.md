## 源码机制与限制

v324校准约3040行起明确将末样本留作守门；多个后续guard也读取samples[-1]。`_vr_fit`约4039行选取前面最近的有效序列，`_ts_guard`约4289行选取samples[:-1][-2:]生成query原型。这些路径使排列同时改变训练子集、验证样本及其长度，不是仅浮点累加次序。此处是针对已读路径的解释，不是全文件穷尽归因。

该bank校准序列按长度128/256/512/1024/2048排列；真实线上Attention长度分布未知。当前数据是建模激活，不是真实前向采集。本轮不改变生产顺序、不根据本地测试挑选较优排列。
