# v398之后：优化力度复盘

用户反馈v398=21184/267，并质疑近期是否真正大力度优化。结论：有算法含义变化，但主要在v387结果附近做小预算修补，实际覆盖和采用范围小，不能将大方向名称当作大力度实现。不是已经把大搜索空间优化到极致。

v395最多128个64通道块、两棵尺度树、8维宽4 beam；v396/398最多256个head-row、两轮每次1/4坐标更新；v397只有Q度量×K平移四种已有组合，17组代理中14组直接预算旁路。前两类绝大部分仍固定父版尺度/变换与码字邻域，后者也不是广泛组合优化。

本地采用：v395、v396、v397均0，v398只有1个Q头。线上触发不可见，不能据总分推断全部回退，但本地证据足以说明提交前没有广泛生效或强度证据。版本完整复制父源码并追加助手不代表算法结构重做。

失败原因分层：已验证的是覆盖小、局部代理收益不转化为测试收益、校准常回退；尚未证实的是线上具体输入分布和主误差来自Q/K/V哪一侧。目标错配、校准序列间不可迁移、父版局部近似已较好都仍是解释，不能唯一归因。

修正后研究顺序：先用同一父输出做Q/K/V单侧理想替换与交互误差诊断（仅本地，不伪装成可提交方案），分清哪一侧确有足够空间，再选对应的结构性替换。Q侧考虑量化前的度量/变换结构，K侧考虑当前整序列量化目标和有效表示，V侧考虑整个概率加权重构，而非继续给Q邻域多加少量候选。均须先核对历史实现，不能称这些方向全部未做过。

新版本的报告应同时给出：实际覆盖输入条件、改变的元素/块/头比例、候选产生与采用比例、修改后真实输出误差和耗时。全回退的方向可以按用户要求作为未知线上探针提供，但应标低优先级，不再把它作为冲刺大突破的主推荐。需要比较的不是新增代码行数、论文名称或版本数量，而是有效搜索空间和可迁移收益。不是简单撤掉校准保护或放宽全部预算；当前300秒约束仍需遵守。
