# 保留V后处理的宽尺度短trace复核

2026-09-08，父v435，使用参考qwen3_5_35b_a3b_v1的50个T8测试样本。本轮不修改竞赛源码、不发布v440。

先纠正历史边界：docs/value-scale-grid-preserved.json已经完成了旧父版保留V后处理的宽尺度实验，原始质量增量仅+0.004404012，16和24候选相同。本轮不把宽尺度称作新方法，只刷新当前父版与新增数据来源。

每组只校准一次435，Q/K保持同一输出。离线串行替换V内部_dyn_table的6个尺度候选为16个合法候选（指数偏移−1/0/1/2、四个E6M2尾数），保留其余所有V均值/核/残差后处理；不重新校准、不调用接受门控，不把去掉后处理产生的差值当尺度收益。该临时hook仅存在于诊断脚本，不能直接作为提交中的可变全局分派。

结果：全部50次候选格式验证通过，state保持不变。30题输出确实改变，23题改善、7题退步、20题不变。逐题最终输出MSE比值平均0.998790615，原生逐张量MSE比值平均0.998486633。后者逐题不增检查通过，但后处理后的最终输出并不保证逐题不增。它们都是比值的平均，不是线上得分估计。

结论：这组数据不支持把扩大SF网格作为主要突破口，停止增加网格尺寸或为此单发版本。下一研究方向为离线学习量化策略，使用公开真实来源Q/K/V构造训练目标，冻结一个小型共享策略；部署只依赖当前V与自身量化特征。训练/验证/测试分开，不使用测试集选模型，不在运行期读取真实Q/K或缓存跨接口数据。该策略尚未实现，须证明实际合法量化前向、跨样本泛化和成本，不能仅报告代理训练损失。
