# Attention交换对称风险：待验证的低开销方向

这是数学推导/实验计划，不是论文原文、已实现版本或线上收益声明。

当前均值搜索目标(sum e)²+λ sum e²固定λ=0.01。它主要对应接近均匀的注意力；如果真实注意力集中，校准拒绝可能是风险模型错误而非门控过严。

设单行概率p长度T，sum p=1；假设token置换后的二阶矩交换对称，记s=E[sum p_i²]。则

- 对角 E[p_i²]=s/T；
- 非对角 E[p_i p_j]=(1-s)/(T(T-1))；
- H=α11ᵀ+βI，α=(1-s)/(T(T-1))，β=(Ts-1)/(T(T-1))；
- T≥2且s<1时，缩放后目标是(sum e)²+λ sum e²，λ=(Ts-1)/(1-s)。

这保留概率归一化产生的非对角关系；不是单纯把diag方差加到均值外积。均匀时λ=0，集中到一个token时趋于纯MSE。s由校准实际量化Q/K概率统计，能形成每头标量参数，不需要V到概率的学生或测试T²矩阵。

限制：真实token通常不交换对称（sink、位置、语义簇等）；s随T与数据分布变化。该模型也没有补齐Q/K量化交叉残差。不能因为H是PSD就宣称真实输出改善。λ截断、跨长度迁移必须单独验证。

验收：用枚举置换的小T概率向量验证显式H、PSD及紧凑目标；在拟合校准序列估计λ，在另一校准序列筛选，记录集中度与实际输出误差；与λ固定0.01及纯MSE对照。测试分不参与选参数。先诊断校准覆盖，再决定是否制作提交版本。
