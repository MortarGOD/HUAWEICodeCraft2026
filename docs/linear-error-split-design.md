## 两条独立恒等式

用B表示实际解码权重（O×I），Y为官方反量化输入的FP32 `A@W.T`，Z为当前HiF4激活的实际解码值。所有分解内部使用FP64，实际评分严格复现evaluate_local.py：保留参数解码dtype进行乘法，再用FP32计算MSE；当前父版为BF16解码乘法。精确解码乘法的连续上界不是最终舍入评分器的严格上界。

1. 对B做带阈值的FP64 SVD（若行支持不相交，使用可验证的正交行闭式解），得到输出空间投影P及连续解Z*。

   `||Y-ZBᵀ||² = ||Y-YP||² + ||YP-ZBᵀ||²`，另报告数值正交交叉项与闭合误差。

   第一项是固定B的输出空间误差；第二项同时包含HiF4不可避免的离散误差和未收敛搜索，不能全称为可恢复收益。数值秩截断被明确披露，不伪装成已证明的精确数学秩。

2. 捕获动态求解器实际收到的教师T。令D=T-Y，R=T-ZBᵀ：

   `||Y-ZBᵀ||² = ||R||² + ||D||² - 2<R,D>`。

   教师偏差不能直接加到第一条分解中，也不能因教师偏差存在就认定它贡献全部缺分。降维直接输出路径单独重建教师，检查其是否等于原始目标。

另报告原评分器dtype输出计算相对FP64解码乘法的有符号误差增量，以及求解器内部携带B与实际Q(W)解码值的偏差。

FP32 MSE归约相对FP64归约的微小差异也单独列出，使实际评分误差与全部分量数值闭合；它不是新的算法损失。升维/降维均按实际O与I关系分类，不按模型层名判断。

## 合法搜索例证

复用已有单坐标搜索，固定当前参数/权重，分别针对原教师T、真实目标Y执行小预算修正；并测试把连续Z*直接HiF4量化。逐个调用self_check验证这些输出格式，记录它们对真实目标的误差和保留父候选后的逐行最低误差。

这些是抽样行上的可恢复收益例证，不是全局最优或完整测试收益。例证不替换当前方案返回值、不修改Q(W)、不写入state。未将连续Z*冒充合法量化结果。
