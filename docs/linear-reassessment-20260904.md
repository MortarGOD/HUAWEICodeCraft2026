# Linear计分纠正后的路线复核（仅规划）

## 本轮边界

用户要求先审视本地代码和论文，收到v323线上反馈后才开始开发。本轮不新建版本、不改变solution.py、不跑新算法或调参实验。以下是源码与已有实验支持的候选，不是已经验证的改进。

当前Linear分项按历史隔离链推算为4397/5000，距满分603（12.06%）；v322 Attention为20803−4397=16406。旧记录中的9397/10000、Attention11406均作废。v285为4366，v304增12，v317再增19；此后Linear冻结。分项仍是差分推算，不是官方逐题回执。

603是分数上限差额，不是已证明可以恢复的收益。按每题100×(1−MSE/MSE_STD)且无失败罚分，当前50题误差比之和为6.03，平均为0.1206；不是原始输出相对误差12.06%，也不知道误差集中于哪些权重。相同加分目标比原先理解更难：+200需要消掉约33.17%的现有归一化误差，而不是小调参。

## 1. 当前生产路径核对

源码以solution/solution_v323.py为准，Linear继承v317。

## 2. 数学问题必须分清

设W、B均为O×I，B为实际解码后的固定Q(W)，Y=AWᵀ，Z为实际合法解码后的Q(A)。测试目标是

`min_{Z∈HiF4} ||Y−ZBᵀ||²`。

固定B时，关于每行Z的精确曲率是2BᵀB，不是2AᵀA；当前输入主要改变目标/梯度，B固定时可以提前编译曲率信息。

令Π_B=B(BᵀB)†Bᵀ。在精确实数乘法下：

`||Y−ZBᵀ||² = ||Y(I−Π_B)||² + ||YΠ_B−ZBᵀ||²`。

第一项是固定解码器的表示空间误差，第二项包括HiF4离散误差和搜索未充分误差。O>I时第一项可能明显；O≤I且B满行秩时连续空间可完整覆盖输出，但合法HiF4误差与评分dtype误差仍存在。

因此docs/max_opt.md关于“有完整W就不存在权重误差、可普遍简化为量化Y”的表述不能照搬；只有可合法构造足够输出承载维度等条件成立才可如此。测试时任意重选Smooth/rotation也不能不补偿固定B就保持等价。论文自定义codebook、混合精度旁路不能直接作为官方HiF4输出。

已有v316误差拆分在缩小checkpoint权重配建模激活上：空间项约41.39%，空间内项约58.53%；不能拿它分配线上603分，且v317改变过B，需要更新诊断而非复用比例。教师偏差当时较小，也不应凭感觉提升为主要矛盾。

## 3. 优先级与真正的增量

### P0：重做当前版本的可恢复误差诊断（收到回执后）

按每个权重报告：实际评分误差、固定B连续空间误差、合法局部搜索仍能消掉的误差、教师/最终dtype差异，以及各段耗时。保留每题官方基准误差作归一化分母，不能只看绝对MSE、目标能量或总token数。

特别覆盖I=4096、I>4096、O>I及实际长激活；当前代理为checkpoint权重配建模激活，不冒称真实前向激活。少量高成本连续解只在诊断中用，不进入提交。不预先断言线上剩余误差全在up或不存在square。

### P1：固定合法Q(W)与实际离散Q(A)的联合优化

依据AQLM的离散码分配/连续参数交替，以及AdaRound局部重建目标。保留HiF4表达，不引入AQLM自定义码本。

当前v317的循环主要是B←HiF4(W'P^{-T})、P←连续正则LS，最后才执行一次真实部署筛选。这与每轮获得实际Z_i=decode(Q(A_i))，再解固定B的加权重建目标不同。

计划以当前实际Z构造Q(W)残差方向，用低秩/双空间校准更新限制成本；每次权重候选量化后要重编译必要统计并用真实动态求解器评估，不能只奖励连续损失。目标按五份校准各自基准MSE与元素数归一化，避免最长/最高能量样本主导；采用前份拟合、末份验证及跨份稳定性检查。父校准已看过末份，不能宣称整个流程完全独立留出。

区别于旧研究：此前已试过少量ALS配置、低秩谱修正、完整逆encoder，不是“从未做过联合优化”。下一次必须单独比较评分归一化、离散编码参与、低秩方向三者；如果只是原ALS增加轮数，不算新方向。I>4096覆盖只能通过成本受控方案扩展，不能直接解除宽度限制运行完整立方复杂度solve。

预期对象：降低空间项并兼顾可量化性。历史v285 +10、v317 +19支持方向存在收益，但不支持本次+200预测。

### P1：卡住块的联合舍入，取代部分固定微组循环

依据AdaRound二次交叉项和AQLM小beam/增量目标。先测完整64块拒绝时是否存在单组或两组显著有益改动；仅对这种块做top-k局部组合。候选可以试一个/两个4通道组、共享8通道尺度或小宽度beam，保留完整交叉项和原输出候选。

令r=y−xBᵀ，新向量x+d的损失变化为`−2d(rB)+d(BᵀB)dᵀ`；不能只累加各微组对角损失。按该可获益信号分配预算，而不是所有块一律20/5轮。

旧v244已有顺序微码，v255已有并行完整块守门，v260已有lv3联合枚举，v289已有小beam弱收益。真正要验证的是当前强父版的拒绝修复率与单位时间收益，不重做全量顺序扫描或用beam名称包装旧策略。若几乎无可恢复拒绝，则立即降级。

### P2：跨块误差反馈作为替代初值/替代迭代

QuIP#第4.1节是block-LDL三角反馈，不是把Newton块从64扩大到128。GPTQ的lazy更新提示可把顺序局部计算与批量外部更新分开。

先诊断跨块相关和局部陷阱，再试受限带状/少量相关块反馈，生成一个HiF4合法候选，替换部分现有搜索。块内梯度可按Gram更新，积累差分后一次更新输出残差；跨块必须同步所需项，不能因为延迟更新使用过期梯度却声称等价。

旧v264/265是down超块Newton，v267 PCG仅+6却增加119秒；v273连续映射仅+9/+17秒。原down已换直接编码，不能拿这些收益或成本直接外推当前up。全量在线PCG、扩大稠密白化仍低优先级。完整LDL在4K+的内存/立方校准成本必须先测；不直接搬E8P或其理论最优保证到HiF4。

### P3：降维残差位分配与解码尺度

借鉴残差/加性量化，在合法固定B框架里按校准第一/二级实际残差收益分配不足整级的列，比较共享尺度变化后的联合收益；必要时校准固定radix选择，而不是测试改B。现有布局按RMS选择，不一定最优。

本地降维已近满分，v304整个替换线上只+12。先诊断再投入；不能把其余603分默认算给down。也不因局部少量列重新引入严重稀疏小循环。

## 4. 不作为首轮主攻

- 单纯增加所有迭代轮数：v255→v256旧集仅+20/+45秒，现预算更紧。
- 单纯增加旋转/尺度/多起点：v289/v290已有弱收益证据，需有新的误差诊断才重开。
- 只改教师为更高精度：值得数值核对，但旧分解不支持主要收益来自这里。
- 把QuIP#理论界当HiF4可达满分保证；或把连续最优值当合法可提交答案。
- 通过局部数据重加权强行拟合603分；原代理大收益多次没迁移，必须保留不一致结果。

## 5. 回执后的执行顺序及停止条件

1. 先记录v323并锁定已验证Attention父版，再更新当前Linear误差诊断；不同时改变两部分精度策略。
2. 空间项主导则先P1固定B；可恢复离散陷阱主导则先P1局部联合舍入；P2由跨块证据触发。
3. 新候选相对父版、连续方案及旧同类实现做消融，逐权重记录归一化收益、采纳率、拒绝率、时间和宽度覆盖。
4. 校准重编译时间与五次测试一起算，使用actual shapes；新策略应替换低效工作，避免叠加。300秒硬限/280秒内部目标，实际余量等v323回执。
5. 源码实现、格式自检、推送、实际文件本地回归/估分按既定流程执行。本轮不执行这一步，不创建v324；Humanize不可用，以上为手工验收规划。
