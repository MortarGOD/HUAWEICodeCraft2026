# v357：自适应风险因子空间的PSD度量学习

## 方法

父版固定为v353，Linear、Q、K及V的HiF4编码/8轮离散搜索不变。对每份训练校准激活，先得到v353的16个V条件概率因子`A`，再把全部部署Q/K产生的概率行`P`最小二乘投影到`A`的行空间：`P ≈ C A`。

由`CᵀC / query数`得到16×16 PSD风险度量；两份校准平均后，与v353的单位度量按25%/75%混合。动态阶段用Cholesky因子变换`A`，严格满足变换后`BᵀB/16 = Aᵀ M A`。因此保留完整16个自适应方向，不增加风险rank，只增加一个每KV头16×16乘法。

新增状态只有有限float32 CPU Tensor `metric_transform[KV头,16,16]`；测试阶段不读取Q/K，不改变接口。

## 选择、留出与正式回归

- 初筛12组：+0.011756，8升/1降/3平；covariance六组全部正向。
- 完全未参与参数选择的20组：+0.004539。feedback为3升/0降/7平；covariance微小正负混合但合计仍正。
- 正式实际文件26组、130题：+0.015230，95项结构、Gram恒等式、状态与配对检查通过。

相同26组上v356为+0.013793，因此v357本地略优，并避免v356把动态rank由16增到20。代理仍是checkpoint投影权重与建模激活，不能把增量线性换算成线上分数。

## 性能

六组正反顺序计时：

- 首运行位置：v353 28.049秒，v357 27.799秒（−0.9%）。
- 次运行位置：v353 25.156秒，v357 25.410秒（+1.0%）。
- 同位置动态QKV总计约+0.1%/+1.2%。

冷启动仍显著，但顺序配对说明新增度量变换接近等成本。线上96核和完整300题仍需实测；参考v353条件情景，v357预计比v356更安全，不承诺绝对耗时或达到22000。
