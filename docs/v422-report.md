## 单一改动与依据

仅替换 Linear 的 `_pair_polar_factorization`，原实现保留为异常回退。父版使用 W 的全宽温和白化；新实现使用每 64 通道、最多两次 Householder 反射。既有 Smooth/Hadamard、权重求解、encoder、动态搜索和 v421 前缀搜索预算保留。AST 比较确认除此处重命名和两个新函数外，其余顶层代码一致；Attention、down 路径和默认入口保持原样。

来源是固定参考提交 `test/base_1.7@52b490459d117c7982d2ed7d14cbe791a756c193` 中 `_peak_suppression_reflectors`（参考 `solution/solution.py:221–267`）。参考实现按激活单侧二阶矩抑制谱峰；本版把 A 和 W 的块二阶矩分别按平均对角归一化，再等权相加。前两条突出谱方向依次映射到全正、正负交替的等幅 Walsh 方向，后一个方向同步经过此前反射。有限样本经验门槛沿参考形式，样本数取 A 行数和 W 行数的较小值；这不是严格统计显著性检验。

[DuQuant 原文](papers/quantization/text/DuQuant_2406.01721.txt) 第 270–324 行支持块旋转、重排与逆变换配套的思路；其附录旋转构造与本版不同。本版联合二阶矩及确定性谱方向是任务适配，不称完整复现 DuQuant，也不是原参考函数的直接复制。

先将理想反射乘积 R 冻结为 BF16，再将同一矩阵展开为 FP32 的 F，计算 `A'=AF`、`W'=WF^{-T}`；互补权重通过 64×64 solve 得到。返回 state 中冻结的变换与拟合使用的 F 一致。BF16 的 F 不再严格正交，但配对逆变换保持连续乘积的数值一致性。无活动方向则 F 为恒等；不支持的形状、非有限或数值异常回退原 polar，无跨接口缓存。

事前假设是共同谱均衡能改善 HiF4 量化并减少全宽变换成本；替代解释是原 polar 的条件化更重要。原 polar 有历史旧口径正向证据，旧实际离散 decoder ALS、variable projection 等方向也已有负例，此次没有把它们换名重做。

## 验证与真实生效范围

[机制测试](../tools/test_v422.py) 10/10 通过，覆盖实际冻结矩阵的配对乘积、A/W 双侧尖峰、尺度归一化、零值、非有限及异常回退、输入/state/动态 RNG、新模块重放和改动范围。合成双侧尖峰案例中，联合矩阵最大对角由约 31.2327 降至 1.00008，BF16 变换正交性最大误差约 0.0004066；合法量化后输出 MSE 为恒等 205.305、父 polar 77.112、块反射 16.474。这些只是机制样本，不能替代模型数据结论。

官方六接口 6/6、格式 22/22 通过。候选通过临时目录唯一 `solution.py` 调用原始 `self_check.self_check`，没有覆盖默认入口。推送后两套配对验证分别通过 160 和 80 项检查，包括合法输出、输入/state 不变、动态 RNG、跨样本及新模块重放；另有恒等消融 16 项通过。父校准本身会消耗 RNG，各版本从同一校准 RNG 起点执行，不把历史校准行为写成 RNG 不变。

active 的五个 up 组共 48 个块，仅组 0 的 6/8 块产生非恒等变换；其他 up 组为恒等。另一套数据所有 up 块均为恒等。两套均无原 polar 异常回退。因此，大量结果检验的是移除全宽 polar 后的表现，不能把所有退化都解释为“反射本身有害”。down 的 25 题校准、参数和输出与父版一致。
