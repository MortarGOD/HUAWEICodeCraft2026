# Attention 部署一致守门与完整坐标系重选

> 后续组47重复性审计发现本机父校准可漂移。本文两次完整回归的等价结果仍是当时实测，但不代表任意重跑都确定；后续消融已改为共享一次父状态，详见 `docs/attention-frame-causal-research.md`。不得把不同父实现之间的小差值全部归因于新候选。

状态：线上最佳 v314=20071/241 秒，v315待回执，22000+未达。本轮研究不修改生产或Linear，不发布新编号。完整feedback_v2回归净增2.462152原始分，仍不能作为线上增量预测。

## 1. 源码确认的偏差，不等同于已证实的线上失分

`solution_v314.py`的早期校准存在三处顺序/目标差异：

- `_qks_maybe` 使用抽样Q/K/V、普通快速量化和原始V决定通道平滑尺度；不在完整GPTQ路径下重新比较“保留尺度/不保留尺度”。
- 旋转选择也在普通量化下进行，之后才拟合并启用GPTQ。
- GPTQ开关守门保留全部key但用原始V；refinement守门抽样key并用原始V。Q行独立只允许抽样query，不能证明抽样key后softmax输出不变。

末尾joint变换/V kernel会再做完整key及真实量化V守门，但它只比较已经接受的上游平滑/旋转坐标系及其密集配平，不会撤销早期平滑。它也要求父版已启用GPTQ。

这些偏差提供实验动机，但不能据此断言某个线上版本失分都由守门造成。GPTQ恢复的线上大收益仍有效。

## 2. 先检验算法开关

固定最终父坐标和V，对Q/K建立parent、GPTQ开/关、refinement开/关的候选；已有U/H逐值保留，缺失矩阵才在部署坐标由calib[:-1]重建。保持原来只用T≤1024校准统计的覆盖，不把校准覆盖变化混入本轮。

校准评分始终保留所有key及原始序列的动态预算，使用公开动态返回值解量化后的结果。按KV组联合选择共享K选项与组内各Q头选项。比较raw-V与deployed-V目标，两折query总误差都改善0.5%才可采用。

关键预算约束：若最后校准T>1024，refinement在该样本上不执行，不能根据它改变短T refinement策略。因此这些候选全部保留父rf值。covariance_v1的最后校准T=1024可实际比较rf；这是代理设置，不是线上长度事实。

三批各20题（feedback组1/5/14/49、7/19/27/36，以及covariance组1/7/16/49）中，raw-V/deployed-V均全部保留父候选，分数增量0。此结果不证明所有线上组都如此，但不支持仅换GPTQ开关就能获得大幅收益。

## 3. 扩大到完整配对坐标系

候选保留原父版，并新增：无尺度/校准尺度 × 无旋转/seed0旋转。每个坐标系在前四份可用校准中重新拟合H/U，执行实际GPTQ；refinement标志沿用父版，V输出不变。校准尺度直接复用已有 `_qks_fit`，不再预先用旧RTN守门拒绝。

Q/K必须按同一个KV组一起切换坐标系，绝不将不同坐标系的Q、K任意组合。原型state携带候选列表和CPU整数choice；动态调用相关父量化器，再按完整64通道块合并合法元数据。初版有重复计算；后续快速实现只计算真正被选择的候选，校准仅量化被评分query，仍保留完整key及原T预算。

### 额外守门限制也需要验证

group14的新坐标系在实际量化V下，两折的总误差比为0.88522和0.91310。但其中一折一个Q头的误差比为1.04958，因此被本轮原型额外设置的“逐头最多退化1%”拒绝。

官方最终MSE并不要求每个头都改善。移除这条额外限制后，仍要求两折总误差同时改善，新候选通过；它的五个测试原始分增量依次为0.0007315/0.0071658/0.0281660/0.0471001/0.0980425。这不是删除所有守门，也不保证其他样本泛化。

group19在严格守门下就采用同类坐标，五个测试增量为0.0061092/0.0107187/0.0257628/0.0344720/0.1097116。

### 收益具体来自什么

两组都选中 `scale0_rot1_gptq`：保留seed0旋转/GPTQ，撤销通道平滑并重建相应统计。源码实测父状态表明：

- group14原来有通道平滑＋seed0旋转＋密集joint变换；新候选同时撤销平滑和密集joint变换。
- group19原来有通道平滑＋seed0旋转，无密集joint变换；新候选撤销平滑。

因此这两组收益不是“增加GPTQ轮数”或“从无旋转改为旋转”。早期在RTN路径选择的平滑，未必适合最终GPTQ坐标系；之前只在父坐标之后学习正交变换，也不能等同于允许撤销非正交的通道平滑。新候选还重建了Gram，group14还同时移除密集变换，所以尚不能把净增益全部归因于单独的平滑参数。

## 4. 验证与限制

`test_attention_gates.py`通过：8个动态格式检查，覆盖Q/K、GQA、T=1/129/1025、混合候选、未启用及单token父版逐值回退；已有矩阵不改，零Gram不能凭空启用GPTQ。选择器验证两折都要改善、非有限值拒绝、Q/K坐标匹配，以及可取消单头保护而不可取消总误差两折保护。

改变最后校准三角色数据，不改变新Gram或坐标候选参数；calibration输入及全局RNG不变；候选state通过公开类型检查。小矩阵反例明确展示删除key会改变softmax输出。

候选选择是保留父版的顺序改进，含0.5%门槛，不宣称枚举所有变换或全局最优。所有折来自同一最后校准序列，不等于独立序列验证。研究计时包含参考输出/格式检查，部分进程并行，不能折算96核线上时间。
