## 原生尺度初查

源码确认：固定sf时，原V量化的lv2/lv3树已按加权MSE做条件最优选择；sf只枚举6个E6M2候选。增加到16/24候选后，六组未加后处理的原生逐元素MSE降低约0.29%–0.73%；24相对16没有额外收益。逐测试格式和MSE不增检查通过。

目前三个替换候选（最近舍入6、16、24）均未通过真实输出校准，30题最终输出回退父版同分。但这次替换没有保留父版V的全部均值/核/残差后处理，不是“只扩大原pipeline尺度网格”的严格消融，不能将零分结论扩大到后者。

下一步：保留父V后处理的尺度网格对照，避免把去掉后处理造成的损失归因于尺度。先原生参数、最终输出和时间一起检查；即使候选误差降幅小，也不直接判线上必然无效。当前没有新的提交版本，目标22000未完成。
