# v323：补齐长序列 K 平移覆盖

## 决策

父版v322线上 **20803分/251秒**，相对v321 **+160分/+5秒**。本轮继续优化Attention，保留Linear。多种新数学目标在固定代理上没有足够收益，最终候选落实的是已有有效K平移算法的长序列覆盖，不冒称新论文公式已带来确定加分。

旧版在测试或末份校准超过4096行时关闭K平移。新版本把覆盖延伸到 **16384行**，并增加 **8388608个K元素**的工作量上限；超过任一上限回退。长序列只做 **3轮偏移更新**，不是把所有输入的搜索加到8轮以上。

当校准和测试均不超过4096行时保持v322；如果校准本身变成长序列，选出的K状态可能影响其短测试，不宣称这种情形也逐题相同。Linear/Q/V算法不变，新校准只改变K状态，查询仍抽32/64行而保留完整key。长校准缺少有效Q GPTQ状态时回退。

## 论文与代码复核

- 重新定向阅读DFSQ Simplified的条件平方敏感度定义及向量输出式(30)，以及Softmax论文命题2和常量零空间推导。它们支持面向任务的量化目标，但高分辨率条件不自动适用于HiF4。
- 复核已有PV-GN、共同变换、GPTQ顺序与HiF4分组代码。测试了动态token敏感度，而非把旧静态通道Hessian研究换个名字。
- Q/K通道配平同时使用互逆缩放，H和U作相应合同变换；共同布局同时重排两个角色的坐标和误差度量，确实改变HiF4小分组，并非仅改内部处理顺序。两类数学单测通过，但没有可靠收益，未合入。
- 最终长序列路径沿用之前SageAttention2启发的K平移自由度：任意共享c满足 `softmax(Q(K-c)^T)=softmax(QK^T)`。长度上限是工程预算，不是这条恒等式的适用上限。

原始资料与边界见 `docs/attention-math-literature-20260903.md`、`docs/v321-report.md`。本轮是定向复核，不声称重新逐页读完全部论文。
