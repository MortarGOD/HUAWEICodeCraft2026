## 结论先行

最贴近本题的数学领域不是普通权重量化，而是**分布式函数量化、条件风险最小化、算子回归和相关舍入**。独立接口不等于只能做逐元素重建；它要求测试决策仅依赖自己的输入，并把缺失角色的影响通过校准得到的条件统计纳入目标。

本轮优先提出两个尚需实验的新组合：

1. **V 的条件二次风险：学习二阶算子和一次残差项**，而不是先预测一个 K/P 再当成真值。
2. **Q/K 的输入条件化输出敏感度**，保留已有 GPTQ 求解器，将它与可泛化的条件输出度量结合。

相关舍入、收缩估计是配套手段，不将“更多搜索”或“换阻尼”独立包装成确定的大幅增益。

## 二、论文卡片及接口适配

以下“论文结论”与“本题迁移”分开书写；优先级表示值得验证，不表示预期分数。

### M1. Distributed Scalar Quantization for Computing: High-Resolution Analysis and Extensions

Misra、Goyal、Varshney；IEEE TIT 2011，预印本 2008。[原文入口](https://arxiv.org/abs/0811.3617)；[本地 PDF](/Users/ee/.agent-reach/hif4-attention-math-20260903/pdf/DFSQ_0811.3617.pdf)。

- 论文结论：各编码器独立观测相关变量，为中央函数计算设计量化器；核心统计是条件平方敏感度。高分辨率下，固定码率最优点密度与 `(gamma² × 输入密度)^(1/3)` 成比例。
- 阅读：PDF 13-15 页的定义 3、定理 9/13；23 页编码器通信扩展的条件定义。
- 本题迁移：分别学习当前 Q/K/V 对输出误差的重要性，而非要求恢复全部缺失输入。优先级 P0，需与 M2 合用。
- 边界：高分辨率、平滑性、源分布等条件不自动适用于 NVFP4 输入和 HiF4 多级共享尺度。论文的编码器通信、熵编码和可变比特分配不能直接移入本题。

### M2. Distributed Functional Scalar Quantization Simplified

Sun、Misra、Goyal；IEEE TSP 2013，预印本 2012。[原文入口](https://arxiv.org/abs/1206.1299)；[本地 PDF](/Users/ee/.agent-reach/hif4-attention-math-20260903/pdf/DFSQ_Simplified_1206.1299.pdf)。

- 论文结论：在所列条件下，直接将固定函数作用于量化输入的简单解码器，与复杂条件期望解码器具有相同的一阶高分辨率渐近表现；扩展到无界分布与向量输出。
- 阅读：1-8 页模型、定理 1/2、推论 1；12-13 页多变量证明中交叉项的处理。第 8 页式 (30) 已视觉核对。
- 本题迁移：判题器固定计算 Attention，正对应不能任意更换解码函数的结构。用输出 Jacobian 的条件平方范数指导合法尺度和舍入。优先级 P0。
- 边界：证明中的跨误差项是在高分辨率近似下消失；我们的低位宽、共享尺度和主动误差补偿不能照此删掉交叉项。式 (24) 与 M1 定理 13 一致，点密度含 `gamma²`，不能据提取文本中孤立公式漏掉平方。

### M3. Conditional Mean Embeddings as Regressors

Grünewälder、Lever、Baldassarre、Patterson、Gretton、Pontil；ICML 2012。[会议原文](https://icml.cc/2012/papers/898.pdf)、[含补充材料版本](https://arxiv.org/abs/1205.4656)；[本地正文](/Users/ee/.agent-reach/hif4-attention-math-20260903/pdf/CME_Regressors_ICML2012.pdf)。

- 论文结论：条件均值嵌入可写成向量值正则回归，可通过样本学习条件期望算子，并做交叉验证和稀疏近似。
- 阅读：正文第 2-7 页的回归、式 (9)-(12)、定理 3.1、适用条件和稀疏化；补充材料第 9 页 Lemma A.1/Theorem A.2。
- 本题迁移：预测与量化决策相关的二阶矩、梯度或候选损失，而不执着于重建缺失 K/V。优先级 P0。
- 边界：普通岭回归只是有限特征的条件均值模型，不能据此宣称完整 RKHS 方法已实现。收敛率依赖核、分布和采样条件；五份校准序列内的相关 token 不等于大量独立序列。

### M4. On the Properties of the Softmax Function with Application in Game Theory and Reinforcement Learning

Gao、Pavel；预印本 2017。[原文入口](https://arxiv.org/abs/1704.00805)；[本地 PDF](/Users/ee/.agent-reach/hif4-attention-math-20260903/pdf/Softmax_1704.00805.pdf)。

- 论文结论：Softmax 是 log-sum-exp 的梯度；Jacobian 为 `lambda × (diag(p)-p pᵀ)`，半正定且消去常数方向；温度控制其 Lipschitz 性质。
- 阅读：第 5-7 页命题 1-4 与推论，核对第 5 页式 (27)。本地版本命题编号与某些搜索摘要不同，以下载 PDF 为准。
- 本题迁移：度量应区分对 Softmax 无影响的 logit 平移与真正改变输出的方向；进一步乘入 V 后才是输出敏感度。优先级 P1。
- 边界：Softmax 的 Fisher/Jacobian 不等于完整 Attention 输出平方损失的 Hessian。不能因为降温降低敏感度，就无限降低温度而忽略对原输出的偏离。

### M5. Hardware-Limited Task-Based Quantization

Shlezinger、Eldar、Rodrigues；IEEE TSP 2019，预印本 2018。[原文入口](https://arxiv.org/abs/1807.08305)；[本地 PDF](/Users/ee/.agent-reach/hif4-attention-math-20260903/pdf/TaskBased_1807.08305.pdf)。

- 论文结论：量化设计应服务于最终估计任务。无硬件限制的向量量化可基于条件均值分解误差；在标量 ADC 约束下，直接量化该均值一般不再最优，需要联合考虑前后处理与有限动态范围。
- 阅读：第 9 页式 (4)、12-17 页噪声假设、Lemma 1、Theorem 1 与维度条件。
- 本题迁移：为任务设计表示和合法离散搜索，而不是把一个预测结果直接 round。优先级 P1，提供问题框架，不是可照搬的提交算法。
- 边界：论文允许设计数字后处理 B；Attention 判题器没有任意 B 的接口。其白量化噪声条件不适用于任意 HiF4 搜索输出，也不能据条件均值误差给整个分布式 Attention 系统定下界。

### M6. The Gram-Schmidt Walk: A Cure for the Banaszczyk Blues

Bansal、Dadush、Garg、Lovett；预印本 2017，STOC 2018。[原文入口](https://arxiv.org/abs/1708.01079)；[本地 PDF](/Users/ee/.agent-reach/hif4-attention-math-20260903/pdf/GramSchmidtWalk_1708.01079.pdf)。

## 三、本题推导：从预测缺失输入，转向学习决策所需的条件风险

以下是**结合论文框架后针对本题的推导**，不是任何一篇原论文已经实现的 Attention 算法。

### 3.1 形式化独立接口

以 NVFP4 输入解码后的 Q/K/V 作为题目参考张量；不将其误称为量化前的真实模型激活。令固定评分算子为：

`F(Q,K,V) = softmax(Q Kᵀ / sqrt(d)) V`。

若实际评分包含掩码或其他规范，应在教师中原样保留，不额外假设因果掩码。三路只能部署 `f_q(Q;theta_q)`、`f_k(K;theta_k)`、`f_v(V;theta_v)`。校准可以联合训练这些函数，但测试不跨角色传递当前张量。

这属于分散观测、统一任务的优化问题。没有当前完整 Q/K/V，阻止的是逐题 oracle 搜索，不是所有输出导向训练。

### 3.2 V：固定 Q/K 量化器后，关于 V 候选的损失是精确二次型

下面先写单个 attention head；GQA 对共享 V 的所有 query heads 汇总。条件期望还隐含条件于固定校准 state、head 布局和当前序列长度，不混合不同尺寸的算子。

记参考概率 P、父版 Q/K 得到的概率 P_hat、父版 V 输出 V0，参考输出 Y=PV。令候选 V_hat=V0+Delta，父版残差：

`R0 = P_hat V0 - Y`。

先以 m 个 query 上的 `||R||_F²/m` 为目标。对一个校准样本，有精确等式：

`L(V0+Delta)-L(V0)`

`= tr(Deltaᵀ H Delta) + 2 tr(Deltaᵀ G)`，

其中 `H=P_hatᵀ P_hat/m`，`G=P_hatᵀ R0/m`。

V 动态接口虽然不知道测试 P/P_hat/R0，但知道当前 V 和由 V 确定的父候选 V0。对缺失角色条件平均后，仍有：

`E[Delta L | V] = tr(Deltaᵀ H_V(V) Delta) + 2 tr(Deltaᵀ G_V(V))`，

`H_V(V)=E[P_hatᵀ P_hat/m | V]`，

`G_V(V)=E[P_hatᵀ R0/m | V]`。

**要学的是 H_V 与 G_V，不必先准确还原 K 或当前输出 Y。** 等式本身精确；用有限特征/有限校准估计 H_V/G_V 是近似，且不保证可准确学习。

G_V 包括父版 Q/K 误差和 V0 误差的交互。若只最小化 `||P_proxy(V_hat-V)||²`，就可能遗漏针对 Q/K 误差的主动补偿。现有条件核并不等于完整实现这两个条件统计。

上述是未归一化到官方基准的输出 MSE。如果每题评分带不同归一化权重 omega，训练标签应改为 `omega×H` 和 `omega×G` 再取条件期望，不能默认各题的大幅度 MSE 等价于更多分数。

### 3.3 不能用“平均概率的平方”替代“概率平方的平均”

设 `P_bar=E[P_hat|V]`，则：

`E[P_hatᵀ P_hat|V] = P_barᵀ P_bar + E[(P_hat-P_bar)ᵀ(P_hat-P_bar)|V]`。

右边第二项半正定。只生成一个平均/点估计概率再优化，会漏掉这个不确定性项。它不是随便加一个固定 ridge 就自动准确补齐的。

构造反例：两种等概率注意力 `[0.9,0.1]` 与 `[0.1,0.9]`，误差向量 `[1,-1]ᵀ`。平均概率给出误差 0，实际期望平方误差是 0.64。此反例只证明两种目标不同，不说明线上存在该比例的数据。

### 3.4 不显式存储 T×T 矩阵的路线

优先验证两种有界近似，不直接做全长核矩阵求逆：

- **结构化条件度量**：`H_hat(V)=diag(a(V))+U(V)U(V)ᵀ`，`a>=0`，U 的列数先限 4/8/16；通过当前 V 的 token 特征和序列汇总量生成。常数均值方向、能量/位置特征方向只是候选，不能假设它们等于真实注意力主方向。
- **候选风险回归**：从当前 V 生成少量合法 Delta，校准计算真实 Delta L；用候选自身的特征拟合风险排名，避免先回归整张 H/G。须保持 PSD/信赖域或回退约束，不能给任意神经回归值无限信任。

矩阵方案的二次项可算成 `sum_j a_j ||Delta_j||² + ||Uᵀ Delta||_F²`。固定秩下可避免 T² 存储。G_V 的低秩或逐 token 回归必须保留一次项，并比较其跨序列稳定性；不将梯度很小当成预测准确。

### 3.5 Q/K：条件化的输出敏感度，而非仅有全局 Gram

对单个 query，令 `p=softmax(Kq/sqrt(d))`，`C=diag(p)-ppᵀ`，则按行向量输出约定：

`delta y ≈ delta q · J_q`，`J_q=Kᵀ C V/sqrt(d)`。

局部 Gauss-Newton 度量为 `J_q J_qᵀ`。对 key j：

`delta y_i ≈ p_ij (q_iᵀ delta k_j) (v_j-y_i)/sqrt(d)`。

GQA 时按共享 KV 的所有 Q heads 汇总。平方输出残差还有一次梯度项；Gauss-Newton 不是完整损失 Hessian，较大舍入步长必须重新计算真实校准输出。

已有研究做过静态 PV 度量、草图及仿射蒸馏，因此不能把这些 Jacobian 再列为“首次发现”。新验证点是：**由当前可见输入条件化的度量/残差，是否比统一校准 H 更能预测真实候选排序**。单看 H 的 Frobenius 拟合误差不够。

### 3.6 相关舍入应服务于可信目标

对固定合法尺度，误差向量的联合舍入可以写成向量平衡或离散二次优化。若 H 已可信，两个位置 i/j 的移动会包含 `2 delta_i delta_j H_ij`，不能只将单点收益相加。

现有 Q/K 两通道搜索已证明“局部二次型下降却 PV 不改善”的现象。新方向不是重复增加通道对数，而是换成经验证的条件输出目标，再比较相同时间预算下的单点、成对和小块相关舍入。

原版 GSW 只作算法灵感和可达到性分析；HiF4 的限幅、不同步长、共用元数据必须显式处理。不能将多个通道来自不同尺度树的参数任意拼接。

## 四、与已有实现/失败实验的差异

| 已有方法或研究 | 已经得到的证据 | 本轮真正新增的验证点 |
|---|---|---|
| Q/K 全局对端 Gram + GPTQ | 已有线上有效组合，不删除 | 条件输出敏感度/梯度能否改进候选排序 |
| 完整 Q→K/V、V→K 岭回归 | 部分代理上预测误差显著大于 HiF4 误差 | 改预测对象：H/G 或候选损失，而非原始缺失张量 |
| 静态 PV Gauss-Newton | 数学正确，小样本收益不足 | 当前输入条件化、一次残差项、预测不确定性 |
| Q gain/bias 输出蒸馏 | 训练下降不代表跨组泛化 | 低自由度风险学生，先做序列级留出再讨论容量 |
| V 条件核 + v319 尺度树 | 已有可执行版本，v319 等线上反馈 | 从单一 P_proxy 改为条件二阶统计，并显式加入 G_V |
| Q/K 二坐标格点搜索 | 代理目标更优但最终输出收益小 | 先修目标再比较相关舍入，不重复调大搜索预算 |
| 固定 0.1 阻尼与阻尼摸排 | 已有收缩形式，历史微小收益 | OAS 仅作统计校准候选，不列为大突破 |

## 五、下一轮验证顺序及验收标准

本轮只形成研究候选，不自动分配 v320。收到新线上反馈后再按用户约定进入版本迭代。

### R0：先确认可学习信号，不改量化器

1. 固定父版一次校准结果，记录真实完整 key 下的 H/G 或候选 Delta L 标签，只抽 query；不把抽 key 改变后的 Softmax 当同一任务。
2. 按完整校准序列留出，不只随机拆同一序列内 token；有限样本时逐份轮换。父版校准/开关如果使用了留出样本，必须重做外层留出，不能伪称全系统独立验证。
3. 比较常数统计、现有 V 条件核、仅 H、H+G、H+G+不确定性项。标签只来自校准；本地测试用于最终评估，不反向拟合每组策略。
4. 指标优先看真实候选损失排序、接受错误率、输出误差变化和最差组；同时记录预测误差，但不以它单独验收。
5. 若条件模型没有稳定优于无条件统计，停止扩大模型，转向低自由度校准参数，不以“更多原始信息”替代证据。

### R1：先做 V 的 H+G 小候选搜索

- Linear、Q/K 固定；原始 V 生成当前父候选和少量合法候选，预测器只读当前 V 与冻结 state。
- 初始结构低秩 4/8/16、最多两次接受更新；需记录各个配置全部结果，不预设这些数最优。
- 验收解析增量、PSD/有限值、边界、回退等输出、输入与 RNG 无副作用、独立调用、状态类型/深度/节点数、HiF4 参数合法性。
- 单次选中后复评代理真实二次项；局部保护不能取代校准输出筛选。

### R2：Q/K 输入条件化度量

- 保留当前 GPTQ 算法作为父候选；先低自由度混合输出敏感度与原始 Gram，不直接强制替换所有 heads。
- 显式对齐旋转/配平坐标，保留 Softmax 常数方向不变性和 GQA 聚合。
- 对照静态 PV 度量、同预算 GPTQ 和当前输入条件化模型；同时评估包含一次残差项的必要性。

### R3：相关舍入与速度

- 只有 R1/R2 建立有效目标后，再比较小块平衡、成对更新、普通逐点搜索；总时间预算相等。
- 冻结 Linear；300 秒硬限制、280 秒内部上限。新增预测/校准成本必须计入，不能只计搜索循环。
- 新版本仍按既定流程：实现 -> self_check -> 推送 -> 完整本地回归/估时。没有合格本地预测器时，明确标注探索性估计，不能承诺 +50/+200 或 21200+。
