# v352：缺失Gram时的等价三角恢复

基于v324，仅修改 `_joint_raw_metric` 缺失H的分支。若U满足 `UᵀU = Hd⁻¹`，则 `Hd = U⁻¹U⁻ᵀ`。用上三角求解求U⁻¹后相乘，替代该分支的cholesky_inverse；原有阻尼去除公式不变，已有H的快速路径不变。没有新增state字段，不改变Linear、测试动态量化预算、阈值或候选数。不包含v350因子、v351缓存、双精度实验或统一基线选择。

## 实现依据

同父状态重复实验发现，候选失效首次出现在无H的k_state经 `_joint_raw_metric` 恢复hq时。故障时hq与正常结果相差约160万，后续阻尼矩阵已有大负特征值；第一阶段Cholesky抛非正定异常，且没有修改输入。双精度中间计算仍失败，已否定其作为充分修复。这里仅定位了当前本地环境中的路径，不断言所有PyTorch/线上后端都存在相同问题。

三角恢复原型在同一捕获状态上连续10次候选构造成功，各中间矩阵逐值相同。96项代数/不修改状态/已有H路径检查通过，最大Gram相对误差3.04e-7。三角恢复研究两bank各30例，feedback仅组6微小变化、covariance同分；原始比较基线有偶发失败，不能将微小差异当作一般提分证据。
