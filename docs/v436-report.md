## 改变的主要条件

新风险不使用假 Q/K 预测 P，也不通过父 VK 校准门。每次仅从真实当前 V 构造 8 个确定性正交符号方向的标准化内容特征，对正负方向分别以 0.5/2 两档生成 32 个 softmax 概率场；均匀场占总风险的一半，其余场合占一半。不同内容和 token 置换会同步改变风险，既不冻结 token 下标，也不把它声称为真实 P。

令加权概率行组成 B，E 为实际合法 BF16 解码值减当前 V，目标为 `||BE||² + ||E||²/T²`。固定当前 V 后这是跨 token 的二次目标。它假设真实注意力对 V 内容具有一定依赖；若真实概率与这组方向无关，代理改善可以导致线上退化。方向和尺度是预先确定的先验，不是从本地测试调参。

从完整 v435 输出出发，两轮低秩 Woodbury 连续求解与 HiF4 全尺度树投影交替；允许 SF/lv2/lv3/码一起改变。每个 64 输出通道块跨全部 token 验收，真实解码风险严格下降、块 SSE 不超过原父 1.10 倍才保留。最终合并后再次复算并回退不满足约束的块。保护的是代理风险和块 SSE，不是最终 Attention 输出不退化。

全部 V 头和通道参与新增路径，预算为 CPU、2≤T≤4096、D 为64倍数、总元素≤2²⁰，其他形状原样回退。没有沿用 v435 最多16通道/四分区/固定尺度限制。校准、Q/K、Linear 沿父链；新增标记只在最终 state 加包装，不改变父校准内部动态调用，也不读当前真实对端或使用共享缓存。

与 v399 的共同点是连续/离散交替求解；区别是当前自身内容定义风险、全部头可进入且不依赖假对端门。不能把求解器名称当成新发现。与 v435 的区别是连续内容概率族、全通道和尺度自由度，而非扩其码对搜索轮数。
