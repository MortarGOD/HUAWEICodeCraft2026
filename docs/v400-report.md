# v400：跨序列Q预测残差的多情景V风险

线上回执21204分/257秒，相对v387+20/+5，成为当前最高分参考。该小幅正反馈支持继续研究残差风险建模，不说明本地重复性问题已经解决，也不能将20分全部归因于某个独立模块（后续校准有交互）。

v399线上21094/254，相对v387=21184/252为−90/+2，不合入。结构和压力本地小正未兑现，说明当前本地正向不是可靠预测；不能据此断言预测P偏差是唯一原因，离散解和联合校准交互同样可能影响结果。

本版从v387完整前缀出发，只改`_vk_fit`和`_vk_probabilities`，不继承v399的ADMM。Linear不变；保留8轮固定尺度V反馈、原MSE上限、原联合校准守门。后续Q/K校准可以间接受影响，不宣称最终Q/K相同。

非末校准份拟合共享V特征/K模型，对每份Q用其余份的岭回归预测，形成跨序列残差。特征图和K模型仍共享这些份，因此不是完整模型的独立交叉验证。将残差投到预测K特征坐标后，取协方差前两个主方向，动态生成±sqrt(2)方向的四个对称Q误差情景，各自执行softmax。保留每个P计算平均输出平方误差，不把平均P的误差当成风险：E||Pe||²=||E[P]e||²+E||(P−E[P])e||²。四点仅匹配保留的秩二协方差，不精确积分softmax，不假设真实残差高斯，也没建模K残差。残差均值被扣除，常数偏置不在本版范围。

实际v387核秩为64，含偏置通常65维，不能沿用旧工具原型的32维说法。新state只加[QH,2,rank+1]的有限CPU BF16模式张量，不含测试Q/K或额外共享缓存。T>4096/无模式/零模式回到父概率。场景将概率行数扩大4倍，V反馈矩阵乘也随之增加；固定8轮不代表耗时不增加，300秒硬限/280内部预算仍有风险。

机制测试通过：协方差匹配、概率归一、方差恒等式、零模式回退、状态/RNG不变、合法输出、末序列不进入新增拟合、父前缀与imports；合成例改变296个值，仅证明生效。初次测试将宽度误写33导致断言失败，核对实际秩64后修正测试，没有修改算法来迎合断言。官方接口6/6、格式22/22通过。

本轮使用codebase-memory定位并检查覆盖，最新测试小改的索引元数据滞后已用源文件验证；未做全仓穷尽、未声称本轮新读论文。自检后推送，再按v399固定17组85测试配对，保留反例和输出覆盖，不改本地数据，不许诺+200或22500。
