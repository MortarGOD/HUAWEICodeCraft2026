令P是从当前V和校准信息预测的父概率，D是每token量化码字步长平方的通道均值。用小矩阵求δ=D Pᵀ(P D Pᵀ+λI)⁻¹P(X−Y)，λ=小Gram平均对角×0.01。它最小化输出残差与加权修正幅度的阻尼问题，不是包含列MSE代价的精确Newton方向，不访问当前测试Q/K，也不是原始Attention目标的梯度。

根据δ到下一整数码字边界的距离，选择跨越1/4/16/64个位置的候选步幅（重复预算去重），幅度限于每列4倍父RMSE。由于饱和/同时边界/限幅，实际跨越数不保证等于预算数字。每候选重新计算完整P误差+MSE/T，按列接受严格下降且MSE≤父最终输出1.05倍的结果。最多2轮，无接受提前退出，只对active头求解；T>4096、概率行数>128或分解异常回父。不形成T×T矩阵。

第六方向本轮实现的是当前量化格驱动预条件和边界驱动候选预算；不是已穷尽全部当前输入稳健统计/全策略。追加搜索有额外排序、矩阵乘和解方程成本，不能把停滞退出称整体提速。300秒硬限、280秒内部目标仍需线上检验，22500未达成。
