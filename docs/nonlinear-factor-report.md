# 非线性V特征试验及集中组生成机制复核

2026-09-05。未修改solution、Linear、Q/K或默认入口。

## 特征试验

在v350原线性特征之外增加36维：固定均匀采样16通道的平方/交叉项，以及能量、序列相对能量、最大幅度、平均方向投影。输入z限制在[-8,8]，相对能量限制到64。训练必须逐序列构造相对特征再拼接，避免训练和测试定义不一致。没有固定token索引特征。

六组30例、相同8轮和搜索正则1：普通v350 +0.220808983441；非线性普通拟合+0.220634802023；非线性概率加权+0.220162082065。14/19/49仍未通过守门，没有出现新的收益组。

每档36项特征检查通过：token置换等变性、零输入有限性、维数、输入不变；108项已有搜索数学检查通过，实际状态与30例V输出参数合法性通过。不是新提交版本的完整验收，无性能或线上收益承诺。保留研究实现，不把略低的本地结果当作线上无效证明。

## 更重要的生成机制偏差

通过图定位并逐行读取tools/probe_attention_population.py及tools/build_attention_feedback_bank.py，核对实际bank metadata：组14/19均为 `{'tail':2,'roles':'v','sink':8}`。

生成器先随机选择约1%的token，将其V乘2；然后令所有Q的第0坐标为sqrt(d)，把所有K第0坐标置0，仅在`amp.argmax()`位置置8。T2048时约20个V token有相同放大系数，argmax选其中最早索引作为独有K集中点。这并不是从真实forward观测到的关系。V的尾部放大可能包含弱线索，不能说集中位置与V严格独立或数学上不可预测；但学习这条特殊选点规则也不是线上收益证据。

生成器manifest已经明确记录post-projection扰动可能破坏DeepSeek K=V身份关系。此次确认这些难组的预测瓶颈受该人为规则影响，纠正此前仅围绕“缺少特征/拟合权重”展开的优先级。它们应保留为安全性/分布偏移压力测试，而非单独充当恢复真实模型关系的优化目标。
