# v407/v408：角色独立校准后的V路径消融

父版均为线上最好v400=21204/257，不继承v405/v406。用户要求继续通过正常算法候选摸清原因，不以短期同分猜线上维度或伪造收益。

## 两个候选的唯一轴

| 版本 | 最终动态V | 对照意义 |
|---|---|---|
| v400 | 当前V均值协调 + 可能启用的VK/VM/VR校准增强 | 最佳父版 |
| v407 | 只用原_vk_parent_v：当前V尺度/码字量化及8轮均值误差协调 | 检验校准V增强在假Q/K背景下的净贡献 |
| v408 | 只用原_dyn_table：当前V尺度/码字量化 | 相对v407隔离8轮均值协调 |

两版全量保留v400源码前缀。外层校准完成后才用固定字符串模式替换v_state，动态看到该模式才切换；没有模式的内部调用仍委托原父函数。故父Q/K的选择过程保留，Linear不变。Q/K自己仍可能依赖假对端，本轮没有宣称全方案已摆脱该依赖。

固定v_state只含模式，不从假矩阵推断身份；同一当前V输出不随假校准Q/K变化。没有新增D256/D512或T4096资格门，也没有对端校准通过门才启用的条件，T=1两路都回到原基础量化。这是正常合法算法消融，不制造错误、读文件或利用跨调用缓存。

为保持Q/K校准不变，父校准中后来丢弃的V相关拟合仍执行；本轮不顺带删除这些耗时。动态V少执行增强，不能仅凭删除操作保证线上耗时数字。300秒硬限/280内部目标仍需实测。

## 验证与回归计划

两版官方6/6接口、22/22格式通过。专项：实际结构组10完整父校准各观察到7次原动态V调用且无模式标记；返回Q/K与捕获的完整父state逐项相同；固定V state合法；五个测试上的全新模块输出分别与原基础V/RTN逐字段相同；无标记回退逐字段等于父版；state/RNG不变，源码父前缀/导入白名单通过。

自检后推送，再执行tools/check_role_v_probes.py。固定结构10/11及压力0/49覆盖D256/D512；每组分别构造独立行置换与16列块重采样两种假矩阵假设，各做三次角色校准，只取目标角色state，再对真实QKV测试。三版共享同一组实际父校准结果以隔离数值波动，并使用独立动态模块。两种假数据都不是官方分布，不据此估计线上点数。

## 线上结果如何解释

- v407高于v400：这组V校准增强在当前Q/K组合下净有害；不能因此判定每一个子模块都无效。
- v407低于v400：即使对端是假的，这组增强仍有净价值；保留基线，再拆子模块。
- v407同分：增强可能未采用/未改变结果，或净影响小/抵消；不能反推没有某类维度。
- v408低于v407：当前V均值协调有净价值；差值不能唯一推出attention熵或序列长度。
- v408高于v407：均值代理在当前线上组合里净有害，应研究更稳健的单角色目标。
- 三者同分：先查state路由和两条基础输出是否在线上真的不同，不贸然宣布V无误差空间。

建议先提交v407，再v408。两者都是可回退的诊断候选，可能降分，默认入口仍不替换。
