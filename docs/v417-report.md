# v417：统一Q/K坐标、迁移GPTQ度量

**线上回执更新（2026-09-07）：19263分/250秒。** 相对v412：−1941/−6秒。统一原坐标大幅退化，不替换父QK。以下本地“待测/未知”文字保留历史上下文，最新归因见[本批总结](online-attention-findings-v413-v419.md)。本轮仅记录，不开发新版本。

父v412=21204/256。用户确认Q/K分别校准且对端为假，本地此前发现独立校准可能导致旧变换不互逆；这只是机制风险，不证明全部线上损失由它引起。v417在完整父校准后统一两侧到原始通道坐标，清除qs/ks、joint_transform、rot/rseed，同时递归转换K的ts_fallback。Q temperature_gain是有意温度，保留；KT/TS平移、原始坐标kt_probe、激活掩码及预算保留，不重做选择。V和Linear不变。

旧原始输入到量化坐标为X A，故新原坐标误差e对应旧误差e A，未阻尼风险迁移为Hnew=A Hold Aᵀ。有H直接使用，缺H用U上三角求解重建度量并扣原阻尼；重新施加新坐标阻尼、生成GPTQ U。不是只删变换键沿用旧U。新H保留FP32避免变换后二次bf16舍入，增加部分状态内存；阻尼重新计算、精度改变意味着不能称全算法严格等价。

重建失败则留在原坐标，用正对角度量或单位度量，不回退旧坐标。去掉平衡和旋转可能损害量化精度，统一坐标只保证连续双线性兼容，不保证真实Attention提分。K任意常量平移仍是softmax不变性，但量化搜索及原激活选择可能在新坐标下次优。
