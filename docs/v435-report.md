# v435：真实 V 内容区域的残差协调

父版本v430，线上21303/261秒，SHA256 `0638a8cbc7948f018770ff782fe23d44b45ccd23279659b6415d3459096d59ee`。此前六版线上复盘见[专门记录](attention-online-reassessment-v429-v434.md)。这是一份新信息条件实验，不是把原概率树加深；未收到v435线上回执，不承诺提分或总时限。

## 实现

保持父全部校准、Linear/Q/K以及已启用VK的V头。最终返回的V state仅用纯数据字典包裹原state；父校准内部未带标记的动态调用逐值沿用父版。仅在动态输入为当前真实V、父头没有启用VK时搜索，避免新机制继续依赖假Q/K的双重选择门。

每head以自身V两个最大方差通道、中位数分成至多四个内容区域，不存储校准token位置。令e为合法解码值减真实V、S_g为各区误差和、S为全局误差和，目标J为`sum_g S_g²/n_g + S²/T + SSE/T`。区域残差中不属于全局常量的分量`sum_g S_g²/n_g−S²/T`用于分配每次最多16个通道的预算；未选择通道保持父码。

固定HiF4三个尺度字段，只修改signed code。最多两轮、每通道四个严格有利的单步leader，第二token扫描全部位置和−1/0/+1；两token必须不同，计算完整跨项。不存在有利单步leader时不能跨越双步才下降的局部极小，有限leader及通道预算均不具全局最优保证。

每轮及最终pack后均按真实BF16解码、FP64统计验收：每通道J严格下降，SSE和S²相对原父版双不增加，无epsilon放宽。不通过则回退对应父通道。条件限制为CPU、D为64倍数、2≤T≤4096、T×KVH×D≤2²¹；活跃VK头不参与。无变化轮和全部不合法leader提前结束，输出语义不变。

双不增保证的是给定V条件下交换对称概率二阶矩的同算子V风险，不保证任意真实概率、内容区之外权重或Q/K量化后的完整输出。详细公式与反例见复盘报告。

## 机制与成本

4项core机制测试、4项wrapper/解码测试通过；后者覆盖kh=2/d=128混合活跃头和255种SF×15种码×4种微尺度（15,300值、两种dtype）。实际校准与逐角色fresh module重放通过，父state、输入、RNG不变，未标记V及Q/K输出保持，Linear/Q/K代码保持。

构造例实际改2个码，内容J从0.078125降至0.015625，SSE=0.0625和S²=0均不变；这是机制覆盖，不是自然题量或线上收益。

完整通道原型四份合成输入核耗时约0.043/0.183/0.202/1.316秒，成本否决。加入16通道预算后相同随机输入为0.009/0.018/0.059/0.126秒，但对应改变量由6/51/26/30降为0/2/2/2，明确存在覆盖代价。这份预算测试在等输出的空轮/空leader提前结束改动之前执行，不冒充最终源码的独占性能结论。原始原型数据未删除。不能按本机秒数换算鲲鹏整场耗时；父261秒、内部280秒、硬限300秒仍需线上确认。
