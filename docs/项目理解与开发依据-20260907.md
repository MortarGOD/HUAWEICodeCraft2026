## 2. 比赛真正优化什么

输入已经经过 NVFP4 量化。每 16 个 carrier 值乘对应 scale，按任务书 API 转为 BF16；后续参考计算转 FP32。不能绕过这次 BF16 舍入，也不能把量化前不可得的 FP16 模型当作监督真值。代码依据为 [NVFP4 解码与 HiF4 基线](../hif4_quant.py)。

Linear 的参考为 `Y = A Wᵀ`，候选为 `Ŷ = Â Ŵᵀ`；Attention 的参考为 `O = P V`，其中本地评测使用 `P = softmax(Q Kᵀ / sqrt(d))`，GQA 按 KV head 扩展至 Q head，候选用 HiF4 解码后的 Q/K/V 重新计算完整输出。当前本地评测没有 causal mask；不能把额外 mask 或论文修改过的 softmax 默认为本题评分算子。

每题原始质量指标为：

```text
s_i = (MSE_standard_i - MSE_player_i) / MSE_standard_i
```

标准和候选都与同一 NVFP4 反量化参考比较，最终按题汇总相对改进。必须保留逐题分母，不能把全体元素的误差合并后再做一个比值。`evaluate_local.py` 输出的是原始比例和；线上回执保留平台原单位，不把不同题量的本地数值直接换算为平台分。任务书没有在所读公式中规定零基准 MSE 的特殊处理，不自行编造该边界的官方行为。

任务书第 3 节规定 10 组 Linear，每组 1 份权重、5 份校准激活、5 份测试激活，共 50 题；Attention 250 组，各有校准与测试，共 250 题。校准不直接计分，总计 300 道测试。250/300 的题量占比使 Attention 值得重点研究，但不能据此推导其误差占比或每条优化的收益上限。

用户于 2026-09-07 进一步确认：线上数据集由旧版 250 Linear + 50 Attention 调整为上述当前 50 Linear + 250 Attention；参考仓库同源码约 16806→24201 正是数据集调整造成。历史比较应按旧/新口径分别记录，不再把该分差原因列为未知，也不从两个总分反推固定分项得分。持续学习参考 `base_1.7` 的每 6 小时跟进与落地授权见[跟踪记录](test-base_1.7跟踪记录.md)。

总量化运行时间硬限为 **300 秒**，包含必要校准和动态处理；任一非法返回、异常、缺失结果或超时会导致提交失败。同分时先提交者优先。[imperial_edict.md](../imperial_edict.md) 记录内部目标为 **280 秒**，较旧的 420 秒限制已失效。判题运行于鲲鹏 920B、Python 接口；本机代理计时不能直接变成线上耗时保证。

### HiF4 表示契约

每个末维 64 元素块分为 `8 × 2 × 4`。返回的是合法参数张量，反量化为 `sign × mant × scale_lv3 × scale_lv2 × scale_factor`，不是任意自由浮点张量。

令原张量 shape 为 `[..., C]`，`B=C/64`：

| 字段 | shape | 合法值 |
|---|---|---|
| `scale_factor` | `[..., B, 1, 1, 1]` | 精确可表示的正 E6M2，`2^-48` 至 `49152` |
| `scale_lv2` | `[..., B, 8, 1, 1]` | `{1, 2}`，每 8 元素共享 |
| `scale_lv3` | `[..., B, 8, 2, 1]` | `{1, 2}`，每 4 元素共享 |
| `sign` | `[..., B, 8, 2, 4]` | `{-1, 0, 1}` |
| `mant` | `[..., B, 8, 2, 4]` | `{0, 0.25, …, 1.75}` |

任务书图中的 E1 是 0/1 指数，API 返回的是它对应的 1/2 乘数，二者不能混淆。所有结果须有限。格式细节已与 [self_check.py](../self_check.py) 的 `_expected_hif4_param_shapes`、`validate_hif4_params` 核对。

state 可包含 `None/bool/int/有限float/str/CPU Tensor/list/tuple/字符串键dict`，最大深度 8、总节点数 4096。Tensor dtype 允许 `bool/int8/int16/int32/int64/float16/bfloat16/float32`，不得有梯度、NaN、Inf、复数；本地自检还检查 dense strided layout 和单字符串 4096 UTF-8 字节上限。不能将浮点计算临时使用的 float64、压缩临时使用的 uint8 自动视为合法 state dtype。

提交中不得文件读写；较新的本地规则记录还要求只含 `.py`，列出禁用模块，详见 `imperial_edict.md`。这些限制针对提交代码；本地数据生成、阅读、评测工具另行管理，不打包进提交。

## 3. 六个接口与关键的信息差异

| 接口 | 输入 | 输出 |
|---|---|---|
| `hif4_calibration_and_quantize_weight` | 固定 NVFP4 W、校准激活列表 | `weight_params` 与 `activation_state` |
| `hif4_dynamic_quantize_activation` | 当前 NVFP4 A、`activation_state` | A 的 HiF4 参数 |
| `hif4_calibration_attention` | 校准 Q/K/V 列表、Q/KV head 数、head_dim | `q_state/k_state/v_state` |
| `hif4_dynamic_quantize_q` | 当前 Q、Q head 数、head_dim、`q_state` | Q 的 HiF4 参数 |
| `hif4_dynamic_quantize_k` | 当前 K、KV head 数、head_dim、`k_state` | K 的 HiF4 参数 |
| `hif4_dynamic_quantize_v` | 当前 V、KV head 数、head_dim、`v_state` | V 的 HiF4 参数 |

**Linear 能利用固定 W，Attention 动态角色不能假定能看到真实对端。** 任务书允许 state 保存固定权重信息；`imperial_edict.md` 的 08-31 更新以及当前 [赛题澄清.pptx](赛题澄清.pptx) 又明确记录可利用 `A@W` 拟合合法的 `Q(A)`。因此旧材料中“不保存 W”的业务背景不能继续作为初赛实现限制。

Attention 的更关键澄清来自仓库中的用户反馈记录：[attention-role-calibration-correction.md](attention-role-calibration-correction.md) 与 [最新线上总结](online-attention-findings-v413-v419.md)。实际按角色分别校准：真 Q / 假 K,V 只取 q_state；真 K / 假 Q,V 只取 k_state；真 V / 假 Q,K 只取 v_state。假矩阵的来源仍未知，尚无官方判题器源码佐证，须保留该来源层级。

三次调用不能凭空汇聚真实 Q、K 的边缘统计，也不能假设一次校准中三个矩阵来自同一真实模型输入。动态 Q/K/V 各自仅接收当前自身张量及自己的 state。因此校准对端 Gram、V→Q/K 回归、配对输出守门虽可执行，其“真实对端敏感性”解释需要额外证据。

对可逆矩阵 T，`A′=AT, W′=WT^(-T)` 保持 `A′W′ᵀ=AWᵀ`；Q/K 同理。实际分别生成变换 A、B 时须验证 `ABᵀ=I`，并检查 head 排列及所有回退。连续等价不保证量化精度提高；v417/v418 的线上结果已给出反例。V 的任意输出坐标旋转没有评分端逆变换，不能照搬。

### 现有实现已经做了什么

- **Linear：**降维场景已有直接输出解码布局，动态阶段可用固定 W 计算目标再寻找合法激活表示；等宽/升维已有互补平滑、Hadamard/成对变换、反馈权重量化和精确输出目标离散搜索。升维特定条件下缓存部署权重的 `BᵀB`，以输入 Gram 更新替代较大输出残差计算，限制宽度和内存。依据默认入口约 1928–2205、4341–4356 行。
- **Q/K：**已有校准变换选择、对端 Gram、阻尼/Cholesky、GPTQ 和后续格点优化；K 还包含平移中心与 token 权重优化及按头回退。默认 v325 另有 Q scale-tree 尾层。它们使用什么校准对端必须与第 3 节信息边界一起解释。
- **V：**已有当前 V 均值误差协调，以及由当前 V 和校准 state 预测概率因子的 VK 路径，优化输出风险并保护逐通道 MSE。默认还保留尺度树和输出残差回归层。它们已是研究基线，不能把“尝试 GPTQ/旋转/输出感知量化”当作全新方案。
- **v419：**保留 v412 完整父文件作为前缀；与默认 v325 处于不同尾层分支。父链包括实际量化工作点的 Q 输出 Jacobian Gram、原 logit 度量混合、最后的温度选择、Q 回归残差情景。最终 V 去除 VR/VM 包装但保留其父校准过程，继续基础均值和 VK；v419 仅在最终 VK 之后增加相关残差方向和离散边界搜索。删除最终包装不等于删除其校准成本或影响。

### 将论文知识转化为可检查的数学对象

以下为本题的直接代数推导：

```text
ΔLinear = ΔA Wᵀ + A ΔWᵀ + ΔA ΔWᵀ
ΔAttention = (P̂-P)V + P(V̂-V) + (P̂-P)(V̂-V)
```

分项范数平方不能直接相加成为总误差，必须保留内积交叉项。对固定真实 Q/K，`||P ΔV||²` 是 V 扰动的精确输出目标；`||ΔQ Kᵀ||²` 与 `||Q ΔKᵀ||²` 仅是 logit 代理，尚未包含 softmax 与 V 混合。

当 P 不可得时，应把使用的预测因子写作 `P_proxy` 并标明来源。若引入多种概率情景，`E[||P e||²]` 与 `||E[P]e||²` 一般不同；这说明风险形式需要核验，不证明目前拟合的情景是真实条件分布。

v419 现有方向可写为 `δ = D P_proxyᵀ(P_proxy D P_proxyᵀ + λI)^-1 P_proxy(X-Y)`；D 来自当前 V 码字步长平方的通道均值。它是阻尼加权修正，不是完整真实 Attention 梯度。当前实现固定尺度、最多两轮，按 1/4/16/64 边界预算生成提案，并用完整代理风险及父输出 1.05 倍 MSE 上限验收。饱和、同时跨界和限幅使实际改码数未必等于预算数字。

## 7. 用《实践与攻坚方法》组织后续工作

指导思想来自用户指定文档。下列是工程落实，不冒充毛泽东或小说原话，也不声称已经通读其所有原著。

1. **调查先于定性。** 每轮固定父文件、数据、接口条件和已知回执。遇到同分，依次查信息、触发、state 生效、最终张量差异、损失和评分，保留多种解释。
2. **具体分析条件。** 论文能使用真实配对、修改整网或增加残余表示，不代表本题具备这些条件；按角色可信信息重新推导，而非照搬方法名。
3. **集中一个主要问题。** 当前有证据支持优先研究“代理风险与最终收益是否一致，以及 v419 哪部分有效”。这是一项研究优先级判断，不是证明剩余误差只来自该问题。
4. **实践检验并修正实验。** 用消融、自然/强制覆盖、独立模块、留出样本和性能测量分别回答问题；失败只约束覆盖到的具体命题。旧配对实验仍有诊断价值，但适用范围需修正。
5. **数量分析与适用边界。** 记录组/head/题数、接受和回退率、参数/解码值变化、逐题误差、尾部退化及分阶段时间。不能用几个总分识别隐藏模型、长度、概率熵或假数据来源。

### 后续开发的三个优先实验（本轮未实施）

**A. 分解 v419 的有效条件，先校准实验的解释能力。** 保持 v412 父校准/QK/Linear 和父 VK 结果，围绕相关预条件与边界提案做分离消融；对同一合法候选同时记录代理风险、最终 Attention 误差、实际跨界数和局部开销。自然路径与强制路径分别报告，保留 v413 的反向结果。若只降低代理却持续恶化真实留出输出，优先修正风险或守门，不能用增加轮数解释为进展。

**B. 量化合法编码的剩余空间。** 从实际 NVFP4 解码值抽取小块，建立元素 SSE 的离线参考：固定 E6M2 后，每个 8 元素组枚举一个 lv2 与两个 lv3，共 8 种组合，再做最近合法舍入；枚举全部 255 个有限正 E6M2 码值，可得单块元素 SSE 的最优参考（由固定格式推导，本轮未运行）。它可判断当前尺度树/码字搜索还差多少，但不是 Linear/Attention 全局上界。将筛出的差异再放回实际输出目标，检查收益是否传导。SOAR/Four Over Six 的候选思想据此应用于正确的 HiF4 格式。

**C. 检验对端代理的可迁移性。** 保持各角色自己的输入和 state 边界，对数种明确标注的假数据假设比较候选排序、变换兼容性和最坏退化；先检查单角色可观察统计是否稳定。只有双方可共同确定的变换才进入等价性实验，并保留 v417/v418 的负向对照。不能通过拼接三次真实边缘统计或猜真假角色绕过接口。

每轮在 `implementation-plan.md` 写目标、事实、必要条件、可证伪实验、验收、结果和处置；沿用 `candidate-dag.md` 与 `benchmark-log.md`，不另造互相冲突的事实源。规则、版本与线上反馈更新后刷新本文件涉及的快照。
