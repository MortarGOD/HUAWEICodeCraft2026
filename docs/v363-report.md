# v363：当前Q码字误差的K通道联合补偿

## 线上反馈后的结论

v362线上20803.75/244秒，与v360完全相同，排除“校准Query原型不能代表测试Query”是当前主要误差。v363不再替换K平移原型，而是直接补偿当前Q的HiF4码字误差。

## 算法

Q动态路径复用父函数内部连续Q，并保存量化后Q。对启用translation-search的K状态，按KV head和通道闭式拟合标量`c`，使量化Q乘以`c`逼近连续Q；再把相同通道补偿作用到连续K并进入v324原有K平移、Lloyd与HiF4编码。每个head把`c`归一到均值1，严格保留父算法已学习的attention temperature，只补偿相对通道误差。

首个8×8非对角实现会改变整体温度并在group4产生灾难性下降，未发布。最终逐通道版本的实际补偿范围约0.97–1.02。

- 完整本地回归196.80秒，20次测试K调用进入联合补偿；没有第二套K候选或全尺寸softmax搜索。
- 官方mini 22/22通过，禁止导入扫描通过；Linear和校准训练继承v324。

## 线上结果

v363为 **20803.75分/245秒**，相对v362的20803.75/244秒同分、慢1秒。本地+0.005020没有迁移，说明当前Q码字的逐通道相对失真不是线上主要剩余误差。停止扩展到全部K translation分支和非对角补偿，下一方向必须改变表示空间或最终目标，而不是继续放大当前输入补偿。
