# 跨校准序列诊断：不能把同分都归因于门控

固定v343均匀风险候选与父v324 Q/K，不改变搜索轮数。在6组的512/1024/2048三份校准上分别计算最终输出MSE比并记录两折采用标记。父校准保持不变，所以这是选择规则的序列对照，不是整个校准训练流水线的独立泛化验证。

| 组 | 三份校准的主要表现 | 解释范围 |
|---|---|---|
| 0 | 两头始终改善，误差比约0.44–0.71 | 末份选择没漏掉该组 |
| 1 | 0.9904 / 0.9994 / 1.0149，只有第一份采用 | 存在长度/样本间不一致 |
| 5 | 第一头1.32 / 1.96 / 1.06，第二头接近1 | 拒绝有实际误差依据 |
| 14 | 1.78 / 2.17 / 21.92 | 不是末份孤立地拒绝 |
| 19 | 1.43 / 4.66 / 12.67 | 三份均恶化 |
| 49 | 1.05 / 1.20 / 1.37 | 三份均恶化 |

比值是校准输出MSE相对值，不是线上扣分倍数；未据此反推线上每类题占比。

30题测试总原始增量：末份、至少两份支持、平均比值改善且最坏比<1.05，均+0.138825796；“任一份支持且最坏比<1.25”的受限并集+0.147558081，额外+0.008732285来自组1。测试分仅报告，不参与门控参数选择。该并集有放大误接受风险，没有足够证据将其视为大幅提分办法。

结论：本地这6组中，大多数拒绝并非校准末份选择错误。不能取消门控，也不能将结果扩大为所有线上头均无覆盖问题。暂不把四种门控都机械发布成新版本；保留诊断代码，合理新风险目标成熟后再做独立提交。
