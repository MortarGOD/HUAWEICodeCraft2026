## 可学习的共享误差差分界

参考4441–4546及5001–5057行不再仅比较“候选误差上界”和“父误差下界”，还保留两者共享的压缩误差。设近似残差为e、候选引起的近似输出变化为d，实际对应量是e+f、d+g，且已知`||f||≤B_e`、`||g||≤B_d`。近似损失下降量为：

`D = -2〈e,d〉 - ||d||²`。

展开实际损失差，并用Cauchy–Schwarz不等式可得下界：

`实际下降量 ≥ D - [2(||e||+||d||)B_d + 2B_e(||d||+B_d) + B_d²]`。

括号项比D小时，在精确算术与给定误差包络成立的条件下可以接受候选。这可能减少独立误差区间造成的保守性，不声称对所有输入都严格更紧。400个确定性binary64随机向量诊断通过；另构造近似下降0.0199、差分界0.004221的例子，独立区间拒绝而差分界接受。详见审计JSON。诊断没有运行参考量化算法，不代表线上收益。

该界目前只覆盖算子压缩/截断误差。参考守门使用FP32反量化与算子乘积，未完整纳入BF16解码/GEMM、softmax和归约舍入，不能称实际评分的严格保证。本项目当前VK从自身V构造少量查询/场景的概率代理，没有相对真实P的可证误差包络，也没有需要此界保护的压缩算子。因此保留数学方法，暂不引入无收益证据的新压缩器。
