# APTQ全文复读：可迁移的是输出度量，不是混合位宽

阅读范围：本地 `study_2026codecraft/papers/pdf/APTQ_2402.14866.pdf` 全6页文本，另渲染核对第3页公式与架构图；不声称其他65篇已完成本轮全文复读。

## 论文与赛题的差异

- 第3页式(5)将重建目标从单层线性输出改为整个Attention块输出；式(7)保留一阶Jacobian外积以形成半正定Gauss-Newton近似。半正定不自动保证可逆，仍需阻尼。
- 论文主要量化投影权重WQ/WK/WV/WO；本题Attention接口已经拿到Q/K/V激活且无WO。不能直接移植论文对投影权重的导数，必须对输入操作数重新求导。
- 第4页的Hessian trace驱动2/4bit分配不适用于固定HiF4输出契约；可以借鉴敏感度分配计算预算，但不能改变输出位宽。
- 论文在A100上使用128×2048校准，不能将其计算复杂度直接用于本题300秒/CPU限制。

## 独立推导与v365–v367

对一条query，`p=softmax(q K.T/sqrt(d))`、`o=pV`。
Q输入导数的转置为`Jq=K.T diag(p)(V-o)/sqrt(d)`，完整通道度量为`Jq Jq.T`。
单个K token的通道Gram为`p_j² ||V_j-o||² q q.T/d`。v366累加这些token块，**没有保留不同token间的交叉块**，不是完整K Hessian；v365也将不同query的度量聚合为静态共享Gram，不是逐query自适应最优。
导数均通过autograd对照；使用部署坐标、阻尼和固定原Gram混合，测试期仅使用静态状态。

## 仍未解决的两层问题

1. 当前先用operand MSE选择HiF4层级scale，再用输出Gram决定mantissa。两阶段目标不一致；下一结构实验应比较最终Gram下的**完整参数候选**，而不只是加码字轮数。
2. Q输出Gram依赖当前query对应概率，静态平均会掩盖稀疏与扩散头/行的差异。条件化度量需要证明新增状态能从当前Q独立计算，不能依赖未保证的Q→K进程共享。

此处是受APTQ启发的激活域独立实现，不称为论文原算法完整复现。公开仓库弱父上的Jacobian收益不等于成熟父同样收益，所有候选仍需线上回执。
