# Attention 跨角色预测与 K/V 误差补偿研究

2026-09-03。线上最佳仍为 v314=20071/241 秒，22000+ 未达到；v315 待回执。本轮只新增研究工具，不修改 Linear、生产入口或 v315。

## 预测目标可信度

`cross_role_predictor.py` 用 calib[:-1]、128/256 个固定随机通道特征拟合 Q→K/V 和 V→Q/K 岭回归，末份校准与五份测试评估新增预测器。合法 CPU state 包含索引、中心、尺度和系数。离线工具的局部随机生成器不能直接照搬进提交源。

反馈代理组 1/14/26/49 的 16 个配置，预测 PV 误差 / 官方 HiF4 输出误差在测试上的均值约 8.69–125.88 倍，不能把预测输出作为真实教师。这只否定本次有界回归，不否定所有预测方法。V 已知的 256 特征配置在组 1/49 上预测量化残差与真实残差平均余弦约 0.624/0.338，仍提供方向信息；报告中的无约束输出扣除仅为诊断，不是合法 HiF4 收益。

## 校准确认 K=V 后的经验 Q 分布

反馈代理仅组 1、2、48、49 的全部校准样本解码 K/V 完全相等；这是按校准结构筛选，不按测试分数选组。人工 V stress 破坏了其他组的相等关系，不能将 4/50 当线上比例。相等条件仅在校准中被观测到，不保证未来输入必然相等。

动态 V 从自己的当前输入推得 K，用固定校准 Q 样本计算完整 key softmax 权重，指导 V 格点修正，不读取当前测试 Q/K。末份校准采用实际部署 Q/K/V 输出，两折都至少改善 1% 才启用。

| 验证范围 | 32-query 原始分增量 | 说明 |
|---|---:|---|
| 组 1/14/26/49，20 题 | +0.053255 | 仅组 1 采用 |
| 另组 2/48，10 题 | +0.049014 | 仅组 2 采用；128-query 为 +0.046434 |
| 非相等组 0/3/5/19/40/47，30 题 | 0 | 全部回退，属于负对照 |

两批反馈合计 +0.102268 原始分，本地 ×100 仅约 10.23 分，不能当线上预测。旧协方差 bank 的长度不代表线上长度。顺序运行的缓存效应未排除，耗时不是性能结论。新增 Q 样本排除末份校准，但父版仍沿用自身校准逻辑，不能称整个父版对末份校准完全独立。

## 调整 K 补偿 V 量化误差

`kv_compensation_math.py` 在固定 HiF4 尺度、整数码 [-7,7] 上搜索。目标为固定 query 下原始 K/V 输出；候选使用量化 K/V。解析梯度和 GN 对角选择每 key 的通道候选，检查非线性输出损失与 logit 扰动预算。

K=V 前提下，动态 K 可从自身当前输入获得原始 V 和父版量化 V；查询来自匹配变换坐标下的校准量化 Q，跳过 T1 特殊变换路径。另设诊断 arm，使用当前测试偶数 query 优化、奇数 query 评估；此 arm 不可提交到独立 K 接口。

数学单测梯度/GN 对角最大误差分别 2.78e-17/1.39e-17，格点、单调接受、logit 预算通过。玩具损失下降约 79%，不是实际收益。

这些为完整 key、抽样 query 的诊断分差。优化目标下降并未保证留出 query 输出改善；即使换用同测试样本的另一批 query 也有退化。守门挡住组 49，但未挡住组 1 短输入退化。本次 8-query/8-round 固定尺度实现暂不合入，不等于联合补偿方向无效。

## 决策与证据

- 保留经验 Q 分布为条件候选，不为小收益单独发布。
- 联合 K/V 搜索先研究 query 分布、Q 量化交叉误差与少量 query 过拟合，不盲目堆轮数。
- 所用 bank 是真实 checkpoint 投影加模型化 hidden，不是完整模型前向激活；均无线上分数预测资格，不承诺 21200/22000。
- 三套单测覆盖预测不变性、合法状态、GQA、禁用/边界回退、MSE 保护和解析数学。生产未改，本轮没有新版本 self_check 或线上结果。
