# v373：保持权重尺度的双校准折码字调整

父版v324，非v372叠加。Attention/降维/动态求解器均不改，原父AST完整前缀相同。新增仅针对O>I且I≤4096的校准包装器，默认solution.py未替换。

保留全部weight scale_factor/scale_lv2/scale_lv3，前四份校准分别采样至多64个实际部署Q(A)行，按等序列/目标能量归一化。第0/2份和第1/3份组成两折。选择最多64个输入通道逐次调整，每个权重最多移动一个HiF4码字，只有两折固定Z二次误差都降低才接受。最后一份校准重新计算实际Q(A)输出，两折改善0.01%才采用候选。不用测试数据拟合/选版，父校准已见过最后一份，不冒称完全独立验证。

## 结果

- 九项数学测试覆盖I=64/128/256与三档噪声；两折下降、父参数不变、三个尺度不变、最多一码步、HiF4参数合法性通过，确有7073次修改而非空路径测试。
- 官方接口6/6、格式22/22通过。
- 全部10组50道本地题与父版逐题同分，每侧60项公开返回/状态检查。五升维均触发，修改12768–14248个码字，但留出输出误差仍升约1.5%–3.7%，全部拒绝。降维不触发。
- 比v372退化幅度减小，不能把较小退化称为收益。两版的基线、数据一致，操作同时改变多个因素，不能由此独立归因尺度重选。

本地计时包含验证重叠和机器波动，不给线上总时预测。虽然删去了拟合阶段完整逆矩阵，候选状态重编译仍有稠密求解，4096+真实成本未验证。作为用户要求的线上未验证方向低优先级交付，不宣称22500突破。
