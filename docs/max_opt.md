## 一、场景形式化与核心思路

### 1.1 新旧场景对比

| | 旧场景 | **新场景** |
|---|---|---|
| **校准阶段** | $A_1, W$ → 确定 $Q(W), \Theta$ | $A_1, W$ → 确定量化策略/超参数（不变） |
| **测试阶段** | 只有 $Q(W), \Theta$；$W$ **不可用** | $A_2$ 和 $W$ **都可用** |
| **测试阶段操作** | $A_2 \cdot Q(W) \approx Q(A)$ | $A_2 \cdot W = Y$（全精度），再量化 $Y \to Q(A)$ |
| **核心约束** | $Q(W)$ 必须在部署前固定 | 可在运行时针对当前 $A_2$ **重新决策量化方式** |
| **量化对象** | 权重 $W$（离线） | **输出/激活 $Y = A_2 W$**（在线） |

### 1.2 核心思路

> **范式转变**：问题从"找到一个对所有输入都足够好的固定量化方案"转变为"为每个输入找到最优的量化方案"。前者是统计平均意义上的最优，后者是**条件最优**。

具体来说，新场景下有三个关键自由度是旧场景不具备的：

1. **全精度计算可用**：测试阶段可以计算 $Y = A_2 W$ 的精确值，不存在权重近似误差 $\|A_2 W - A_2 Q(W)\|$。量化误差**仅来自**对 $Y$ 的舍入/截断。

2. **W 的结构信息可用**：可以利用 $W$ 的奇异值分布、行/列范数、条件数等信息来指导量化策略（例如：输出维度 $i$ 对应的 $\|W_{i,:}\|$ 越大，该维度的量化误差对下游影响越大，应分配更高精度）。

3. **当前激活统计量可用**：可以针对当前 batch 的 $A_2$ 动态计算量化参数（scale、zero-point、clipping range），而非使用校准集上的全局统计量。

### 1.3 优化目标的重新表述

旧场景：
$$\min_{Q(W),\Theta} \|A_1 W - A_1 \cdot Q(W)\|_F^2 \approx \|A_2 W - A_2 \cdot Q(W)\|_F^2$$

**新场景**：
$$\min_{Q(\cdot)} \|Y - Q(Y)\|_F^2 \quad \text{where } Y = A_2 W$$

其中 $Q(\cdot)$ 是一个**量化策略**（不仅是固定的量化器，还包括量化粒度、位宽分配、异常值处理等决策），且该策略可以依赖于 $A_2$ 和 $W$ 的实时信息。

> **关键洞察**：新场景下，校准阶段的角色从"确定固定的 $Q(W)$ 和 $\Theta$"变为"**学习量化策略的超参数**"——例如学习哪些层需要 per-token 动态量化、最优的 clipping 策略、混合精度的位宽分配等。

## 二、第一梯队：直接匹配新场景的论文

> 这些论文的设计前提就是"推理时可以访问完整权重/全精度计算 + 当前激活"，与新场景完美匹配。

### 23. Atom: Low-bit Quantization for Efficient and Accurate LLM Serving ⭐⭐⭐
- **作者**：Yilong Zhao 等（UC Berkeley / Stanford）
- **发表**：MLSys 2024 (arXiv:2310.19102)
- **核心思想**：提出 **activation-aware per-token dynamic quantization**——在推理时对每个 token 的激活动态计算量化参数（scale / zero-point），而非使用全局静态统计量。同时提出低比特（W4A4）下的混合精度 GEMM kernel，将量化开销降到最低。在 LLaMA-2 上，W4A4 配置下精度损失 < 1%，推理吞吐提升 2.3×。
- **与新场景的关系**：**完美匹配**。Atom 的核心假设就是"推理时可以访问当前激活的完整信息"，并据此做 per-token 动态量化。在新场景下，$Y = A_2 W$ 可以先在全精度下计算，然后对 $Y$ 的每个 token 维度做动态量化，量化参数（scale, zero-point）根据当前 $A_2$ 的统计量实时确定。
- **关键可借鉴点**：
  - Per-token 动态量化参数的计算方法
  - W4A4 混合精度 GEMM kernel 设计
  - 量化误差对下游 perplexity 的影响分析
- **链接**：https://arxiv.org/abs/2310.19102

### 24. QServe: W4A8KV4 Quantization and System Co-design for Efficient LLM Serving ⭐⭐⭐
- **作者**：Yujun Lin 等（MIT / NVIDIA）
- **发表**：MLSys 2025 (arXiv:2405.04532)
- **核心思想**：提出 **progressive quantization** 策略——权重以 W4 存储，推理时按需反量化到 INT8 与 A8 激活做矩阵乘。关键创新：(1) **SmoothQuant 与 per-channel 量化的结合**——在 W4→INT8 反量化时引入激活感知的补偿项；(2) **动态量化调度器**——根据当前 batch 的激活分布选择最优的反量化路径。系统层面配合 GPU kernel 实现零额外开销。在 LLaMA-2-70B 上，W4A8KV4 配置下精度损失 < 0.5%，边缘 GPU（Jetson AGX Orin）推理吞吐提升 3.5×。
- **与新场景的关系**：**高度相关**。QServe 的 progressive dequantization 思路可以直接迁移到新场景：先在全精度下计算 $Y = A_2 W$，然后按需将 $Y$ "渐进量化"到目标位宽，每一步量化都利用当前激活的统计信息做最优补偿。
- **关键可借鉴点**：
  - Progressive quantization 的多级量化策略
  - 激活感知的反量化补偿项设计
  - 边缘 GPU 上的量化推理系统优化
- **链接**：https://arxiv.org/abs/2405.04532

### 25. LLM.int8(): 8-bit Matrix Multiplication for Transformers at Scale ⭐⭐⭐
- **作者**：Tim Dettmers, Mike Lewis, Younes Belkada, Luke Zettlemoyer（UW / Meta / HuggingFace）
- **发表**：NeurIPS 2022 (arXiv:2208.07339)
- **核心思想**：发现 LLM 激活中存在 ~0.1% 的**系统性异常值**（出现在固定通道上），这些异常值贡献了大部分量化误差。提出 **mixed-precision decomposition**：将包含异常值的维度保留在 FP16，其余维度用 INT8 计算，最后合并结果。关键发现：异常值通道是**确定性的**（不随输入变化），因此可以在推理前预计算异常值通道列表。
- **与新场景的关系**：**直接适用**。在新场景下，计算 $Y = A_2 W$ 后，可以利用 $W$ 的结构信息（哪些输出维度对应异常值通道）来指导 $Y$ 的混合精度量化：异常值维度用高精度，其余用低精度。由于异常值通道是确定性的，这个决策可以在校准阶段预计算，测试阶段直接查表执行。
- **关键可借鉴点**：
  - 异常值通道的确定性特征（不随输入变化）
  - Mixed-precision decomposition 的实现方法
  - INT8 GEMM 的精度-效率权衡分析
- **链接**：https://arxiv.org/abs/2208.07339

### 26. ZeroQuant-V2: Exploring the Potentials of Multi-bit Supernet for Post-Training Quantization ⭐⭐
- **作者**：Zhewei Yao 等（Microsoft / Intel）
- **发表**：ICLR 2023 Workshop → 后续扩展版 (arXiv:2303.02684)
- **核心思想**：提出 **analysis-based quantization**——不依赖大规模校准数据集，而是通过分析模型权重和少量样本的激活统计量来确定最优量化配置。引入 **multi-bit supernet** 概念：一次校准同时生成多个位宽（2/3/4/8-bit）的量化配置，推理时根据硬件约束和精度需求动态选择位宽。
- **与新场景的关系**：在新场景下，multi-bit supernet 的思路可以进一步扩展——不仅在校准阶段生成多个位宽配置，还可以在测试阶段根据当前 $A_2$ 的统计量**动态选择**每个层/每个维度的最优位宽。这相当于把"静态位宽分配"升级为"条件位宽分配"。
- **关键可借鉴点**：
  - Analysis-based quantization 的轻量级校准方法
  - Multi-bit supernet 的多位宽共存设计
  - 动态位宽选择的决策策略
- **链接**：https://arxiv.org/abs/2303.02684

## 三、第二梯队：关键技术组件（可在新场景下动态化升级）

> 这些论文的核心技术可以"动态化"——从离线固定参数升级为在线条件参数。

### 27. OmniQuant: Omnidirectionally Calibrated Quantization for Large Language Models ⭐⭐⭐
- **作者**：Wenqi Shao 等（OpenGVLab / 上海 AI Lab）
- **发表**：ICLR 2024 (arXiv:2308.13137)
- **核心思想**：提出两个创新组件：(1) **Learnable Weight Clipping (LWC)**——用可学习参数间接确定每个权重通道的量化上下界（而非直接用 max），通过 block-wise 重建误差反向传播优化；(2) **Learnable Equivalent Transformation (LET)**——将 SmoothQuant 的手工缩放推广为可学习的等价变换，通过可微优化确定最优缩放/偏移参数。在 W4A4、W3A16、W2A16 等极端配置下均显著超越 GPTQ 和 SmoothQuant。
- **与新场景的关系**：**高度相关**。在新场景下，LWC 和 LET 的参数可以**条件化**——以当前 $A_2$ 的统计量为输入，动态输出最优的 clipping 范围和等价变换参数。这相当于把 OmniQuant 从"全局最优量化"升级为"per-input 最优量化"。
- **关键可借鉴点**：
  - LWC 的可微分权重裁剪设计（间接参数化上下界）
  - LET 的可学习等价变换框架
  - Block-wise 重建误差作为优化目标
- **链接**：https://arxiv.org/abs/2308.13137

### 28. DuQuant: Distributing Outliers via Dual Transformation Makes Stronger Quantized LLMs ⭐⭐⭐
- **作者**：多位作者（国科大等）
- **发表**：NeurIPS 2024 **Oral** (arXiv:2406.01721)
- **核心思想**：指出传统方法（SmoothQuant、QuaRot 等）主要处理"常规异常值"（所有 token 在某些通道上都有较大值），但对"海量异常值"（某些 token 在多个通道上同时出现极大值）处理不足。提出**双重变换**：(1) **旋转矩阵**分散常规异常值；(2) **置换矩阵**重排通道顺序，使海量异常值分散到不同量化组中。两种变换交替使用，效果优于单一变换。
- **与新场景的关系**：在新场景下，由于可以访问完整的 $Y = A_2 W$，可以**实时检测**当前输入是否包含海量异常值，并动态决定是否需要额外的置换变换。对于常规输入，仅用旋转即可；对于包含海量异常值的输入，自动切换到旋转+置换的双重模式。
- **关键可借鉴点**：
  - 常规异常值 vs 海量异常值的分类方法
  - 旋转+置换的双重变换设计
  - 异常值检测的实时判据
- **链接**：https://arxiv.org/abs/2406.01721

### 29. SliM-LLM: Significance-Mixed Quantization for Large Language Models ⭐⭐
- **作者**：多位作者
- **发表**：ICML 2025
- **核心思想**：基于权重**显著性**的分组混合精度量化。提出两个核心组件：(1) **SBA（Significance-Based Allocation）**——全局视角下根据每个权重通道的显著性分配不同位宽；(2) **SQC（Significance-Quantized Calibration）**——局部视角下在组内进一步识别高显著权重，用 τ 缩放校准最小化 ℓ2 重建误差。关键发现：显著通道成簇出现，但组内仍有 ~1% 离散高显著权重。在 2-bit LLaMA-7B 上，困惑度从 GPTQ 的 152.31 降至 14.58（↓90%）。
- **与新场景的关系**：在新场景下，显著性判断可以从"基于校准集的全局显著性"升级为"基于当前 $A_2$ 的**条件显著性**"——同一个权重通道对不同输入的重要性可能完全不同。SliM-LLM 的分组框架天然支持这种动态调整：校准阶段确定分组结构，测试阶段根据 $A_2$ 动态调整组内位宽分配。
- **关键可借鉴点**：
  - SBA 的显著性度量方法（可用于条件显著性计算）
  - SQC 的 τ 缩放校准策略
  - 分组混合精度的位宽分配算法
- **链接**：需确认具体 arXiv ID（ICML 2025 已接收）

### 30. SmoothQuant / AWQ / Czakó et al.（新场景重评）⭐⭐
- **重评原因**：在旧场景中，这些方法的等价变换参数在校准阶段固定后就不再变化。但在新场景下，等价变换参数可以**在每个推理步骤根据 $A_2$ 重新计算**：

| 方法 | 旧场景（固定参数） | **新场景（动态参数）** |
|------|-------------------|----------------------|
| **SmoothQuant** | $s_j = \max(\|A_{1,j}\|)^\alpha / \max(\|W_j\|)^{1-\alpha}$，$\alpha$ 固定 | $\max(\|A_{2,j}\|)$ 用当前 batch 实时更新，$\alpha$ 可逐层自适应 |
| **AWQ** | 显著通道在校准集上一次性确定 | 显著通道可根据当前 $A_2$ 动态识别 |
| **Czakó et al.** | 分位数在全局校准集上计算 | 分位数可在当前 batch 上实时计算，更准确反映输入分布 |

- **关键优势**：动态等价变换比静态变换能更好地适应不同输入的激活分布，特别是当测试数据与校准数据分布差异较大时。
- **注意事项**：动态计算的开销需要控制在可接受范围内。Czakó et al. 的分位数计算可以通过预排序+二分查找加速到 $O(\log n)$。

### 31. QuaRot / QuIP#（新场景重评）⭐⭐
- **重评原因**：在旧场景中，旋转矩阵 $Q$ 在校准阶段确定后固定。但在新场景下：
  - **RHT（Randomized Hadamard Transform）** 是 $O(n \log n)$ 的快速变换，完全可以在推理时对每个 batch 实时执行
  - 旋转后的量化可以在旋转空间中做更精准的激活感知量化
  - 对于包含大量异常值的输入，可以动态增加旋转次数或切换旋转矩阵

- **关键可借鉴点**：
  - RHT 的快速实现（Walsh-Hadamard 变换）
  - 旋转空间中量化误差的理论分析
  - 旋转矩阵与量化精度的关系

## 四、第三梯队：理论基础与精度上界

### 32. GPTQ（新场景重评）⭐
- **重评原因**：GPTQ 的 Hessian-guided 逐列量化原本需要校准数据估计 Hessian $H = A_1^T A_1$。但在新场景下，Hessian 可以用 $H = A_2^T A_2$ **实时估计**，使量化顺序和误差补偿完全适配当前输入。
- **限制**：实时计算 $H^{-1}$ 的开销为 $O(d^3)$，对于大维度不现实。但可以用以下近似：
  - 对角近似：$H^{-1} \approx \text{diag}(1/h_{ii})$
  - 分块近似：将 $H$ 分块，每块独立求逆
  - 仅对关键层（首层/末层）做在线 GPTQ，其余层用更快的方法
- **适用场景**：作为精度上界参考，或用于对精度特别敏感的关键层。

### 33. FlatQuant（新场景重评）⭐
- **重评原因**：FlatQuant 的可学习仿射变换原本在校准阶段训练好后固定。在新场景下，可以将仿射变换的参数化为**条件网络**——以当前激活统计量为输入，动态输出变换参数。
- **实现方式**：训练一个轻量级 MLP（~1K 参数），输入为当前 batch 的 $[\text{mean}, \text{std}, \text{max}, \text{quantile}_{0.99}]$，输出为仿射变换的 scale 和 bias。
- **限制**：需要额外的前向计算（但参数量极小，开销可忽略）。

## 五、技术路线重构

### 5.1 新旧场景技术路线对比

| 技术路线 | 旧场景角色 | **新场景角色** | 代表论文 |
|----------|-----------|--------------|----------|
| **Per-token/batch 动态量化** | ❌ 不存在 | ✅ **核心方法** | Atom, QServe, LLM.int8() |
| **等价变换（Smooth/Rotate）** | 离线固定 Θ | **在线动态重算 Θ** | SmoothQuant, AWQ, Czakó+, OmniQuant |
| **异常值处理** | 离线识别 + 固定掩码 | **在线检测 + 动态混合精度** | LLM.int8(), DuQuant, SpQR |
| **混合精度/显著性** | 全局固定位宽分配 | **per-input 条件位宽分配** | SliM-LLM, ZeroQuant-V2 |
| **旋转/不相关化** | 离线固定旋转 | **在线快速 RHT** | QuIP#, QuaRot, DuQuant |
| **Hessian 重建** | 离线校准 | **在线条件 Hessian（精度上界）** | GPTQ |
| **可学习变换** | 离线训练固定参数 | **条件化动态变换** | FlatQuant, OmniQuant |
| **蒸馏/QAT** | 仍适用 | 仍适用（作为基础模型增强） | QAD, BitDistiller |

### 5.2 新场景下的量化流程
