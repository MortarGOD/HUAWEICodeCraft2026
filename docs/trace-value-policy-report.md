## 两个训练方法

1. **近似梯度**：Adam学习全部121参数，30轮；实际前向为合法量化，反向使用identity STE近似。训练及留出未得到优于父版的检查点，按预设保留epoch0，50题逐值不变。不能把训练代理梯度当作真实离散方向。
2. **真实离散目标**：固定随机特征层，仅搜索13个输出层参数，三轮步长0.25/0.125/0.0625，每坐标比较±方向，实际训练目标下降才接受。第一轮接受3个更新，后两轮没有接受更新。以留出校准选择第一轮模型，未使用test选步长或参数。
