# 参考Attention历史数据集的新回执验证

20组实体数据、28个不同测试用例，两套整数权重各合计250题。实际重测v435、v441–v444，共100份版本/组结果；新回执未参与权重拟合。源文件SHA与70位Decimal加权复核通过。

| 版本 | 线上相对435 | 原始整数权重增量 | 参考默认权重增量 |
|---|---:|---:|---:|
| v441 | +4 | +29.76 | +89.28 |
| v442 | +1 | +29.76 | +89.28 |
| v443 | +0 | -20.11 | -5.18 |
| v444 | +0 | +46.06 | +71.11 |

两套方案都无法区分441与442，也不能重现443/444与435同分。默认权重收益排序441=442>444>435>443，与线上441>442>435=443=444不符。以小变化允许1分误差计，四条幅度均不通过；±5分也均不通过。

Linear固定4450时，原始整数权重对四版总分约15071–15138，默认权重约13983–14077，远低于线上21304–21308。用435线上回执平移基线也不能修复增量误差。

历史98边用原始源cell的代理复核：原始整数权重方向73、幅度54、联合37；默认方向70、幅度45、联合30。实体attn.pt有17个校准张量与原始源不同，因此这些历史数不是实体bank完整重测结果，不能作为精确验收。

结论：该bank可用作机制回归与整数题数格式示例，不宜作为当前线上精细估分或候选排序的唯一依据。需要在实体数据上补齐全部历史版本才能给出准确全历史匹配率。
