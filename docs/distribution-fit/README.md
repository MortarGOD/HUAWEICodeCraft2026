# 线上回执驱动的Attention分布拟合

用户已指定：剔除只改Linear的样本；涨跌方向一致，增减分误差≤15%，微小变化允许1分误差。原120条有效回执，经源码依赖与版本记录交叉检查，排除18条，只评测保留的102个版本（含基线）。不删除负例或同分Attention版本。

## 已冻结的输入与规则

- manifest.json：全部120条标签、保留/排除原因、源码SHA256、两类API依赖指纹。依赖指纹读取实际绑定及全局函数/常量，解包装饰器，只跟踪LOAD_GLOBAL/LOAD_NAME；不是一般反射程序的数学等价证明。
- targets.json：纯Linear对照用于消除总分偏移，不参与Attention拟合；v287/v293跨组Linear锚点仍未识别。它们仍运行，组内差分保留，不能把缺失跨组信息算作匹配。
- 用户已确认按实际研究父版验收。102个保留版本对应98条有效父子约束；v277/v283/v287/v358的父版没有完整有效回执，单独标记。被剔除的纯Linear父版仍使用其真实回执，Attention测量借用依赖指纹相同的保留版本。
- 所有版本共享非负、和为1的数据分布权重，不使用每版本修正系数。98条实际父子差分约束均逐条输出；绝对总分含Linear，不能直接当Attention分数。

## 第一轮

从缓存模型投影重新生成12个基础分布：两类模型×基础/弱logit/强logit/V尾部/偏置key/V均值。各自交叉paired、row_permute、block_resample协议，共36个场景。paired仅诊断；其余24个场景可参与拟合。每个场景五份校准/五份测试，T=4/8/32/128/512。固定源码和数据哈希，每次角色仅保留自己的state，动态接口独立模块、独立state拷贝，验证合法输出及输入/state不变。每单元单独进程、900秒本地超时，失败完整保留，不作数值插补。

历史临时相邻口径：第一批7个完整场景匹配16/100条，36条目标在该支持集凸包投影之外；该匹配率已废弃。实际父版口径重算：8个完整场景匹配29/98条，尚未满足验收。例如310→311目标−4995，支持全部为正。该事实否决“只调这7个场景权重即可匹配”，不否定所有可能分布。

## 第二轮扩展

依据上述方向失败，加入0.05/0.5尺度噪声的相关假对端假设，并引入两套真实短trace来源与原投影来源、gain1/4，共12个新场景。生成过程不读取任何候选输出。真实trace重复使用，不冒充独立留出；未知假对端相关程度是待拟合的假设。先在15个关键版本形成方向证据，再补齐全部102版本。

## 样本级分布与缺口诊断

`fit.py --case-mixture` 允许组内测试样本分别加权，保留原始校准数据；所有版本共享同一权重。以组级拟合权重初始化，避免扩展支持集后从较差起点重新求解。该结果属于训练拟合，不能作为独立验证。

`screen_support.py` 复用尚未补齐整列的测量，逐条检查目标是否落在已测样本差值范围。不同边可能使用不同的可用支持，因此范围覆盖不代表共享权重可行。当前快照98条中22条仍超出可用支持；需要继续扩展数据，不可仅反复调整现有权重。

## 第三轮：参考数据组覆盖

两个参考数据集分别有10/50组，前一轮只用了各自第0组。第三轮固定选择另外5/7组，分别使用相关噪声和行置乱假对端，共24个场景。先测30个关键版本，再补齐有用场景的完整矩阵。生成器不读取候选输出；保留数据来源hash、组号与随机种子。

## 求解数值稳定性

已验证反例：A=[[1e8,0,0],[0,1,-1]]，目标[0,0.5]，容差[1,0.01]。原FISTA在100000次后第二项仍约0.0012，漏掉已知可行解。新增`fit.py --case-mixture --solver admm`以行范数缩放并分裂区间与单纯形约束，同反例11次通过；专项测试保留。真实矩阵45个样本列的交叉检查仍仅26/98通过，未找到可行分布。两种求解失败均不是不可行证明，继续扩展支持；ADMM报告单独保存，不覆盖FISTA结果。

## 第四轮：定向幅度扩展

round001的sink/block_resample长序列样本使v310→v311下降约1878分，仍不足目标4995分。第四轮在相同来源上增加sink/tail幅度，共4个场景；先测310/311，保留不利结果，再据效果决定完整矩阵扩展。所有变换发生在NVFP4输入构造阶段，评分与版本代码不变。

第三轮增量：trace35-group3-row_permute补上v388/v390/v393的负向幅度范围，已提升为完整102版本矩阵评测。`run.py --atoms`可只补齐指定场景，使用独立进度文件；原筛选任务已越过该场景，避免同一单元并发写入。范围覆盖不等于共享权重可行。

第五轮准备4个低秩强协方差场景（rank8/32、strength4/16、固定32/128 tokens）。其中rank8/strength16/128对v367的诊断已通过格式检查，三次独立校准均产生Q/K GPTQ状态，但OJ接受头数仍为0；前置状态覆盖改善，尚无新增分支收益证据。其余场景待测。诊断保存在diagnostics/v367-lowrank.json。

有限支持可行性检查：新增分离不等式证书，比较约束区间上线性函数的最小值与所有数据列上线性函数的最大值。60个完整样本列快照差距9148.9682，数值保护界0.0002407，确认当前有限支持不可行；不外推至未测数据。证书保存在support-separation-60-columns.json。已验证单条范围都覆盖但联合不可行的反例，以及可行反例不会被误报。
