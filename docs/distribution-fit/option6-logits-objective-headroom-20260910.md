# Option 6：logits 目标下的 Q/K 编码余量（2026-09-10，goal round 7）

## 0. 问题

官方 `mini_sample` 上 Q/K 占 attention 残差 87.2%（round 6），且与 openaddr 独立测得的
判题器口径 71–85% 吻合。我们已确认 Q/K 侧合法杠杆只剩「基础量化」与「Q/K 联合正交变换」，
且后者在 64 个 Hadamard 种子里 seed 0 最优、已穷尽。

那么 Q/K 侧究竟是「已经到边界」，还是「我们的编码目标选错了」？目前基础量化器最小化的是
**逐张量重建 MSE**，而真正进入输出的是 **logits `Q Kᵀ`**。本轮直接量化两者之差：
如果把码字选择的目标从逐张量 MSE 换成 logits 误差，能拿回多少？

## 1. 方法

`tools/probe_logits_vs_mse.py`：取部署路径实际返回的旋转坐标下的 `Q̂/K̂`（六 API 原样调用），
在 S1P2 格点上做 **单调行块坐标下降**（整行提议 + 折半线搜索，接受条件是该行块误差严格下降），
目标为 `||Q̂ K̂ᵀ − Q Kᵀ||²`，每元素每次最多走一个码步，3 轮。

**这是 oracle 上界**：搜索过程用到了真实对端的码字与真实 logits 目标，因此它不是任何合法
编码器能达到的值；它只用于给 Q/K 侧的**可达空间**定标。

### 本轮修掉的三个实现错误（都会让数字失真）

1. **K 侧必须换到转置坐标系。** `greedy` 里 `x` 是第一个因子，直接复用会去拟合 `K̂ Q̂ᵀ`
   对 `target`，而被打分的是 `Q̂ K̂ᵀ`；两者只在 `target` 对称时相同。改用
   `K̂s[j] Q̂[h]ᵀ` 对 `target[h]ᵀ`（Frobenius 范数完全相等）后才是同一个目标。
2. **GQA 复制的 K 行必须联动。** `repeat_interleave` 出来的 8 份副本若各自独立移动，
   得到的就不是任何合法编码器能输出的 K 张量。改为每个 KV 行只走一步，方向取组内梯度之和、
   曲率取组内每通道曲率之和。
3. **`kd[:kh]` 不是 KV 头切片。** `repeat_interleave` 之后前 `kh` 行全是**同一个** KV 头
   （kh=2, g=8 时是 head0 的两份），必须写 `kd[::qh//kh]`。此前 K 侧是从一个退化张量出发的，
   所以出现「内部目标单调下降、外部指标反而暴涨 3000%」的自相矛盾。

自检：修完后「正向目标 = 转置目标」的相对偏差为 **5.0e-08**（mini_sample）/ **3.8e-08**（镜像库）。

## 2. 结果（logits MSE，相对部署码）

| 库 | 部署码（逐张量 MSE 选码） | 只重搜 K | 只重搜 Q | Q+K 都重搜 | 可达余量 |
|---|---|---|---|---|---|
| **mini_sample（官方）** | 8.008e+01 | 3.140e+01（−60.8%） | 7.928e+00（−90.1%） | **2.372e+00（−97.0%）** | **97.0%** |
| structural-v3 镜像 | 2.990e-02 | 1.500e-02（−49.8%） | 1.196e-02（−60.0%） | **3.028e-03（−89.9%）** | **89.9%** |

两个库、两种角色结构，结论一致：**逐张量 MSE 选码在 logits 目标上离最优极远**，
Q 侧单独就有 60–90% 的余量。

## 3. 为什么这仍然不是可用机制

- 搜索需要**对端的码字**（`other`）与**真实 logits 目标**。动态接口只给当前角色自己的输入与
  state，且规则不允许跨角色共享缓存、调用顺序或可变全局状态（AGENTS.md 信息边界）。
  因此这是一条 oracle 通路，不是候选。
- 更要紧的是，**这份余量在合法先验下会整体消失**。设对端 `k̂ = k + e_k`，`E[k kᵀ] = σ²I`：

  ```
  E_k || q̂ k̂ᵀ − q kᵀ ||²  =  σ² || q − q̂ ||²  +  σ_e² || q̂ ||²
  ```

  即各向同性对端下，logits 目标**退化回逐张量 MSE**（只差常数权重）。所以上面 90–97% 的
  余量**全部来自对端各向异性的那部分**——恰恰是动态接口让我们看不到的部分。
  这与 QKS 守门在官方校准数据上判 `stab = 0.0597`（无可重复通道结构）是同一件事的两面。

## 4. 与 23000 的关系

- Q/K 侧：跨 token / 跨通道的耦合结构是唯一有量的余量，而它需要不可得的对端信息。
  合法子集（固定正交变换、基础量化）已穷尽。**当前架构下 Q/K 侧没有可交付的机制。**
- 因此想从 attention 拿到 round 6 估算的 ~1146 分，必须出现**新的接口内合法构造**，
  而不是在现有旋钮上继续搜索。
- 已确认可交付的余量仍只在 Linear 的 M>K 宽组（本地 +1232，按 0.79 折算约 +973 线上），
  单独不足以到 23000。
