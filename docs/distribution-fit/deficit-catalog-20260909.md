## 两类失败，处理方式不同

**A. 幅度不足（预测接近 0 或方向正确但太小）**，需新增*更强/更纯*的对应机制支撑：
310→311、283→302、306→307、322→365、322→374、419→426、321→322、400→407、400→411、
387→392、322→367、308→309、310→314、400→401、387→399、387→393、365→381、381→382、
412→413、412→419、403→404、387→388、387→389、435→436。

**B. 幅度过强（预测远超容差）**，是当前某些原子（如 correlated_noise、sink/block_resample）在
少数边上的极端原始质量差被联合拟合放大：283→284(−53804)、322→333(−66736)、322→364(−205)、
303→305(2348)、303→306(2592)、365→379(23)。这些需要**不牺牲已匹配边的前提下降低这些原子在高杠杆
test 上的单列极端值**，或用更纯的机制原子替换。

## 关键判据（本轮独立验证）

- v311 去重行原子 `round038/repeat00-first-paired`：321→311... 经全 98 边向=只在 310→311
  驱动 −63344pt，其余 97 边**精确 0.0**（完全解耦）。它已在 645 基中但权重被置 0。
- 用它补 #1 缺口需权重 ≈ 4995/63344 ≈ 0.079；该权重重归一化会按 (1−0.079) 缩放其余列，
  把若干 near-zero 方向边翻转，导致 barrier phase-I 报 `trial_direction_failures` 大列表。
- 因此不是"再加一个 v311 原子"能解决的——而是需要一个**幅度介于现有原子与去重行极端之间**的
  新支撑原子（较弱强度、同机制方向），使其以≤15% 容差收敛到 −4995，同时可被其它边抵消。
