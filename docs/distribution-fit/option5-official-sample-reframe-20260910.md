# 重大修正：官方样例上 Q/K 占 attention 误差 87%，我们此前的镜像库是反的（2026-09-10）

## 1. 决定性诊断：在官方 `mini_sample/attn.pt` 上，整套机制全部关闭

对 v435 与 v501 在官方样例上做校准并 dump 全部调试状态：

```
CO_DEBUG      {"order":"OJ-KT-TS", "oj":{"accepted":0}, "kt":{"accepted":0}, "ts":{"accepted":0}}
JOINT_DEBUG   {"balance_heads":0, "kernel_heads":0}
QKS_DEBUG     {"fitted":true, "accepted":false, "stab":0.0597}     ← public_quantizer 上是 0.871
TEMP_DEBUG    {"heads":0}
VM_DEBUG/VR_DEBUG  {"accepted":0}
q_state keys = ['kvh','rot','rseed']      ← 没有 gq / u / H / qs / joint_transform / temperature_gain
k_state keys = ['kvh','rot','rseed']
```

**官方样例上的部署路径退化为「一次 Hadamard 旋转 + 基础量化器」**，连 GPTQ(`gq`) 都没有。
原因：`QKS_DEBUG.stab = 0.0597`（跨校准样本的通道结构相关性），
远低于门槛 `QKS_STAB_MIN = 0.5` —— **官方校准数据没有可重复的通道结构**，
所以每个守门都判它是在拟合噪声并拒绝。

这解释了为什么**所有版本在官方样例上逐位相同**（v441/v445/v504/v519/v521/v525/v529/v610/v613/v615/v621/v622/v623 的增量全部恰好 0.00000）。

## 3. 结构不可知杠杆在官方样例上全部无效或有害

| 版本 | 改动（都是不依赖校准结构的） | 官方 mini_sample |
|---|---|---|
| v513 | 扩大每 block 尺度候选网格 | −0.0009 |
| v621/v622/v623 | 旋转候选 8 / 16 / 64 | **恰好 0.00000** |
| **v624** | 强制打开 Q/K 的 GPTQ（跳过守门） | **−0.0455** |

- 旋转：seed 0（原 Hadamard）在 64 个候选里仍是最优 → **规范自由度已穷尽**。
- 基础量化器：官方数据上已接近最优（v513 ≈ 0）。
- 强制 GPTQ：更差 → 其校准 Hessian 在无结构数据上是噪声，守门判得正确。

## 4. 由此得到的架构性判断（Q/K 侧的合法杠杆可能已穷尽）

在「无校准结构」的口径下，Q/K 侧可用的合法手段只有三类：

1. **基础量化**（逐 block 精确枚举）——已接近最优；
2. **Q/K 联合正交变换**——数学上是唯一能在保持 logits 不变的前提下改变量化几何的自由度，
   且 Hadamard 在 64 个候选中最优，**已穷尽**；
3. **校准拟合型**（GPTQ Hessian、QKS 平滑、温度、key translation、联合变换、逐头精化）
   ——在无结构数据上被守门（正确地）拒绝并失效。

Q/K 的合法变换必须是正交的（非正交会改变 logits），而单独作用于一侧的任何变换都会改变 logits
且动态接口不允许跨角色补偿。**因此 Q/K 侧在我们当前架构下确实已到边界**，
尽管它持有官方样例上 87.2% 的残差。

## 5. 与 23000 目标的关系

- 官方样例得分 0.155，而线上 attention 若按 `linear=4450` 推算约为 0.674 —— **官方样例远比线上难**，
  所以它的绝对值不能用于线上估分；但它的**角色结构**（Q/K 87%）有 openaddr 的独立测量佐证。
- 我们的两个大杠杆族（Q/K 逐头 Hessian 精化 +1841 本地 → 线上 −78；V 侧 kernel +398 → +9）
  都是"校准拟合型"，按 openaddr 的定理永不迁移，**已被线上回执证实**。
- 结论：**要在线上拿分，必须找到一类既结构不可知、又能在保持 logits 的前提下改善 Q/K 量化的新机制。**
  这需要新的数学构造（例如利用 logits 的等价类而非逐张量 MSE 的量化目标），
  而不是继续在现有旋钮上搜索。
