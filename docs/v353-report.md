# v353：v351风险学习/缓存与v352稳定恢复合并

v353以v351为父，只将 `_joint_raw_metric` 无H分支的 `cholesky_inverse(U)` 改成等价的上三角求解：`R=solve(U,I)`、`Hd=RRᵀ`，再沿用原阻尼移除。它保留v350的V条件概率因子风险、v351校准内精确K缓存和精简guard，同时带入v352定位的恢复稳定性修改。

Linear、Q/K/V动态量化函数、候选数、搜索轮数、阈值、state结构均未改变。没有合入全Query、跨序列辅助、统一基线选择或双精度实验。

## 验证

- 实际v353相对v351：除模块说明外，AST仅 `_joint_raw_metric` 改变；禁止模块和动态文件/执行调用扫描通过。
- 三角恢复96项数学/状态检查通过，最大相对误差3.04e-7；已有H快速路径逐值保持。
- 官方self_check：接口6/6，Linear和Attention输出格式22/22。
- 实际v351/v353在feedback与covariance各6组、合计60例配对回归逐例同分，总增量0；27项结构/状态检查通过。
- 配对校准单轮合计23.72秒（v351）/25.29秒（v353）；v353首组包含明显冷启动。去掉首个配对后为20.56/19.20秒。该噪声较大且不是完整运行，不宣称加速或退化百分比。

本地代理预估精度与v351相同；如果线上触发本地观察到的无H恢复异常，v353可能更稳定，否则可能完全同分。线上分数仍以已知v324约20803为参考，不能从本地风险增量外推到22000。动态预算不变，但总时限300秒仍需线上验证；v351此前仅有低置信265/267秒条件情景，不是保证。
