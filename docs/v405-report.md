## 复盘与方向改变

v404=21137/263秒，比当前最佳v400=21204/257低67分且慢6秒；该分母消融淘汰。用户提供对手22775/281秒，差距1571分，无法从总分猜出对手算法。最近将局部微小代理增量不断发布，证据强度不足，停止v403/v404路线。

本版以v402（线上与v400同分的数值稳定实现）为父。Linear、父Q/K与既有V策略保留，新模块放在完整父校准之后，不再重拟合后续Q/K。不同于原核只求P(Y−X)或VR固定线性残差回归，本版明确求解两个不同算子下的P_quant Y−P_raw X。

## 算法及限制

1. 最后两份符合4≤T≤4096的非末校准样本、每份最多128个对齐行，拟合共同V-PCA特征（秩≤64）。分别回归原始Q/K和父版真实量化Q/K，形成两个双线性核。两个核使用同样样本、特征和阻尼。K逐序列常量先移除（softmax不变）。高宽V使用≤256行的对偶Gram，避免新增大通道平方特征分解。
2. 动态仅有当前V与冻结state：最多4个当前Query特征，四个共享Q残差sigma情景，预测P_raw/P_quant。每KV因子行数≤128；D>256、QH>128、QH/KVH>32、缺少GPTQ、样本不足或T>4096回父。模型无法知道真实当前Q/K；共享残差场景不等于真实误差联合分布。
3. 令a=P_quant、b=P_raw，目标为||aY−bX||²/R + η||Y−X||²/R。η=R/T²+0.05×mean_diag(aaᵀ)。连续解X+aᵀ(aaᵀ+ηI)⁻¹(b−a)X，经可观测量化噪声的2倍RMS截幅产生起点；固定父版合法尺度，4轮码字候选搜索。
4. 按实际打包表示对应的代理成本择优，每列MSE≤父输入误差1.5倍；未激活头逐参数不变。1.5比原核1.05宽，是本版候选空间改变之一，不把全部收益归因于双核。
5. 最后一份校准保留完整K/V、最多64Query，实际父Q/K及候选V输出误差在奇偶两折均下降0.5%才按KV头采用。该样本未用于新增双核拟合，但用于过父校准，因此不称完全独立验证。测试不访问任何当前对端输入、文件、共享缓存。

状态只增加两个FP32核、BF16特征/残差模式、布尔mask以及原V fallback；只使用CPU允许类型，无梯度。纯算法没有新增导入。已有父动态计算仍执行，候选有额外成本，不保证300秒内。
