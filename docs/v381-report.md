# v381：同模块、不同组合顺序

最新线上回执：**21099分/250秒**，对v365 +65分/−7秒。下文保留提交前本地记录；本地负增量没有迁移为线上负增量，当前线上已确认该组合顺序的净收益。

## 为什么做

v380线上21032/288秒，未优于v365=21034/257。用户提出组合优化视角，本轮不再叠训练/搜索，而是检验当前模块的选择顺序：已验证有效的模块，其组合不一定单调获益，也不能声称原顺序已到极限。

原v365：共同早期变换、温度及V处理 → K平移KT → 加权Lloyd平移TS → Q输出Jacobian Gram OJ。

v381：同一共同早期状态 → OJ → KT → TS。

原顺序按旧Q为K选平移，随后Q更新但K不重新选择；新顺序让K选择看到最终OJ-Q。相反，新顺序选择Q时尚未看到最终平移K，同样可能劣化。因此这是两种条件优化次序的实测，不宣称重排数学上必优。每模块只执行一次，无双完整组合竞赛、无新增动态搜索。

历史probe_qk_order_ablation是删除温度/平移的消融，不是本轮模块重排；不声称已检索穷尽所有历史组合。
