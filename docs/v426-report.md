## 实现与发布

改变 K refinement 风险为 `tr((E-mean(E)) H (E-mean(E)).T)`，消除 token 共同偏差的风险惩罚。新增三个 K 调用参数与独立求解器；其余父 AST 相同，Q 路径复用原函数。HiF4 格点、父 H/GPTQ、原轮数、KT/TS 和真实输出守门保留。后续校准决策可能被 K 输出间接改变，不能把代码范围误说成 Q/V 最终 state 恒等。

整批候选的精确二次增量包含 `-sum(D).T H sum(D)/T`，批次不下降时只取每 head 最优单 token。生产保留有限轮数及 active-set 冻结；20 个固定合成样例另与同轮数全行重检比较，保留全部差异，不称为全局最优或输出无损保证。

7 项机制检查通过：[原始 JSON](v426-mechanisms.json)。其中两 token 反例：父逐行风险没有有利改码；quotient 允许单个 token 改变；两行同时各自改善会造成整批退化，新增检查正确只留一个。合法 BF16 格点上的真实 softmax 输出 SSE 随之下降。还覆盖64个fp64单/多token恒等、T=0/1/2、GQA、false路径逐位相同、三个独立角色校准、fresh module倒序重放及输入/state/RNG不变。

## 固定父状态揭示的主要失败边界

观察到协方差组3/7的大幅退化后，以同一个父state、相同Q/V和坐标系，只替换K求解器，再跑两组全部10题。父MSE逐题复现原配对报告，没有混用不同坐标系的Q/K。

| 对照 | 两组10题原始质量增量 |
|---|---:|
| v426完整重校准 | −0.664957168 |
| 冻结父state，仅子K求解器 | +0.001461714 |

因此这两个组的主要损失与重校准后的决策组合有关，不能全部归罪于quotient目标；也不能据两个事后选出的组宣布冻结校准普遍提分。固定state组7/T512仍有约−0.000072的小负例，二次风险降低不等于最终输出单调。原始对照见[固定状态诊断](v426-fixed-state-diagnostic.json)。

冻结行近似也保留实测边界：20个固定合成种子中16个不及同轮数全行重检，4个相同，最坏相对差约34.73%；两者都不是全局最优。这不是全部线上误差的上界。当前主要反证在校准组合与成本，不继续围绕该近似加轮数出版本。

## 成本与最终处置

全量计时含轻量统计，父/子轮换执行顺序：

|---|---|---|
| feedback 50组/250题 | 199.554 / 90.179 | 219.530 / 93.335 |
| covariance 50组/250题 | 295.876 / 65.365 | 317.332 / 72.754 |

另去除全部调用统计，固定feedback组0/25/49、两轮轮换顺序复测：接口合计分别 **21.744→30.236秒（+39.06%）**、**21.886→28.780秒（+31.50%）**，说明不能把全量约8%的增幅当通用上限。该子集代表性有限；数值是本机秒数，不是线上耗时预测。

固定合成强制helper中位耗时：T64/H4/D64为5.21→7.79ms，T512/H4/D256为22.00→55.54ms，T2048/H2/D256为24.21→51.16ms，T4096/H2/D512为89.49→230.49ms。完整批次接受与均值耦合确有代价，不能称为免费优化。

结论：实现和数学专项成立，完整输出大范围改变，但质量跨bank不稳定且存在时间风险。**保留v422研究基线，v426不合入默认入口；尚不能可靠估分或保证300秒。** 该版包只作为有明确风险的独立对照。后续把校准分支选择与部署求解的耦合作为必要检查项，主攻队列仍转向V完整token曲率与Linear表示空间联合重建，不继续调这版的搜索轮数、top-k或守门阈值。
