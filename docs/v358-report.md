# v358：因子空间内PSD度量 + 行空间外位置谱

## 方法

父版固定为v353，Linear、Q、K以及V的HiF4编码与8轮搜索不变。v358合并两个都独立通过留出的最终输出风险模型：

1. v357：将全部校准部署概率`P`投影到16个V条件因子，学习16×16 PSD相关度量，修正自适应因子行空间内的权重和相关性。
2. v356：加入4个归一化位置SVD方向，以5%风险权重补充自适应因子行空间外的attention sink、局部性和长程相关。

动态风险满足`H = 0.95 H_metric + 0.05 H_spectral`，rank为20。新增状态是有限float32 CPU Tensor `metric_transform[KV头,16,16]`和`spectral_basis[KV头,4,64]`；测试阶段不读取Q/K。

## 结果

- 初筛12组：+0.024557，显著高于同集v357的+0.011756和v356的+0.010685。
- 完全未参与选择的20组：+0.007063，高于v357的+0.004539和v356的+0.003442。feedback为3升/0降/7平。
- 正式实际文件26组、130题：+0.031789；v357同口径为+0.015230，v356为+0.013793。
- 133项结构、双层Gram恒等式、状态和配对回归检查通过。

代理由checkpoint投影权重和建模激活构成，不能把这些增量换算为线上分数；只有线上回执能判断是否向22000迁移。

## 多校准负结果

同时验证了将因子训练从2份扩大到所有前置校准：单独因子模型初筛−0.008328；与PSD度量联合初筛−0.001481，独立留出−0.009210。虽然训练集feedback正向，但留出group 2明显退化，故没有按长度路由或生成额外版本。v358仍使用v353已经验证的2份训练+末份守门。

## 性能

六组正反顺序测量存在显著首运行冷启动：

- 首运行位置：v353 35.040秒，v358 31.319秒。
- 次运行位置：v353 25.588秒，v358 25.109秒。

两个相同位置都未观察到性能回退，但差值包含系统噪声，不能宣称加速。算法上动态rank由16增至20，风险乘法部分增加25%，其余Q/K、未采用头和搜索轮数不变。线上300秒仍须实际验证；条件参考约280秒，不是保证。
