## 与当前父v435的相关差异

1. **信息性留出序列**：末份T≤1时改用最后一个满足4≤T≤4096及T×QH×D预算的校准序列作为末份，其余样本相对顺序保持。T=1的P恒为1，无法识别Q/K变换优劣，条件成立。本地覆盖扫描mini_sample有1组触发；两个50组建模bank、Qwen3.5和Qwen2.5捕获型bank均0组触发。不据mini改善推出线上有同类样本。更换留出同时改变训练样本集合，不能声称只改guard。
2. **矩阵计算替换**：配平T已有eigh时用同特征向量和特征值倒数得到T^-T；_vr_fit用Cholesky solve；_oj_state通过上三角求解恢复U^-1 U^-T。公式成立不保证浮点逐位相同，也不能把参考Windows/MKL故障归为本项目线上根因。此前本地因子审计仍有未定位上游负谱，不能认为这三处足以修复全部问题。
3. **新增K不确定性风险**：留一序列回归Q/K关于V的残差，K逐序列去均值，协方差保留64主方向加同迹各向同性余项。Q保留非零残差均值的二阶量，但省略预测Q与残差均值交叉项。风险为平均||pE||² + variance×||[diag(p)−ppᵀ]E||²，再加SSE/T²。每头当前V生成概率与方差，不访问当前测试Q/K，不缓存跨角色信息。它区别于父版仅Q sigma情景，是下一结构性迁移重点。
4. **V9求解器**：在同一K不确定性风险下构造显式T×T矩阵，单码梯度按矩阵列增量更新，最多128步；再做邻近三SF、完整内层树、每64通道块每轮至多一个token、8轮尺度搜索，原SSE1.05预算贯穿两个阶段。V9参考正式500题与V8误差全等，构造大头32题仅6题微增，不把这部分作为突破主攻。
