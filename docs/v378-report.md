# v378：校准 K 量化响应的完整通道映射

## 事实与范围

父版 v324，Linear/K/V 和动态搜索预算不变，不叠加 v375/v377。已核对历史 `query_distill_core.py` 的逐通道 gain/bias、v363 的逐通道 Q→K 补偿，以及父版 reciprocal joint transform。这里是不同的 Q-only 全矩阵响应拟合，不声称已穷尽全部历史代码或论文。

## 数学与实现

每个 KV head 用倒数第二、第三份校准序列的连续变换后 K 与实际部署量化 Khat。分别去除每条序列的 token 均值，排除 softmax 不敏感的公共平移。

拟合 `min_M ||Khat M.T - K||²/N + λ||M-I||²`，`λ=0.1 mean(diag(Khat.T Khat/N))`。其正常方程精确求解，测试 Q 使用 `Q M`。强度 0.5/1 两个候选都经最后一份独立校准序列完整 K/V、32条 Query 的真实最终输出两折验证；每折至少改善0.5%才启用。公共缩放和温度保持父版；M合入原 Q 变换，无第二次矩阵乘（原来无变换的头会新增一次）。动态无需当前测试 K/V 或共享缓存。

该目标只拟合校准的线性 logits 响应，不等于最小化测试 softmax-V 误差。拟合噪声、Q 再量化和分布变化都可能抵消连续域收益。

## 验证结果

- 64/128/256维：正常方程、恒等输入、公共平移不变性、训练误差下降、融合变换一致性均通过。
- 实际 standalone 官方 self_check：22/22；AST 未导入新增禁用模块。
- 最终文件九组45题同父状态配对：全部同分，九组全未通过守门，无异常回退。父144/候选180项校准/返回格式检查通过。
- 不能把同分解释为路径未执行：所有九组都完成拟合和两个候选验证；部分头平均误差下降但未通过两折门槛。保留每组比例于 `v378-paired-screen.json`。
- 配对计时20.329→28.895秒，父校准在外部只做一次、不在这些计时内；不构成整场耗时估计。候选有额外校准成本，没有本地精度收益，不保证线上300秒。

## 决策

按用户“本地无收益但线上未验证也交付”的要求，保留低优先独立探针；不取代默认入口，不合入主线。优先提交已有正向证据的 v375/v377。线上分数未知，22500目标未完成。

下一步修改方向：若继续此类补偿，需直接拟合最终输出或按概率敏感性加权，而非继续加大同一线性 K 重建强度；还需先核对既有非线性 Q 原型，避免重复。V 主导组不能靠本候选解决。
