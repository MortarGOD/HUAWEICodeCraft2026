# 无变化快路径假设被否定；Attention瓶颈重新定位

本轮未出v376，不向生产加入未经证实的启发式跳过。

## 1. 精确无变化判断

tools/probe_metric_noop.py检查六组0/24/25/34/47/49的最后校准。候选Query与父Query均不逐值相同，改动485–1023个元素，最大改动0.15625–1.25。即使最终输出比值几乎1，也不是代码没改或空分支。因此不能通过torch.equal快路径节省这些组的K/V验证；没有用近似相等替代严格相等。

## 2. 同坐标、全Key的误差拆分

复用tools/attention_error_budget.py，以v324为父，每题至多32Query、保留全部Key，六组共30题。原概率P和量化概率Pq分别从配对Q/K构造，不混用原始Q与变换K。FP64恒等式为：

E=PqVq-PV=(Pq-P)V+P(Vq-V)+(Pq-P)(Vq-V)。

三项平方及所有带符号交叉项之和与总误差的归一化恒等式最大差8.16e-16。下表以每题标准MSE归一化后求和，再除该组总误差；比例不必和为100%，不是线上得分比例。

|---|---:|---:|---:|
| 0 | 29.73% | 71.71% | 0.003086 |
| 24 | 0.0000149% | 100.0027% | 0.999947 |
| 25 | 0.00000004% | 99.99996% | 0.999949 |
| 34 | 0.0000123% | 99.99973% | 0.999800 |
| 47 | 50.78% | 49.47% | 0.009498 |
| 49 | 52.83% | 47.49% | 0.340262 |

24/25/34是强集中且已基本保持原概率的组；继续改善Q不太可能解决其当前V误差。47/49有明显QK贡献，不能一起跳过。理想QK替换有时略降，反映误差抵消；不能把反事实分数叫可达到的上界。

## 3. 下一步行动

- 不开发无变化快路径探针，因为代表组无命中证据。
- 为性能优先核查父校准已产生的相同K/V输出是否可以在**同次校准**精确复用。需输入和完整state相等、缓存有界、返回副本、finally清理，不允许跨测试角色缓存或仅按Tensor指针匹配。
