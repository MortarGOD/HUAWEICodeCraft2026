## 具体差异

v387的Q量化度量使用部署Q/K/V点的Gauss-Newton项J Jᵀ，并混合50%原Logit度量。v393在相同两份校准、相同16个query位置补上非零输出残差的曲率：

`H = J Jᵀ + Σ_j p_j <r,V_j−o> (K_j−μ)(K_j−μ)ᵀ / d`

其中r=o−原始QKV目标，μ=pK。残差项跨query聚合，避免每条query多做一次Kᵀdiag(w)K。先对称、特征分解，将负特征值截为0，然后继续原50%Logit混合、阻尼和两折输出守门。只替换原_oj_fit，无新动态代码、状态字段、校准候选或Q/K接口依赖。

这是非线性输出损失局部Hessian的PSD近似，不是完整Newton；没有加入梯度更新，也没有证明PSD投影一定优于Gauss-Newton。与v389的常数Q偏移不同。后续KT/TS/TEMP仍在新Q度量选择后重新拟合，因此其状态可能间接变化；不承诺最终K相同。
