# v360：稀疏校准顺序救援

> 线上回执：20803.75分/244秒。相对v324约+0.75分、快2秒，未形成可见精度突破。本地唯一触发组没有代表线上主要误差分布，停止沿RMS/峰值硬门控扩展；以下保留提交前研究证据。

## 线上反馈后的路线切换

v358线上20803/255秒，与v344同分且慢3秒，否决继续扩展V最终输出风险家族。v360回到v321/v322已连续获得+435/+160线上收益的Q/K状态选择问题；Linear以及测试阶段Q/K/V算法保持v324。

## 方法

现有Attention校准用固定样本顺序训练并守门。五个循环移位状态的离线诊断表明，个别分布的完整Q/K/V状态对“哪一份样本作为末尾守门”高度敏感。五候选在10组50题上相对v324为+0.364129，但校准成本不可接受，不能原样部署。

生产实现只读取第一份校准样本的32行：

- 当Query RMS不低于0.8或Value峰值不超过12时，逐值返回原v324状态。
- 仅对低RMS Query、高峰值Value的异常组，额外训练一次循环移位3的完整状态。
- 用原顺序首尾各32个Query的真实部署Attention输出MSE比较两个完整状态，候选总误差至少下降0.5%才采用。
- 返回的是一套完整、内部一致的Q/K/V状态；不混合不同坐标系的H、变换或平移字段。
- 测试阶段执行路径与所选v324状态完全一致，没有新搜索、文件访问或跨接口通信。
