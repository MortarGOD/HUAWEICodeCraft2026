# v432：集中度校准与共享尺度子树使用同一风险

独立父v422，Linear/Q/K及父校准保持；只在返回V state中增加温度与子树联合标记。温度拟合沿用v430，父V重构和子树均使用同一校准后P，最后共用一次末份两折1%实际输出守门，不简单串联两次校准。没有叠加v429，不增加query、sigma或搜索轮数。

单一交互假设是风险模型修复能使尺度树搜索更有效；替代解释是错误集中位置被放大。保留v430/v431独立消融，不能把两版收益相加当联合预测。校准成本仍须线上验证。

子树的1.05倍逐通道MSE帽相对“使用新概率完成父V重构后的输入参数”，不是相对v422最终V的全链统一上限；完整版本与v422的比较由末份真实输出守门及独立测试负责。

三项新增机制检查通过：beta=1的机制样例与v431输出一致；父校准与联合守门各执行一次；活跃头联合风险145.017049→122.093470，修改16节点，非活跃头保持、逐通道MSE帽通过。真实小样本校准与父Q/K相同、无标记动态V等同父、输入/state/RNG检查通过。官方自检结果另存v432-self-check.log。完成格式自检后即刻推送，再做两bank、多假对端与MHA形状压力；尚不能可靠估分。

源码SHA256 `9c2e7579b6e7ebfff64c9c7679a5ceed004d0d94f5d92ed9895dcfa4410f9fb6`；ZIP哈希及路径见attention-campaign-artifacts.json。数学最优性只限选定节点在新尺度上的未约束码提案，MSE帽是额外筛选，不是全部约束组合的全局最优。完整数据与路线上下文见attention-A1-A6实施报告-20260908.md。

温度恒等性检查限于所测概率与格点样例；`softmax(log(clamp(P)))`有截断和浮点舍入，不能宣称所有输入在beta=1时逐位等价。
