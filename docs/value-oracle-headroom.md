# V 固定尺度搜索的离线信息预算诊断

本轮不发布新 solution。Linear、Q/K、默认入口、v348/v349 均未修改。
目标仍是线上 22000，以下不能换算成线上加分或可部署上界。

## 方法与边界

- 父版 v324；固定 native HiF4 尺度，只改 [-7,7] 整数码。
- 使用测试样本实际 Q/K，构造 Pq；仅用于离线诊断，独立 V 接口不能访问这些测试输入。
- `curvature_only` 最小化 ||Pq(Vq−V)||²；`full_output` 最小化 ||Pq Vq−P V||²。后者包含 Q/K 误差交叉项。
- 每通道每轮选择一个精确二次增量最小的码值更新，共 32 轮；不形成 T×T Hessian。
- 六组，每组仅最后一个测试样本 T=2048。抽 32 或 512 个 query，再分一半拟合、一半留出；随机划分固定种子，不改变全局 RNG。
- 数据是 checkpoint 权重配建模激活，不是真实模型 forward 激活。query 留出也不等于跨序列泛化。
- 三组 float64 随机尺寸检查通过合法码值、目标单调；真实数据每个 1/8/32 轮节点校验增量残差与重新计算结果一致、拟合目标不升。

32 query 顺序两折中，组5完整输出留出比为4.2705；512 query顺序两折为2.6864；512随机两折仍为2.2203。
增加覆盖和打散划分只缓解，不能消除该组泛化失败。不能把它简单归因于奇偶位置采样，也不能据此断言线上存在同类组。

## 改变下一步的结论

1. **继续条件曲率方向，但修改表示**：组14/19在此前背景风险守门中拒绝，实际 Pq 的固定尺度搜索却仍能明显改善留出输出；这反对“V码值已普遍到顶”的说法。需研究保留输入相关的非均匀/非对角结构，而不是只增加均匀均值搜索轮数。
2. **暂缓直接跨误差教师扩容**：这六组中，完整输出相对仅曲率通常增量小，组5留出更差。当前证据不足以支持优先花预算扩大跨残差模型。
3. **必须控制稀疏查询过拟合**：更强的真实教师都可能过拟合，故不能把训练目标下降当验收。下一候选须有独立序列守门、query覆盖诊断、正则化/信赖域，并保留失败组。
4. 下一可部署研究：从当前 V 特征和冻结校准状态预测低秩概率特征，保留 `E[PqᵀPq|V]` 的非对角项；与已有 v341 的均值外积+对角近似严格区分。先验证教师/学生候选排序和留出收益，再考虑版本。尚未实现，不宣称新收益。
