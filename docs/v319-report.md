## v319具体改变

1. **不再仅固定V尺度改整数码。** 对父scale_factor枚举前一个合法E6M2值、当前值、后一个值；每个候选重新求64→8→4分组下的lv2/lv3及整数码。不是任意浮点缩放，也不是新建不合法码本。
2. **尺度与输出代理一起选。** 每棵树做4轮均值反馈，目标为`mean(e)^2 + 8/T * mean(e²)`，e=V−Vq。逐token×64块组成候选池，并对全量、最多8行、1行三种更新预算重新计算完整目标；不把单行收益简单相加。每个通道MSE不得超过父版1.1倍（另有极小数保护）。
3. **只在适用的校准头上花计算。** 用最后校准样本的16个query及全部key，计算`T * mean(sum(P²))`。≤16才进入V候选搜索，相当于平均有效key数至少约T/16的筛选；这是分布启发式，不是线上已知比例或收益保证。不使用测试标签、样本编号或模型名称分支。
4. **真实输出守门。** 最后校准样本保留全部key，最多64query，使用父版实际量化Q/K及候选V算softmax-PV；每个KV头奇偶两折均改善0.5%才启用。两折来自同一序列，不保证跨序列泛化。原V kernel/均值反馈仍是回退方案。
5. **只处理启用头。** 动态V先计算父输出，再对选中KV头搜索，其他头直接保留父参数。T=1、T>4096及无启用头均回退。不增加Q/K搜索轮数。
6. **共享步长误差复用。** lv2/lv3的4种组合只有1、2、4三个不同乘积，误差只算3次，保留两级选择与先到者胜出的tie规则。这只是一项等价执行改动，不独立归因线上速度收益。

state只增加启用头布尔向量、variance=8.0和既有V状态的fallback容器；无梯度/优化器/可执行对象。动态仍只访问当前角色输入和校准state。
