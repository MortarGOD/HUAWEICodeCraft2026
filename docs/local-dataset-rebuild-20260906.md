# 本地数据集重审：结构真实性与预测能力分开验收

## 方法与结论边界

本轮把《反对本本主义》的调查要求、《实践论》的实践检验、具体条件和矛盾分析落实为实验约束，而不是用思想标签替代统计证据。工程上的对应关系是：检查输入生成的实际机制；提出能被失败版本否定的解释；冻结生成参数；比较未用于参数优化的算法变化；保留反例。

本轮没有再次通读毛选或马克思主义全部著作，方法来源和此前研读范围见《实践与攻坚方法》。不能由300道题的若干总分唯一反推出模型比例、层号或长度分布；“符合线上”必须是待验命题，不是生成器名字。

## 已核验的本地问题

1. **GQA头对应错误。** Qwen源配置16个Q头、2个KV头，每8个Q头对应一个KV头。原生成器只取前8个Q头，却仍保留2个KV头，评测按4个Q头/KV头分组；后4个Q头因此配错源KV。新生成器在每个源KV组内等额选择Q头，记录源索引；部分组保留全部16头。
2. **投影后人为修改破坏联合关系。** 旧50组中41组含强sink设定，部分压力变换单独改变V或Q/K，破坏原DeepSeek代理的K/V共享关系。82%是旧生成器的配置比例，不是线上统计。新集所有扰动都移到共享hidden上，随后经过同一组真实checkpoint投影、角色归一化、既有部分RoPE和NVFP4转换；不再投影后强塞注意力峰值或二次量化。
3. **目标拟合不可识别。** 旧方案用少量版本变化拟合多种人造分量，额外验收已失败。拟合权重不等于模型出现概率；不能因为某种人造sink能制造−4995分方向，就宣布找到了线上sink比例。
4. **校准顺序混杂。** 旧数据各组固定长度序，末份总是长序列；算法恰好常用末份做选择。新集校准/测试分别打乱长度顺序，部分组长度支持集也不同。校准和测试共享投影、潜在子空间及主题结构，但样本独立抽取。
5. **尺寸和来源不足。** Linear仍是原10组/50题，最大轴2048；不能代表线上4K级及96核耗时。Attention只用了两个模型的有限层投影，hidden仍是模型化输入，**不是模型真实前向捕获**。不通过复制拼接权重伪造真实大矩阵。

## 从线上收益识别机制，而不是套用模型标签

令真实输出为PV、实际输出为P̂V̂，精确误差是：

`E = (P̂−P)V + P(V̂−V) + (P̂−P)(V̂−V)`。

三项的平方不能直接相加：交叉项可能抵消或放大。审计记录各项MSE及交叉项，并核对分解重建误差。

| 线上证据 | 可支持的机制判断 | 尚不能推出的结论 |
|---|---|---|
| v310相对v309 +283；v311相对v310 −4995，均PASS | V的均值修正有用，但进一步极端优化均值代理可能损害真实PV；v311仅更改V，不能归因于Q/K或罚分 | 不能直接认定全部由长序列、单一sink或某模型引起 |
| v365→v381 +65 | 让K搜索看到更新后的Q有净收益，模块次序和依赖工作点值得研究 | 不能推出同一次序对每个head都更好 |
| v381→v382 +60 | 温度与中间V/Q/K选择存在交互，移到末端在本次线上组合更好 | 不能把总收益都归于最后的温度系数 |
| v382→v386 −160；v382→v387 +25 | 纯输出度量未优于混合度量；实际量化工作点有价值，覆盖不足/阻尼/后续工作点变化仍可能解释差异 | 不能宣称已证明纯输出优化不可能，或某个模型占比是多少 |
| v285→v302大增 | 需要验证GPTQ度量、尺度选择和Q/K/V组合对最终输出的作用 | 总分边包含其他差异，不能用总差唯一识别GPTQ单项因果收益 |

V单通道误差的真实二次度量是 `eᵀPᵀPe`。v311使用近似 `I + 11ᵀ`（比例归一化略），只强调普通均值和逐元素误差；若大改码的位置恰好有高attention杠杆，该代理下降仍可能让真实误差上升。关键不是“序列够长”，而是P的非均匀性、P与量化误差的相关性、校准到测试的稳定性。新输入从共同hidden构造这些联系，不再独立捏造Q/K/V。

输出Jacobian近似同样只在局部工作点有效。新审计同时记录概率熵、最大概率、有效token数、Q/K与V误差及交互；这些是可检验的机制特征，不是按版本号或组号部署if/else的依据。

## 新集设计与验收范围

- 50个Attention组，每组5份校准、5份测试；10个Linear组、每组5+5保持不变。
- 2种源投影×5种共享hidden结构×5个种子重复。结构为宽分布、持久低秩、主题簇、公共上下文、主题漂移。**等额覆盖是实验设计先验，不是估计线上比例。**
- Attention长度覆盖64/128/256/512/1024/2048，与Linear步长无关；不宣称线上直方图已知。
- 生成器不读取选手输出或线上分数；生成参数冻结后才回测，不因验收失败重新调整同批数据。
- 完整结构检查：3000个Tensor的有限性/CPU/无梯度，50组正确头映射，DeepSeek代理250份校准/测试保持K/V编码一致，50组校准/测试顺序均不相同，张量文件哈希一致。
- 行为审计用实际10个版本，旧、新各10组50题，共1000次Attention测试。旧组是特征覆盖选择；新组是每个设计分层一组。**两者都不是线上随机抽样，不能乘500推算线上增量。**
- 四条近期边标记heldout，意思是未用于生成参数的数值拟合；分析者已经知道线上方向，因此仍是回顾性验证，不是盲测。真正前瞻验证需要冻结后的新线上回执。
- 现代版本共享同一温度前父状态再独立运行各自后续阶段，减少父校准波动干扰。部分公共成本排除在计时外，不能用这些秒数预测线上。
- 按组做重采样，避免把同W/同分布的5题当独立样本；区间只描述本地覆盖组的敏感性，不是线上置信区间。

## 使用原则

新集可以提高结构检查与反例分析的可信度；**只有结构修复不构成线上预测资格**。任何未复现的大改进/大退化必须保留为缺口，不重新包装为“全面拟合成功”。后续算法比较须同时给出分层差异、触发/回退和最终输出误差，不能因本地无收益就关闭线上尚未验证的大方向。

默认评测路径保持 `local_fitted_models_attention_feedback_v2` 以兼容现有脚本，但以manifest的schema和哈希识别数据，不再按目录名判断版本。旧组号的含义已失效；历史逐题结果只能与当时的旧bank哈希配对。mini_sample仅显式用于格式/正确性，不做性能收益依据。

详细回测结果、实际替换记录及置信度验收见本文后续章节与 `structural-bank-audit.json`。

## 回测结果：预测验收未通过

以下是所选覆盖组的**每题原始分差均值**，不是线上分数。旧/新各10组50题，并非同分布随机样本；不能据此计算“线上预测准确率”。

| 版本边 | 线上总分变化 | 旧集原始差 | 新集原始差 | 新集方向 |
|---|---:|---:|---:|---|
| 285→302 | +1659 | +0.07642195 | +0.06533639 | 一致，但非单模块归因 |
| 310→311 | −4995 | −0.22488674 | +0.14050072 | **相反，关键缺口** |
| 324→365 | +230.25 | +0.00104562 | +0.00007464 | 一致 |
| 365→381 | +65 | 0 | 0 | 未复现 |
| 381→382 | +60 | +0.00024295 | +0.00031677 | 一致 |
| 382→386 | −160 | −0.00230209 | −0.00008124 | 一致 |
| 382→387 | +25 | −0.00103536 | −0.00000234 | 相反，近于零 |

两套覆盖样本在四条近期边上都是2/4方向一致。**新集没有证明比旧集更能预测线上，而且丢失了旧压力样本对v311反例的覆盖。** 本轮改进的是结构约束、来源透明度和置信度标记；不是预测能力已提升的证据。不得从接近零的回测差断言线上无收益。

原因进一步收窄：旧集抽查的强sink组最大概率约0.946到接近1；新集首批宽分布/低秩组仍较分散（例如最大概率约0.0016、0.0129），因此容易奖励均值优化。这里每组特征来自首份测试的32个query，长度不同，不能把这些值当完整分布直方图。删除人为sink后未自然再现相关性，说明**共享hidden的高斯/低秩建模仍不充分**。它没有解释真实残差流中的特殊token、层级语义、非平稳性等条件，不能用“换了真实投影”掩盖这一点。

下一轮应优先获取真实模型前向中间激活或独立层级统计；如继续模型化构造，应把共享hidden的非平稳/稀有token结构作为新假设，以未参与修改的种子和后续线上版本检验。不能重调本批比例后把同四条边再次称为独立验证。当前长度上限2048、Qwen全16头只在部分宽分布组覆盖，也是下一轮设计限制。

## 替换及恢复

- 当前默认路径：`local_fitted_models_attention_feedback_v2/`，schema为`structural-v3`。
- 原目录完整移至：`local_fitted_archive/attention_feedback_v2_before_structural_20260906/`。没有删除原张量；Linear逐字节保持不变。
- 默认评测入口不再暗中使用mini_sample，并输出dataset绝对路径、schema和不可外推提示。算法文件及`solution.py`均未改变。

- **旧压力集作为反例检查保留，不能仅凭新集挑选算法。** 运行同一基线/候选时，对新默认路径与上述旧路径分别评测，单独报告结果，不把两套分数混加或拟合成线上分数。
