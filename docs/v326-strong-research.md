# v326：大幅坐标与目标改动的首轮研究

## 范围及结论

v325线上20810/289，相对v324仅+7/+43。此次不增加Q尺度树轮数，以v324为共享父状态，冻结Linear和V，完成三类13个配置及一项跨组复核。没有创建正式solution_v326.py、没有修改提交入口；下面结果不足以承诺线上+50/+200。

使用codebase-memory定位现有共同变换/GPTQ代码，读取历史负实验后发现：校准KV原型上的当前Q非线性KL/PV搜索已经试过，首30题两档均未产生收益。因此没有重写它再计成新策略。复用共同变换及二次度量数学，不声称本轮重新阅读全部论文。

## 第一类：改变实际HiF4分组和跨通道混合

前四份校准中最后两份，每角色取至多128行，在**当前变换坐标**估计每通道RMS。三种排序分别按K、Q、Q/K联合log-RMS重排；第四种把强弱通道配对做45度正交混合。Q/K同步右乘R，连续点积不变，新的HiF4四/八/六十四通道共享尺度布局发生改变。这区别于保持尺度分组不变、只改变GPTQ消元顺序。

R融合进已有joint_transform；逆度量UᵀU及refinement H同步共轭变换。实际父版K平移、温度、V输出继续参与校准评分，不使用快速RTN近似部署。末份校准保留完整key、至多64个query，两折按KV组同步选择Q/K；没有逐Q头额外误差上限。

| 独立配置 | 六组30题净原始分 |
|---|---:|
| K排序 | 0 |
| Q排序 | 0 |
| Q/K联合排序 | −0.001951880292 |
| 强弱通道正交混合 | −0.086834318005 |

前两项全部校准回退；后两项在组49有一个KV头通过，但测试退化。例：组0 K排序的两折误差比约1.016–1.029，确实没有达到校准改善条件，不是只有格式失败或异常回退。

## 第二类：变换后坐标的非正交误差再分配

Q右乘R，K右乘R⁻ᵀ。区别于旧原始通道平滑：从现有部署坐标出发，不撤销现有变换；允许成对重新分配Q/K的动态范围和相关性。

- 对角平衡：s=sqrt(RMS_K/RMS_Q)，裁剪到[0.25,4]，分别用s的0.5、1、−1次幂。
- 全矩阵两端白化：由U通过三角求解恢复带阻尼H，分别按H_K的平方根、H_Q的负平方根生成R；几何均值归一化并限制奇异值[0.25,4]。
- Q逆度量变为RᵀH_K⁻¹R，K逆度量变为R⁻¹H_Q⁻¹R⁻ᵀ；refinement度量按相应对偶变换同步更新。

| 独立配置 | 六组30题净原始分 |
|---|---:|
| 半强度对角平衡 | +0.000140479187 |
| 完整对角平衡 | 0 |
| 反向对角平衡 | −0.017845804753 |
| K度量白化 | 0 |
| Q度量白化 | 0 |

对白化的0只表示本批全部回退，不表示这个数学方向在线上一定无效。半强度只在组0接受，收益过小，不合入。

## 第三类：替换GPTQ二次误差的谱形状

保持连续Q/K坐标不变，改变优化目标而非增加轮数。恢复带阻尼H，归一化其谱，并同步重建U与现有H；校准计算增加，但动态GPTQ/refinement形状与轮数保持原样。

| 独立配置 | 六组30题净原始分 |
|---|---:|
| 仅Q，特征值平方根：减弱各向异性 | −0.071829910298 |
| Q/K两侧均平方根 | −0.066552418417 |
| 仅Q，特征值平方：强化主方向 | +0.025454911263 |
| Q/K两侧，H与diag(H)各占一半 | −0.132887806803 |

强化Q主方向在组14和19采用；追加5/13/23/47四组20题，净增+0.024386505758，在13/23采用。合计10组50题+0.049841417021，均为本地原始分，不换算成线上分数。它是本轮值得保留的低动态成本候选，但幅度仍小，未达到可信大收益发布条件；其他负向配置不合入。

这并非声称H²是正确的Attention Hessian：它是有意改变任务代理的启发式，强化较大特征值方向，可能牺牲小特征值方向的误差。H包含父版阻尼，重新归一化、重建以及BF16 H舍入也属于该组合，尚未分别消融。不得把整个增量归因于单一理论机制。

## 验证、风险与后续门槛

- 数学检查32项：64/128通道、GQA、非正交互逆、连续点积、H与UᵀU一致性、谱重塑不改变连续坐标。不是所有形状的数值证明。
- 三类首筛及追加复核：82次状态合法检查，2026次动态参数格式检查（含校准内部调用，不是2026道不同题）。没有新提交文件的self_check或860完整验收。
- 所有配置在同组共享一次父状态，测试不参与构建变换或逐题选择。不同family独立生成父状态，跨family不直接拼接绝对总分。
- 数据为checkpoint投影权重加建模激活，不是完整真实模型前向。两折仍来自同一校准序列，不能保证跨序列泛化。
- 本轮并发实验含评分/格式检查，墙钟时间不能用于线上性能预测。
- 原v326梯度切片研究30题参数相同、纯Q单次快6.22%仍保留；不能据此认定可把289秒降到280秒内。
- 下一验收门槛：Q谱强化需要完整250题与另一Attention分布复核，再考虑与梯度裁剪组合；若继续只有小收益，不发布凑数版本。保留v325最高分、v324低耗时回退；当前没有可提交的新版本。

证据：v326-regroup-screen.json、v326-rebalance-screen.json、v326-metric-screen.json、v326-metric-second-screen.json。首份正交报告生成于字段名更新前，orthogonality_error与后续continuous_invariance_error的含义分别如名所示；数据未重写。
