复核日期：2026-08-29。

## 判定边界

- calibration 可以使用校准 split 拟合固定参数；
- dynamic 不得把当前测试激活与 `Q(W)`、权重量化误差或其 Hessian/importance
  目标组合，用来搜索、修正或反推 `Q(A)`；
- dynamic 不得读取其他接口的当前测试数据，也不得依赖调用顺序或跨样本缓存；
- `remote_result` 明确为 `Wrong Answer`、`结果错误` 或 `timeout` 的实现直接淘汰。

仅有固定正交变换、且 activation 的候选选择只依据自身重构误差，不属于上述违规。
