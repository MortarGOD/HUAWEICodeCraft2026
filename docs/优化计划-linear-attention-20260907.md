## 1. 方法论映射（实践与攻坚方法 → 本计划执行规则)

1. **调查先于定性**：v425 的教训是"固定Z局部收益 0.81–0.91 → encoder 重建后 1.044–1.062 全拒绝"。每个候选上线前查完整链路：接口可用信息 → 分支触发 → state 生效 → 最终输出张量改变 → 损失变化 → 评分变化。
2. **每轮一个可证伪问题**：计划中每个候选独立成版，写清父版 hash、必要条件、替代解释；失败只否定被正确实施的具体命题（v413 −57 与 v419 +54 同属 V 搜索家族、方向相反）。
3. **保留条件差异**：短/长序列、MHA/GQA、概率集中/弥散分层记录触发与验收，不用组号/长度硬编码路由。
4. **胸中有数**：本地代理已多次与线上反向（v422 本地 −0.26 / 线上 +39.55；自然轨 40 题全平 / 线上 +54）。修复筛选器（A5）先于扩大搜索；无校准映射时明确写"尚不能可靠估分"。
5. **发版门槛**（沿用 plateau 分析）：结构变化须覆盖多数启用头、或多来源/多长度层同向、或线上消融唯一支持；停止把单组小数级本地增益当发版证据。
6. **交付流程**（沿用 `docs/online-iteration-workflow.md`，用户已授权）：实施计划 → 独立候选开发 + 机制检查 → self_check.py 六接口 + 22 格式 → 直接提交推送远端（保留父版与默认入口 `solution/solution.py`=v325，不覆盖）→ 对已推送源码跑本地数据集估计 → ZIP 交用户上传平台；本地估计不是推送门槛。

### L1｜合法编码的元素级余量测定 → 尺度树全局枚举（= 项目理解文档"优先实验B"，尚未运行）

- **机制**：HiF4 每个 64 块的合法编码自由度 = 255 个正 E6M2 码（2^-48…49152，bias 48）× 每 8 元素组 lv2/lv3 组合。基线 `hif4_quant.py` Algorithm 1 只用峰值启发式选一个点（SF=Vmax/7 向上取整、阈值 4/2）。对真实 NVFP4 解码值抽块，穷举单块元素 SSE 最优参考，测定各生产路径（升维/降维 W、A、Q/K/V）当前尺度树距逐块最优的余量，再把有差异的块放回 `A@W`/attention 输出目标检验收益传导。
- **证据**：V 侧同类实验（6→16/24 个 E6M2 候选）使原生元素 MSE 降 0.29–0.73%（`docs/attention-error-budget-report.md`），但因未保留父后处理未通过输出守门——严格的"只扩尺度网格、保留全部父后处理"消融从未做过。对手 `9f7745d` 用 64×64 二阶矩收缩 + 块二次型候选比较选尺度，属同一家族的已验证存在性证据。
- **必要条件**：单块 SSE 最优与输出 MSE 改善的传导率必须实测（V 侧已知存在"元素降、输出不降"断裂）；穷举参考只作余量上界，不直接当收益承诺。
- **最小可证伪实验**（D1，离线诊断，不改提交）：从本地数据集抽 ≥200 块/区域（升维 W、降维 W、A、Q、K、V），对每块穷举 255×(lv2,lv3) 组合求元素 SSE 最优，与生产路径当前编码比较；报告各区域"当前 SSE / 最优 SSE"分布与可回收上界。
- **验收**：若某区域中位余量 <1%，判定该区域尺度枚举方向关闭；若 ≥5% 且输出目标传导实验（固定其余全部父后处理，只替换尺度选择）在两折上同向改善，升级为版本候选。
- **代码锚点**：基线 `_quantize_e6m2_up`、`quantize_to_hif4`（hif4_quant.py）；生产侧 `_quantize_weighted`（v422:2835）、`_quant_chunk_vec`（2432）、CAND_GRID（2325）。

### L2｜W 尺度树改变 + encoder 联合重建（攻 38.2% 列空间项）

- **机制**：数学分解 `||Y(I−P_B)||²` 表明末端码字搜索不能改变固定 B 的列空间项；只有改变 Q(W) 本身能移动它。v425 已证失败模式：**只翻 W 码、事后再重建 encoder，固定Z收益（0.81–0.91）在重建后消失（1.044–1.062）**。正确姿势是把"W 尺度树（E6M2/lv2/lv3）改变 → encoder/部署 Gram 重建 → A 重搜"作为**一个联合候选端到端评分**，守门放在重建之后的完整输出上。
- **证据**：`docs/v425-report.md` 同W重建对照（组0 空重建逐值全等、P 最大差 0）排除了"空重建破坏父 encoder"解释；v425 报告明确"保留父 P 或对其作受约束增量是未来独立假设，需要先检查历史并用固定父状态受控对照"。
- **必要条件**：先由 L1/D1 回答列空间项中尺度选择可回收的上界，避免盲攻；重建成本每权重一次可控；两折共识 + 末份完整校准守门保留且不降阈值。
- **最小可证伪实验**：在 v425 已有框架上改两点——(a) 提案目标从固定 Z 改为"重建后部署输出"（搜索内嵌一次轻量重建）；(b) 增加"保留父 P、只对 W 码作受约束增量"的对照分支，与"重拟合 P"分支分离归因。五个升维组任一组的末份两折误差比 <1 且 BF16 验收通过才算触发成功。
- **验收**：末份完整校准两折平均 MSE 均降 ≥0.01%（沿用 v425 门槛，不降低）；本地 active 50 题 + realw 25 题无回归；负例照实记录。
- **替代解释**：列空间项大部分可能是合法离散格式不可消除的——D1 先行正是为了区分这两种世界。

### L3｜量化感知的低维块正交变换（v423 审计列为"未充分检验"）

- **机制**：在训练环内放**实际部署量化器**、以真实 BF16 输出为目标学习低维正交块变换。v162（有限 Kronecker Givens 候选）、v211（通道 multiplier）、v424（冻结码代理 + 采样双折）都不等于该目标；v424 失败的是代理目标（逐张量冻结码、闭式提案），不是坐标方向本身——v422 谱峰反射线上 +39.55 证明坐标结构仍能拿分。
- **证据**：`docs/linear-strategy-audit-v423.md`"纠正旋转已系统验证的概括"一节；SpinQuant §3.2 / AffineQuant Eq2 的条件（高精度激活、全网训练）不满足本题双 HiF4、CPU 300s，需用离散候选 + STE 小步数重新推导，不照搬论文训练。
- **必要条件**：每个候选变换必须过完整校准/动态链路重建后再守门（v424/v425 双重教训）；变换族维度受限（块对角、低秩参数化）以控时间。
- **最小可证伪实验**：固定 v422 全部路径，只对升维组追加"以重建后 AW 实际 BF16 输出为目标、STE 梯度驱动的小步数块 Givens 搜索（每块 ≤8 对、≤4 步）"，双折守门。
- **验收**：本地两折同向改善且末份守门通过才推送；若与 v424 同样出现"采样代理改善、完整链路退化"，记录为量化感知训练在本题预算内的第二次负例，方向降级。

### L4｜NVFP4→HiF4 子块结构的预计算最优映射（格式特有）

- **机制**：一个 HiF4 64 块恒含 4 个 NVFP4 16 块；输入值集有限（每子块 E2M1 的 15 个非零电平 × 已知 E4M3 scale）。块输入完全由"4 个子块 scale 比例模式 + 子块内电平分布"参数化。对常见 scale 比例模式**离线穷举最优 (E6M2, lv2, lv3, mant 映射)**，在线查表/规则化，替代逐块连续计算——同时是精度候选与提速候选（任务书两个挑战"Scale 层级断裂/值集空间错位"的直接数学化）。
- **证据**：基线与本项目当前路径都未显式利用输入 discreteness（L1/D1 的穷举基础设施可直接复用）；参考仓rrs-fast-fp16（24201/204s）提供研究线索；其完整方案分数不能单独证明速度结构的贡献。
- **必要条件**：离线穷举须证明"查表映射在真实数据分布上优于生产启发式"（元素级 + 输出级双重检验）；表大小与加载受 300s/内存约束。
- **最小可证伪实验**：先离线统计本地数据集全部 64 块的"4 子块 scale 比例模式"分布；对 top 模式穷举最优映射并与生产编码比较元素 SSE；若优势存在，再做一个只替换 `_dyn_table`/`_quantize_weighted` 内尺度选择的原型跑输出守门。
- **验收**：元素级优势 + 输出级两折同向 + 时间不增；任一不满足则该方向记录边界后关闭。

## 3. Attention 大颗粒优化点（A1–A6）

现状（源码核实，v422）：
- **K 生产路径**：`_kt_input`（4214，qs/ks 缩放 + joint_transform/rot + 温度增益）→ KT 平移（`_kt_quant` 4255，mode 2/4：token 均值/概率加权中心 + 3 轮 Lloyd）→ TS 变体（`_ts_quant` 4348，8 轮概率加权 Lloyd）→ `_kt_fixed_grid`（4230，`_dyn_table` 格点 + GPTQ（`u`=Uk=cholinv(Hq)）+ `_refine_attn_heads`（2720，H=Hq_bf，rf 轮））。守门：`_kt_guard`（4277）/`_ts_guard`（4362）用真实输出 MSE（`_joint_output` 对 strided holdout，两折 all(0) + 最小增益 0.5–1%）。
- **K 风险目标（本次改动对象）**：`_refine_attn_heads` 内 J = Σ_t E_tᵀ H E_t（E=量化误差，H=Hq=Σ QᵀQ 跨组头/跨校准样本，v422:3217–3253）；top-1 逐行贪心 CD，增量 ΔJ = 2sd·M[t,c] + d²·H[c,c]，M = E@H；行独立 → 冻结压缩。常量：`ATTN_REFINE_Q_SWEEPS = ATTN_REFINE_K_SWEEPS = 1`（2566–2567，**不能用 sweeps 区分 Q/K，需显式 role 标志**）、`ATTN_REFINE_MAX_T = 4096`、`_REF_ATTN_ROUNDS = 8`、rounds = rf×(32 if T≤128 else (4 if T>1024 else 8))。
- **V 生产路径**：`_vk_fit`（4689，≤256 query 原型 sigma 模式）→ `_vk_probabilities`（4714，核 logits + 4 sigma 点秩2协方差；T≤4096、概率行 >128 回退父版）→ `_rb_refine`（4778，2 轮、`_rb_factor` 加权 Gram+1% ridge+Cholesky、边界预算 dict.fromkeys((1,min(4,t),min(16,t),min(64,t)))、接受 candidate_cost<cost 且 mse≤cap×1.05）→ `_va_prune`（4734）。
- **诊断**：V 项主导多数组误差（62–98%，组49 QK 56.7%）；真实 Pq 下 oracle 固定尺度 V 码搜索最多降到 0.61–0.99×父版（组5 泛化失败 2.22–4.27）→ **V 码字搜索有上限，P_proxy 风险模型是瓶颈**；P_proxy 把"56% 质量集中于一个 token"抹平成集中度 1.8（真实 ~737/1014），且集中位置在校准/测试间漂移（组14：70→38；组19：149→558）。

### A1｜K quotient 风险目标（softmax 平移不变性）—— 首选，成本最低

- **机制**：对所有 key 加同一向量 δ 使每个 query 的 logits 平移常数 qᵀδ → softmax 不变 → K 量化误差 E 的 token 均值分量 Ē 对输出无风险。把 K refinement 的风险目标从 J = Σ_t E_tᵀHE_t 换成 **L(E) = Σ_t (CE)_tᵀH(CE)_t，C = I − 11ᵀ/T**。
- **精确增量（已推导核对）**：
  - 单 token 改变 δ（坐标 c、步长 s·d）：ΔL = 2sd·M̃[t,c] + (1−1/T)·d²·H[c,c]，其中 M̃ = (CE)@H = M − m̄，m̄[b] = mean_t M[b,t]（M=E@H 与父版相同）。
  - 多 token 联合改变 Δ：ΔL = 2Σ_t Δ_tᵀH(CE)_t + Σ_t Δ_tᵀHΔ_t − (Σ_tΔ_t)ᵀH(Σ_tΔ_t)/T（交叉项不可丢；与对手审计记录一致）。
  - T=1：C=0 → L≡0 → 无翻转，天然安全（且父版 T=1 已早退 `_dyn_table`）。
- **实现要点（源码级）**：
  - 干预点仅四处：`_refine_attn_heads` 加 `quotient=False` 参数；base 校准 K 调用（3329）传 True；`_dyn_qk` refinement 调用（3458）传 `quotient=(role=='k')`；`_kt_fixed_grid`（4241）传 `quotient=(role=='k')`。Q 路径（3320、role='q'）不动。
  - CD 环内：m̄ 为 (B,dh) 每头张量，初值 M.view(B,T,dh).mean(1)；每轮增益用 g = −2d·|Ma−m̄[hrows]| + (1−1/T)·d²col2；翻转后除父版的 Ma.addcmul_(gb,coef) 外，m̄.index_add_(0, hrows, coef·gb/T)（**所有活跃行的翻转都贡献均值漂移，含即将冻结的行**）。
  - **已知近似**：父版"行冻结压缩"在耦合目标下不再严格成立（m̄ 漂移可使已冻结行重新有利）。最小版保留压缩（贪心近似，与父版 top-1 贪心同级）；机制检查须量化该近似的次优性上界样例。不压缩的精确版每轮 O(B·T·dh) 全程无压缩，时间风险高，仅作对照实验。
  - 无新增 state 键（quotient 纯计算路径）→ 无状态格式风险；rf_k 接受仍由校准真实输出 MSE 守门（3331–3334），动态侧仍受 KT/TS 真实输出守门约束。
- **证据**：对手两份审计一致列为最值得分离验证的机制（`docs/test参考实现优化分析-20260907.md` K quotient 公式组；`docs/test分支审计-20260907/isolated-methods.md`）；与已有 KT/TS 值空间平移（v321/v322 +435/+160）**不同**：KT 平移改变 K 值以减少误差本身，quotient 改变误差的风险度量；两者互补（KT 中心化后残余 Ē 仍被 quotient 忽略）。
- **必要条件**：平移不变性在真实评分链路成立（softmax 前无 K 依赖的非线性）；解析增量与直接重算 L 一致；H 沿用父版 Hq 不重估。
- **最小可证伪实验（= v426 候选）**：只换 K refinement 目标，格点、GPTQ、H、轮数预算、KT/TS、V 路径、守门全部不动。机制检查：(1) fp64 小样例 ΔL 解析式 vs 直接重算（单 token 与多 token 含交叉项）；(2) quotient=False 与父版逐位一致（Q 路径与默认回归）；(3) 构造 Ē≠0 样例证明 quotient 找到父版目标下不存在的改善翻转、且真实 softmax 输出不劣化；(4) T=1/T=2 边界；(5) 角色隔离重放（q_state/k_state/v_state 冻结输入不变性）。
- **验收**：本地 attention 两折输出无回归 + 触发覆盖率/接受率/计时齐报；线上回执为准，尚不能可靠估分。
- **替代解释**：若线上无效，可能是 (a) KT/TS 平移已吃掉大部分均值分量，quotient 剩余空间小；(b) 行冻结近似抵消收益；(c) rf_k 在多数组未被校准守门接受（触发覆盖率会区分 a/c）。

### A2｜V 短 T 完整 token 二阶 E[PᵀP]（参考仓历史方案中的机制）

- **机制**：校准估计 token×token 二阶矩 H = E[PᵀP]（P 为注意力概率），收缩 0.7H+0.3I，保留 token 间非对角耦合；动态在冻结 H 下做单坐标 CD、双 token 逃逸、lv3 子树翻转（要求 T 与校准精确匹配，[kv_heads,T,T] 状态）。与 v422 的 16 因子低秩概率模型（`_vk_probabilities`）本质区别：**不抹平 token 耦合与集中结构**——直接针对 factor-information-gap 诊断的结构性缺陷。
- **证据修正**：参考仓归档25062/181s（`368e0da7`）未确认题量及平台上传hash，不能作为同口径线上存在性证明，也没有固定Linear的H-only消融。本项目oracle诊断仅在所测数据中显示V码搜索收益受P质量影响。用户明确确认新旧题量的只有16806/24201同源码对照，其他回执不得自动套用。
- **必要条件（先验证再实施）**：
  1. **三角色校准可迁移性**：对手机制的校准协议与本题线上三角色协议（真V/假Q,K → v_state）的逐项等价性未核实；假对端产生的 P 统计能否迁移到真对端测试分布，必须先做离线诊断（用本地数据模拟假对端，比较 E[PᵀP] 在假/真对端下的 token 耦合结构相关性）。
  2. **状态预算**：H 为 [kv_heads,T,T]，T² 增长 → 只对短 T（对手口径需 T 精确匹配；本项目 state 深度≤8、≤4096 节点、CPU 张量约束下需核算 bf16 存储）启用；长 T 走现有因子路径；T 不匹配稳定回退。
  3. lv3 子树翻转依赖合法编码结构（每 4 元素共享 lv3），与 `_rb_refine` 的预算树交互需分离归因。
- **最小可证伪实验**：第一步只做**风险模型替换**（用短 T 完整 H 替换 `_rb_refine` 的 `_rb_factor` 加权 Gram），不动搜索结构（CD/预算/接受式全保留）；第二步才加双 token 逃逸与 lv3 子树翻转。两步独立成版，避免 v412/v419 式混合归因。
- **验收**：必要实验 1 的假/真对端耦合相关性报告先行；版本验收沿用两折 + 末份守门 + 触发覆盖率；V 项主导组（62–98%）分层报告。

### A3｜P_proxy 集中度预测修复（放大已验证 +145/+54 路径的公共上游）

- **机制**：对罕见高概率 token 加权的 logit/概率拟合替代普通均方拟合；研究位置无关的集中度先验（当前集中位置在校准/测试间漂移，位置特征不可迁移，但"集中度水平"本身可能可迁移）。改善 `_vk_probabilities` 会同时抬升 VK（+145）与 v419 相关残差（+54）两个已验证机制。
- **证据**：`docs/factor-information-gap.md`（预测集中度 ~1.8 vs 真实 ~737/1014；组14/19 位置漂移）；`docs/value-oracle-headroom.md`（组5 连 oracle 曲率都损害输出——P 质量差时任何 V 搜索都无效）。
- **必要条件**：修复必须同时解释正例（组14/19 真实 K 替换后改善）与反例（组5、组49 原型代表性失败）；保留跨序列守门；不用训练目标选版本。
- **最小可证伪实验**：在 `_vk_fit` 的 sigma 模式拟合中加"top-k logit 加权"变体（k∈{1,4,16}），只改概率预测、不改 `_rb_refine` 搜索；本地按集中度分层评估概率预测误差（KL 或 top-1 命中），再跑输出守门。
- **验收**：概率预测层指标改善 + 输出层两折同向；若概率指标改善但输出不动，记录为"预测-输出传导断裂"新证据。

### A4｜三角色校准下的 Q/K 坐标一致性（±1900 分量级变量，先诊断后动手）

- **机制**：共同变换 Q'=QD·R、K'=KD⁻¹·R 要求两侧一致，但 Q/K 分别用不同假对端校准，数据驱动选择无一致性保证。方向：把共同变换改为**双侧都能从自身数据独立推导到同一结果的确定性规则**（按 head_dim/RoPE 对结构键控的固定变换族），或先证明假对端统计下选择一致的概率。
- **证据**：v415 −13、v417 −1941（坐标灾难）、v418 −223；对手 23040 的 Q/K 共同 RMS balance 在今天协议下失效；v422 谱峰反射 +39.55 说明坐标仍有正例，但选择必须稳健。
- **必要条件（= 项目理解文档优先实验 C）**：先用本地数据模拟三角色协议，测量"Q 侧独立选择的变换"与"K 侧独立选择的变换"的一致率；一致率低的变换族直接禁用，高的才进入版本候选。未通过一致性证明的联合变换不进入提分比较。
- **最小可证伪实验**：纯离线诊断（D2 的一部分），不产生版本号。

### A5｜本地筛选代理保真度修复（元优化，A1–A4 的验收前提）

- **机制**：构建模拟三角色校准协议（假对端）+ 长度/集中度分层的筛选 bank；用 7 个已知线上带符号结果标定代理方向一致率：v412 +145、v413 −57、v415 −13、v416 −7、v417 −1941、v418 −223、v419 +54（另可加 v422 +39.55 本地 −0.26 作为反向标定样本）。
- **验收**：代理对 ≥5/7 已知结果方向正确才获得淘汰资格；否则继续"self_check → 推送 → 等回执"流程，本地只做机制与回归验证。
- **地位**：不产生线上分数，但决定 A2/A3/A4 的实验速度与误判率；Phase 0 执行。

### A6｜Q 侧输出感知扩容（条件性，受预算约束）

- **机制**：`_rb_refine` 的 128 行代理 P 上限与 4 sigma 情景是保守配置；Q 输出 Jacobian Gram（`_oj_fit` 4628）已在父链。仅当 D3 计时显示余量、且 A2/A3 证明风险模型改善可传导时，扩 query 覆盖/情景数。
- **反证约束**：单纯扩大搜索已两次失败（v369 超时、v394 −3）；本项排序最后，不独立启动。

## 附录 A：v422 K 路径源码事实（本次阅读核实，供后续开发直接使用）

- 生效动态 K 入口：`hif4_dynamic_quantize_k`（4412，TS 包装）→ `_ts_quant`（4348，8 轮概率加权 Lloyd 中心）或回退 `_kt_parent_k`（4334，KT 包装）→ `_kt_quant`（4255，mode 2/4，3 轮 Lloyd）→ `_kt_fixed_grid`（4230）→ `_dyn_table` 格点 + `_gptq_quantize_batched`（u=Uk）+ `_refine_attn_heads`（H=Hq_bf，rounds=rf×(32|4|8)）。ts_active 按 64 通道块粒度 torch.where 合并（4421）。
- 生效校准链：base `hif4_calibration_attention`（3120）被 vm/vr/oj/dm/kt/ts 等包装逐层捕获，最终生效为 4833 的定义；base 内 K refinement 调用在 3329（H=Hq、kvh、ATTN_REFINE_K_SWEEPS），Q 在 3320（H=Hk、qh）；rf_k 接受守门 = strided holdout 真实输出 MSE（3331–3334，ATTN_REFINE_GUARD=True，MAXT=512）。

- `_refine_attn_heads`（2720）：M = (v4·d − x)@H；每轮全活跃行 top-1 翻转 g = −2d|M| + d²·diag(H)，行无益即冻结压缩；ipos/ineg 界 ±7；total_rounds 参数由调用方注入。
- KT/TS 守门成本函数（4303、4394）：`_joint_output(q,key,v,…,query_subset=True)` 对 holdout 行 ix 的真实输出 MSE，奇偶两折 all(0) + 最小增益（refined: 1%/0.5%）；`_ts_cache` 在 kt/ts 间传递 holdout 上下文。
- 常量：ATTN_REFINE_Q_SWEEPS=ATTN_REFINE_K_SWEEPS=1（2566–2567）、ATTN_REFINE_MAX_T=4096（2603）、_REF_ATTN_ROUNDS=8（2606）、ATTN_GPTQ_ENABLE=True（2605）、CAND_GRID 6 模式（2325）。
- A1 设计结论：quotient 目标 M̃ = M − m̄、m̄[b]=mean_t M[b,t]、增量 ΔL = 2sd·M̃ + (1−1/T)d²H[c,c]、每翻转 m̄ += coef·H[c,:]/T（按头 index_add）；无新增 state 键；Q/K 区分必须显式 role 标志（sweeps 常量相等不可用）。
