# v350：V 条件概率因子的非对角风险搜索

父版 v324，Linear、Q/K 不变，默认 solution.py 不变。此为线上未验证的新方向探针，不是22000分承诺。

## 与旧策略的区别

v341 用预测均值外积加对角方差近似风险。本版从两份校准的量化 Q 选取16个固定 query 原型，拟合标准化 V 到对应量化 K logits 的岭回归。测试阶段仅用当前 V 与回归系数得到16条归一化概率因子 B，采用 H=BᵀB/16 + I/T²；保留多条概率因子之间的二阶信息，而非先平均再做外积。

没有测试 Q/K、跨接口通信、I/O、动态导入；query原型已吸收到回归系数。沿用最后一份校准的真实最终PV两折守门和原V后处理，独立留出序列不参加回归。固定HiF4尺度，8轮精确单坐标码值搜索，不分配T×T矩阵。动态T4..4096且元素数≤4194304，否则原V回退。

这只是经验条件核近似，不是完整条件期望或论文理论保证。Q原型覆盖、V→logit可预测性和跨序列漂移仍有风险。
