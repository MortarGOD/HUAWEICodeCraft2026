# 完整 W 可用场景的论文复核与算法路线

日期：2026-08-30  
输入依据：`docs/max_opt.md`、题目六接口、`self_check.py`、当前 v270 与线上历史消融。

## 1. 先修正数学目标

`max_opt.md` 把新问题简化成了 `Y=A W^T` 后直接量化 `Y`，这与接口不一致。动态接口必须返回与 `A` 同形状的 HiF4 参数，评分器最终计算的是：

```text
B = dequant(Q(W))                    # 校准后固定，五个测试激活共用
Z = dequant(Q(A; A, W, B, state))    # 每个测试激活可动态决定
Y = A W^T                            # 完整 W 教师目标
min_Z ||Y - Z B^T||_F^2,  Z ∈ HiF4(A 的逻辑形状)
```

因此：

- 测试阶段能访问完整 `W`，等于拥有精确教师 `Y`，但不能把输出维度的 `Q(Y)` 冒充输入维度的 `Q(A)`。
- `B=Q(W)` 仍在校准接口中固定，不能针对五个测试输入分别更换。
- 真正的联合问题是双层离散优化：

```text
min_B Σ_i min_{Z_i∈HiF4} ||A_i W^T - Z_i B^T||_F^2,
B ∈ HiF4(W), 且测试阶段只对当前 Z_i 求条件最优。
```

- v270 已完整计算 `Y`，并用 64 维 Newton、4 维微码和精确目标门控优化 `Z`；剩余空间主要是更好的全局初值、预算分配和更强的 `B/Z` 联合基变换。

## 3. 五篇新增论文的可用结论

### 3.1 Atom：动态 scale 的价值高于混合精度旁路

原文机制：

- 取激活平方和最高的 128 个通道作为异常通道，固定重排到连续区域。
- 普通通道 INT4、异常通道 INT8；分组大小 128。
- 当前 activation 在线计算对称量化参数，activation clipping 经验值约 0.9。
- Weight 仍离线用 GPTQ，Weight clipping 经验值约 0.85。

本题映射：

- HiF4 格式不允许 INT8 旁路，因此“混合位宽”不能直接使用。
- 可把异常通道概念改为“混合搜索预算”：显著块扩大 E6/rounding/relaxation 候选并增加 sweep，普通块使用查表快速路径。
- 不能只最小化 `||A-Q(A)||`；每个 token、每个 64 块的 scale/clipping 必须由精确教师变化量
  `ΔL=2<δ,RB_block>+δ(B_block^T B_block)δ^T` 裁决。
- v270 已做 per-row HiF4 和精确目标门控，但尚未做 Atom 式“当前输入异常程度决定候选宽度”。

### 3.2 QServe：保护范围、结构重排与 Attention 平滑

原文机制：

- Weight 先进行 per-channel INT8，再把中间 INT8 按组压到 INT4。
- 为防止二次反量化溢出，把第一层范围从 `[-127,127]` 收缩到 `[-119,119]`。
- QServe 用 `max(|X_j|)` 排序输入通道，让相近显著性的通道落在同组。
- SmoothAttention 对 Q/K 使用互逆对角缩放；RoPE 配对维度必须共享 scale。
- 对 down/out projection，论文指出 SmoothQuant 迁移强度应接近 0，不能照搬 QKV/up 层参数。

本题映射：

- Progressive INT8→INT4 编码不匹配 HiF4，但“层级量化的保护范围”可映射成 E6→E1→S1P2 联合候选的防饱和约束。
- v270 已联合枚举 E1/S1P2，但尚未根据当前块的二级溢出风险动态缩小 E6 候选。
- 激活显著性重排只能在校准阶段与 `B` 一起固定；测试时不能只重排 `A`。v270 的全宽 polar 已是更强的固定联合基变换。
- SmoothAttention 在历史 v129–v131 的旧 50 题代理上负向，且当前 Q/K 接口无法互看测试张量；保留为新增 200 Attention 的低优先级复验，不进入 Linear 主线。

### 3.3 LLM.int8()：把异常通道变成优先求解集合

原文机制：

```text
O = {j: 当前激活第 j 维存在 |x| > α}, α≈6
XW = X_O W_O + X_notO W_notO
```

异常维度通常不超过约 0.1%，且在大模型中反复出现在固定通道。

本题映射：

- 不能保留 FP16/INT8 旁路，所有返回值都必须是 HiF4。
- 可以用当前 `A`、精确残差梯度和 `W-B` 三者的联合显著性识别关键 64 块：

```text
s_b = ||A_b||_F · ||(W-B)_b||_F
      或 recoverable_gain_b = g_b H_b^{-1} g_b^T
```

- 先对关键块执行全候选/更多微码轮数，再对普通块执行窄查表；这是固定格式下等价的“精度资源旁路”。
- 比仅按 `||A_b||` 排序更可靠，因为高激活块若 `W≈B`，并没有足够教师残差可补偿。

### 3.4 ZeroQuant-V2 / LoRC：当前最值得验证的全局初值

原文对 Weight 量化残差做：

```text
E = W-B = U Σ V^T
E_r = U_r Σ_r V_r^T, r通常4或8，超过8后收益快速饱和
```

本题不能把 `E_r` 作为额外 Weight 旁路加回输出，但可以用它构造 `Z` 的全局 warm-start：

```text
Y - A B^T = A E^T ≈ (A V_r) Σ_r U_r^T
G = (A E^T) B                         # 对 Z 的全局梯度
Δ ≈ G · P, P≈(B^T B+λI)^-1
Z0 = project_HiF4(A+Δ)
```

实现时只接受使精确 `||AW^T-ZB^T||²` 下降的候选。可用三档成本：

1. rank-8 residual SVD + 64 块 inverse（首选）；
2. rank-8 全局方向 + SliM 显著块投影；
3. 作为连续上界诊断，不量化、不出版本。

历史 v240 只把 rank-32 warm-start 用于线上未命中的 square shape，因此不能据此否定矩形 up/down 的 rank-8 LoRC。v267 的两步 PCG 是不同机制，且没有利用 `E` 的快速谱衰减。

### 3.5 SliM-LLM：从混合位宽改成混合计算预算

原文 salience：

```text
H = X^T X / P
δ_ij = w_ij² / ([H^-1]_jj)²
```

SBA 按组平均 salience 排序，以高/低位宽对称分配保持平均 bit；SQC 对组内约 1% 的 3σ salient 元素搜索 `τ∈[0.9,1.1]`。

本题映射：

- HiF4 位宽不可变，不能实施 3/4/5-bit 分配。
- 将 SBA 的 bit budget 替换为固定总 FLOPs 下的 sweep/candidate budget：高显著块 20–30 次微码或宽阈值，低显著块 2–5 次。
- 将 SQC 的 τ 搜索改成 HiF4 合法 scale/rounding 候选，并把局部 MSE 换成精确输出变化量。
- 当前测试 `A` 已知，salience 不必使用校准 Hessian；可直接使用当前 `g_b`、`B_b^TB_b` 与可恢复下降量，避免 `A_test`/`A_calib` 分布漂移。
- 这是最可能在不增加总时间的情况下提分的路线：把已证明收益递减的均匀 20/5 轮重新分配，而不是一味加轮。

## 5. 后续验证顺序与出版本门槛

当前先等待 v270 线上反馈；不因论文新增立即出版本。后续实验按下列顺序进行：

1. **LoRC 连续上界**：在 up/down/square 分别测 rank 4/8/16 的理论可恢复量；若 rank-8 对离散前目标没有明显改善，停止。
2. **LoRC 离散 warm-start**：只增加一个全局提案，随后复用 v270 精确验收和微码；严禁无门控覆盖当前解。
3. **SliM 预算重排**：保持总微码迭代数不增，按当前可恢复下降量分配 2/5/10/20 轮。
4. **Atom 条件候选**：显著块启用 clipping/非最近舍入，普通块维持三项查表。
5. **联合 B/Z 校准**：仅当以上三项仍有空间时，用五个校准激活做一到两轮 `Z←argmin`、`B←argmin`，并用独立校准布局严格回退。
6. **Attention 复验**：固定 Linear，只测试 QServe 的 RoPE-pair SmoothAttention；不得与 Linear 实验混版。

出提交版本继续遵守：

- 4K 多 profile 逐题多数一致改善，不能依靠单组均值；

## 8. 联合可达集合与Attention二轮验证（2026-08-31）

- Polar后追加全宽Hadamard把全代理从230.301630降至224.170207：Polar特征方向携带可补偿结构，不能再次无差别摊平。
- 用精确教师Q(A)反推第二个Q(W)的一轮真实离散交替，被五布局回退门控全部拒绝；现有residual-feedback权重已在该代理上占优。
- Polar后加入两步输出空间CG只到230.324505，增量0.022875，仍被64维Newton吸收。
- down层把Q(W)替换为Hadamard正交紧框架，连续条件数改善但两组代理由9.781800降至9.306836；W对激活坐标的对齐比通用字典条件数更重要。
- Attention的Q/K按head联合尺度、V的校准softmax输出坐标下降、Q预测K/V、校准温度搜索均负向；原因是不同测试激活的token关系不可由校准样本稳定迁移。

由此关闭“再加一次旋转、再加一次局部迭代、通用字典替代W、校准Attention关系蒸馏”四类路线。后续若要达到34500，必须找到线上可迁移且能令代理至少增加22.77的全新联合参数化；不以低幅候选生成编号版本。

## 9. v271测试时Attention联合求解

此前负向实验都试图把校准Q/K/V关系迁移到测试样本；v271改为只使用同一次测试调用中的真实当前张量：Q调用缓存变换后的原值与HiF4重建，K调用对五个合法候选执行softmax-KL坐标选择，V调用再用真实目标概率和部署概率最小化最终`softmax(QK)V`误差。没有当前Q/K上下文时保持v270独立回退。

逐token精确KL最初在1024序列形成O(S³)更新。最终实现把同一64块内的token改为Jacobi批处理、块间保持Gauss-Seidel，并把V token坐标更新改成整列张量收缩；只对`seq_len<=512`启用，1024走v270回退。

- 全代理：230.301630→233.655214；Linear完全不变，Attention 5.196944→8.550528。
- 4K Attention单组五stride：0.258172→0.715163；耗时0.880→1.425秒。
- 按线上50组额外约27秒，v270的368秒外推约395秒。
- 短代理按250题完全迁移约+1677分；更接近线上stride的4K代理每组提升0.456991，按50组只迁移50%仍约+1142分，因此预测34750–35400。
- `self_check.py`：22/22。

线上v271为33653/370秒，与v270的33653/368秒完全同分。由此确认线上Q/K/V动态量化器隔离执行，模块全局联合上下文零命中；上述联合上界只保留为算法诊断，不再作为提交路线。v272恢复v270父版，仅在独立Q接口中加入5%的校准K协方差logit度量，以验证对端二阶统计能否在线上迁移。

v272线上33673/362秒，相比v270 +20分/-6秒，独立协方差目标低幅正迁移。随后完整W路线发现新的结构缺口：现有求解器虽用精确`Y=A Wᵀ`，仍从`Q(A)`做局部64/4通道搜索，没有先逼近固定`B=Q(W)`下的全局连续最优`Z*`。v273不做昂贵的全局逆，而在校准阶段把`(W-B)ᵀB`右乘已有64块Gram逆，编译成`P≈I+(W-B)ᵀB·blockdiag(BᵀB)⁻¹`。测试以一次`A@P`产生warm-start，只保留三个E6/RTN投影与原始A候选竞争，并继续用真实输出二次型单调验收。拟合集相对同批v272 +0.441514，mini +0.022336；它是全局搜索入口验证，后继应继续优化`Q(W)`的可补偿性和更高效的全局预条件，而非增加局部sweep。
