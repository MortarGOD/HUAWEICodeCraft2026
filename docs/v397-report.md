## 实现和边界

父校准只运行一次，临时捕获OJ之前的Q状态和KT之前的K状态。四候选：父版、Q恢复Logit度量、K恢复未平移状态、二者同时替换。保持父最终温度gain与key_center_mask；不是再拟合温度，也不是所有策略组合穷举。全组选择一个组合，不按头混合；部署直接返回既有状态，Q/K/V动态函数不新增调用或循环。

从合法校准选首、中、末三份（包含实际末份），每份32个均匀Q和完整K/V初筛。各序列MSE相对父MSE归一，至少两份改善、平均比值<0.995、最差<=1.01，按平均log风险加0.5倍最坏正log风险选一个胜者。完整复核对这一个胜者及父版计算三份全行Q/K/V输出，每128行流式累计实际MSE，使用同一规则，未达则回退。允许某一序列最多1%退化，不能声称逐序列误差不增。

预算sum(QH*T²*D)<=4e9才新增筛选，非GPTQ、异常长度或超预算保持父版。该指标未包含常数、多候选和父量化成本，不是4e9 FLOPs，也不是280秒保证。长序列或多头组合可能全部旁路，这些旁路同分不证伪跨序列路线。

这三份序列都可能参与过父拟合，属于跨序列重代入选择，不是独立交叉验证。只检验少量既有组合，不把v395/v396叠进来，不假定测试K/V可见，不根据数据组号路由。
