# v356：自适应风险 + 低权重位置谱

## 改动

父版为 v353，Linear、Q、K、V 的原生HiF4编码和8轮离散搜索预算保持不变。v353从测试V特征预测16个校准query概率因子；v356另外从两份校准Q/K的真实部署概率矩阵中计算归一化位置分箱，并用截断SVD提取4个风险方向。

动态阶段把16个自适应方向与4个位置谱方向按95%/5%的Gram权重拼接。该构造满足：

`BᵀB/20 = 0.95 AᵀA/16 + 0.05 SᵀS/4`。

测试阶段没有读取Q/K，也没有改变状态接口；新增状态仅为有限float32 CPU Tensor `spectral_basis[KV头,4,64]`。

## 选择与留出

初筛12组：+0.010685，8升/1降/3平；feedback和covariance都净正。

完全未参与参数选择的20组：+0.003442。feedback为3升/0降/7平，covariance为6升/3降/1平。正式实际文件抽取26组共130题复核：+0.013793，95项结构、数学、状态和配对检查通过。

两个关键否决结果同时保留：

- 仅用位置谱替换自适应风险：单末份守门−0.227930，跨三校准守门−0.210445；说明静态谱不能独立迁移。
- 为保持总rank=16而删去4个自适应方向：−0.037912；说明收益来自补充方向，不是替换方向。

## 性能与限制

两次六组顺序互换计时存在明显首运行冷启动：先运行的版本总是慢。冷位置的完整本地评估差约+10.9%，暖位置v356反而更快，无法据此给出可信的线上比例。算法上动态风险rank由16增至20，V风险矩阵乘理论增加25%，但Q/K及未采用头不变；校准多一个最多64列、4方向的小SVD。

以v324线上246秒和v350/v353约12%增量情景推断，v356大致处在280秒附近，但这不是线上保证；仍须实际回执验证300秒安全线。代理数据由checkpoint投影权重和建模激活构成，不能将+0.013793换算为线上分数，更不能宣称达到22000。
