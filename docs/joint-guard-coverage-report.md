# 共同变换守门：全Query覆盖诊断

2026-09-05。仅将v324共同变换/KV候选联合守门中的64个等距Query替换为该留出序列全部Query。六组均T=2048；保留全部Key、候选构造、两折及1%改善阈值。其他守门未改变。源码唯一匹配替换断言通过，12个状态格式校验通过，六组30例配对测试全部完成，所有JOINT_DEBUG.error为false。

结果：相对同轮v324原始分数和增量 **−0.005310634**。仅组0改变选择：balance_heads从1到2，kernel_heads从0到1；该组略降，其余25例逐值同分。两个分支共同变化，不能把组0损失单独归因于平衡或V核。

单轮校准总时间基线12.462527秒、全Query21.180062秒；首组存在冷启动影响，不能作为精确线上耗时预测，但本轮无精度收益支持扩预算。未给出300秒可部署保证。本脚本使用动态装载，仅用于线下诊断，不是提交文件。

## 决策

不增加正式共同变换guard的Query预算。此结果只说明这六组在原序最后校准样本上的全Query评分没有带来收益，不证明所有guard/线上数据都不受抽样误差影响，也不证明顺序敏感性已解释完。下一候选应研究跨序列而非同序列扩大Query数：保留原末样本独立验证作为主约束，其他校准样本只能作训练内稳定性辅助，不冒称独立验证；固定预算复用已有候选，不重复完整校准。不依据本地测试重新选择阈值。

Linear、正式版本及默认入口不变。数据是建模激活，22000线上目标未达到。
