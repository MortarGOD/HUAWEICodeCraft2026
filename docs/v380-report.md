# v380：当前部署路径上的共享 Q/K 正交训练

父版v365（线上21034/257秒），Linear/V冻结，默认入口不变。沿用历史learned_rotation_core的真实量化前向、直通梯度与Cayley正交更新，不宣称新发明或从未尝试。与v379 Q单侧全矩阵补偿不同，本版Q/K共享O，连续域点积保持不变，探索量化坐标系而非改变连续Attention函数。

## 当前路径适配

- 用当前_kt_input获取包含通道尺度、joint_transform/rotation与Q温度的正确部署坐标。
- O分别融合进Q/K原变换；逆Gram按O.T(U.T U)O运输后float64 Cholesky，H按O.T H O运输并保留原dtype。
- K的ts_fallback递归更新同一旋转，避免回退K与旋转Q错配。
- kt_probe直接乘原始K，保持原值，不误旋转；平移中心在当前旋转坐标重新计算。
- 单位矩阵返回原state，未改变头的u/H逐值保留。测试无新增搜索轮数；已有变换融合为一次矩阵乘，原本无变换的路径会新增一次。

训练用最后两份符合2≤T≤1024的非末份校准序列，全key、16query、最多两步，每步两个Cayley幅度（0.03/0.0075），无改善早停。最后一份校准全key与32query的真实量化V输出，两折都改善0.5%才成对启用。线上300秒约束不变，未将未通过门槛人为放宽。
