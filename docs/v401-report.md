每个代表分别softmax，返回sqrt(K×mass)×P的Gram因子，因此原求解器的平均平方目标等于加权情景风险。返回内部因子不再每行归一，但六接口仍返回合法HiF4参数。原梯度预条件器是启发式，不能宣称新权重下收敛最优。通常从4情景变8情景，核矩阵乘预计更贵，不保证总场280/300秒。
